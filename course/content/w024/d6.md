## Forge: a late-fee calculator, test first

A community library wants its late fees worked out by a program instead of by hand. The rules, from the librarian:

- Fees are charged per **day late**: each day after the due date, up to and including the return day.
- The library is closed on **Sundays**, so Sundays are never counted.
- **Books** cost 15p per day, up to a maximum of 500p for one item.
- **DVDs** cost 100p per day, up to a maximum of 1000p.
- **Reference** items can't be borrowed at all, so asking for their fee is an error.
- Members aged **under 16** pay half, rounded down to a whole penny.
- Returned on or before the due date: no fee.

For example, a book due on Friday 6 November 2026 and returned on Tuesday 10 November is late on Saturday, Monday and Tuesday (Sunday doesn't count): 3 days, 45p.

Your tests now say, in code, exactly what the librarian told you: the Sunday rule, the caps, the half price for under-16s. If the library changes a rule next year, whoever updates the code changes a test first, sees it fail, and then changes the code. ## Forge bonus: testing a ledger

This time you don't write the code: a club treasurer has written `ledger.py`, and your job is to test it thoroughly before the club trusts it with real money.

Like Day 5's basket, it's a class, and you only need to use it: `Ledger(path)` opens a ledger, and the methods are called with a dot. The text in triple quotes under each method (its **docstring**) says what it should do, and is what your tests check.

:::exercise id=forge2 points=30 title="Forge bonus: testing a ledger"
`Ledger(path)` in `ledger.py` keeps a club's money records in a CSV file. Read its docstrings for exactly what each method should do. Write a test suite, using a fixture with `tmp_path`, `pytest.raises` and `pytest.approx` where they fit, that passes on the treasurer's code and catches all **eight** broken versions.
@@files
=== ledger.py
import csv
from pathlib import Path


class Ledger:
    """Money in and out, saved to a CSV file with columns date, who, amount.
    Amounts are in pounds: positive for money in, negative for money out."""

    def __init__(self, path):
        """Open a ledger file. A missing file means an empty ledger."""
        self.path = Path(path)
        self.rows = []
        if self.path.exists():
            with open(self.path, newline="", encoding="utf-8") as f:
                for row in csv.DictReader(f):
                    self.rows.append({"date": row["date"], "who": row["who"], "amount": float(row["amount"])})

    def record(self, date, who, amount):
        """Add an entry and save. who is stripped and can't be empty; amount can't be 0.
        Both mistakes raise ValueError and record nothing."""
        who = who.strip()
        if not who:
            raise ValueError("who is missing")
        if amount == 0:
            raise ValueError("amount can't be zero")
        self.rows.append({"date": date, "who": who, "amount": amount})
        self._save()

    def _save(self):
        with open(self.path, "w", newline="", encoding="utf-8") as f:
            w = csv.DictWriter(f, fieldnames=["date", "who", "amount"])
            w.writeheader()
            w.writerows(self.rows)

    def balance(self):
        """Money in minus money out, rounded to 2 decimal places."""
        return round(sum(r["amount"] for r in self.rows), 2)

    def paid_in_by(self, who):
        """Total paid in (positive amounts only) by one person, ignoring case."""
        return round(sum(r["amount"] for r in self.rows
                         if r["amount"] > 0 and r["who"].lower() == who.lower()), 2)

    def largest_expense(self):
        """The row with the most negative amount, or None if there's no money out."""
        out = [r for r in self.rows if r["amount"] < 0]
        return min(out, key=lambda r: r["amount"]) if out else None
