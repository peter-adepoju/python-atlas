205 hours of topics, one that needs three others first, and 20 days of practice in the last 25. At four hours a week, 205 hours is about a year. That's the point of today: turning a wish list into a plan that fits a real life.

## Directions

After two years you know the language well and you've touched most of what it's used for. The next step is **depth in one or two directions**, chosen by what you enjoyed and what you want to do:

- **The web**: a framework in depth, databases, deployment, a service people use.
- **Data and machine learning**: statistics, a proper course in machine learning, larger datasets.
- **Tools and the language itself**: packaging, type checking, CPython's internals, contributing to the projects you use.
- **Teaching and community**: tutorials, mentoring, talks, maintaining an open-source project.

Keep one thing broad: **reading other people's code**. It's the habit that grows you fastest in any direction.

## A plan you can keep

List the topics you want, how many hours each needs, and what each needs first. Order them so nothing comes before what it depends on (a **topological order**, from Phase 4, with alphabetical order breaking ties so the plan is stable). Then fit the order to your **weekly hours**: an honest number, such as four hours a week, not the twenty you'd manage in a perfect week. A topic can run across several weeks; what matters is the week each one finishes, so you can see the whole year.

## Goals and review

A useful goal says **what** you'll do, **how much** (a number) and **by when** (a date): "finish the machine learning course and train one model on my own data by 30 June". "Get better at Python" can't be checked, so it can't be met.

And keep what you learn: **spaced review** (revisiting a topic after 1, 3, 7, 14 and 30 days) holds onto far more than one long session does. Your course exercises are ready-made review material: in a month, redo the ones you found hard.

## Habits

A habit is easier to keep when you can see it. Track the days you practise, and notice two numbers: your **current streak** (consecutive days up to today) and your **longest**. Don't chase a perfect streak: a missed day is normal; two missed days in a row is the thing to avoid. Small and regular beats large and rare.

import heapq
from next_year import TOPICS

def learning_order(topics):
    waiting = {name: set(t["after"]) for name, t in topics.items()}
    ready = [name for name, needs in waiting.items() if not needs]
    heapq.heapify(ready)
    order = []
    while ready:
        name = heapq.heappop(ready)
        order.append(name)
        for other, needs in waiting.items():
            if name in needs:
                needs.discard(name)
                if not needs:
                    heapq.heappush(ready, other)
    if len(order) != len(topics):
        raise ValueError("cycle")
    return order

from next_year import TOPICS

def finish_weeks(order, topics, hours_per_week):
    if hours_per_week <= 0:
        raise ValueError("hours_per_week must be positive")
    done, weeks = 0, {}
    for name in order:
        done += topics[name]["hours"]
        weeks[name] = -(-done // hours_per_week)
    return weeks

import re

MONTHS = "January February March April May June July August September October November December".split()

def goal_gaps(goal):
    date = re.search(r"\bby (\d{1,2}) (" + "|".join(MONTHS) + r")\b", goal)
    rest = goal[:date.start()] + goal[date.end():] if date else goal
    gaps = []
    if not re.search(r"\d", rest):
        gaps.append("a number")
    if not date:
        gaps.append("a date")
    return gaps

from next_year import PRACTISED

def streaks(days, today):
    longest = run = 0
    previous = None
    for d in days:
        run = run + 1 if previous == d - 1 else 1
        longest = max(longest, run)
        previous = d
    done = set(days)
    end = today if today in done else today - 1
    current = 0
    while end in done:
        current += 1
        end -= 1
    return current, longest

import heapq
from next_year import TOPICS

def learning_order(topics):
    waiting = {name: set(t["after"]) for name, t in topics.items()}
    ready = [name for name, needs in waiting.items() if not needs]
    heapq.heapify(ready)
    order = []
    while ready:
        name = heapq.heappop(ready)
        order.append(name)
        for other, needs in waiting.items():
            if name in needs:
                needs.discard(name)
                if not needs:
                    heapq.heappush(ready, other)
    if len(order) != len(topics):
        raise ValueError("cycle")
    return order

def finish_weeks(order, topics, hours_per_week):
    if hours_per_week <= 0:
        raise ValueError("hours_per_week must be positive")
    done, weeks = 0, {}
    for name in order:
        done += topics[name]["hours"]
        weeks[name] = -(-done // hours_per_week)
    return weeks

def review_days(learned, intervals=(1, 3, 7, 14, 30)):
    return sorted((day + gap, topic) for day, topic in learned for gap in intervals)

def year_plan(topics, hours_per_week, start_day=1):
    order = learning_order(topics)
    weeks = finish_weeks(order, topics, hours_per_week)
    total = sum(t["hours"] for t in topics.values())
    lines = ["# My next year", "", f"{hours_per_week} hours a week, {total} hours in all, about {weeks[order[-1]]} weeks.", ""]
    for n, name in enumerate(order, start=1):
        line = f"{n}. {name} ({topics[name]['hours']} hours, done in week {weeks[name]})"
        if topics[name]["after"]:
            line += " after: " + ", ".join(topics[name]["after"])
        lines.append(line)
    first = order[0]
    learned_on = start_day + 7 * (weeks[first] - 1) + 6
    reviews = [day for day, _ in review_days([(learned_on, first)])[:3]]
    lines += ["", "First reviews: " + ", ".join(f"day {d}" for d in reviews) + "."]
    return "\n".join(lines)
