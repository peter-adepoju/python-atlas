intro: "This week looked under Python at the languages it can be extended with: the C API, `ctypes` and `cffi`, Cython, Rust with PyO3, and the judgement of when any of it is worth doing. Today's Forge is the most common real task among them: taking a C library and giving it a **Pythonic wrapper**, so that the rest of a program never has to think about pointers, buffers, or C's error conventions. You'll wrap parts of the C library itself with `ctypes`, turning its functions into Python functions that raise proper exceptions, check their bounds and return Python values. The bonus binds C functions straight from their **prototypes**, the way `cffi` does."
goals:
  - Bind C functions once, with declared types, behind a small library class
  - Turn C conventions (end pointers, raw buffers, callbacks) into Python exceptions and values
  - Guard raw memory with bounds checks and expose it safely through memoryview
  - Parse C prototypes and turn them into ctypes declarations

@@solution
class Pause:
    def __await__(self):
        yield "pause"

def drive_all(coros):
    results = [None] * len(coros)
    active = list(enumerate(coros))
    switches = 0
    while active:
        still = []
        for i, coro in active:
            try:
                coro.send(None)
                switches += 1
                still.append((i, coro))
            except StopIteration as done:
                results[i] = done.value
        active = still
    return results, switches

import inspect

def signature_of(func):
    code = func.__code__
    names = list(code.co_varnames[:code.co_argcount])
    defaults = func.__defaults__ or ()
    parts = []
    first_default = len(names) - len(defaults)
    for i, name in enumerate(names):
        if i >= first_default:
            parts.append(f"{name}={defaults[i - first_default]!r}")
        else:
            parts.append(name)
    if code.co_flags & inspect.CO_VARARGS:
        parts.append("*" + code.co_varnames[code.co_argcount + code.co_kwonlyargcount])
    return f"{func.__name__}({', '.join(parts)})"

## Forge: a Pythonic wrapper

Write a small wrapper module around the C library with `ctypes`:

- **`Library(path=None)`**: loads the library (`CDLL(path)`); `bind(name, argtypes, restype)` declares a function's types once, remembers it, and returns it; afterwards `lib.name` gives the bound function, while unbound names raise `AttributeError(f"{name} has not been bound")`; `signatures()` maps each bound name, sorted, to `"(argtype names) -> restype name"` (using each ctypes type's `__name__`, and `None` for no result).
- A module-level `libc = Library()` with `strtol`, `qsort`, `memset` and `memmove` bound.
- **`parse_int(text, base=10, strict=True)`**: uses `strtol` and its end pointer; raises `ValueError(f"no digits in {text!r}")` if nothing was used, and, when `strict`, `ValueError(f"unexpected {junk!r} after number in {text!r}")` if anything other than spaces follows the number.
- **`sort_ints(values, key=None, reverse=False)`**: sorts with `qsort` and a `CFUNCTYPE` comparison callback, by `key(value)` with ties broken by the value, descending if `reverse`, returning a new list.
- **`Buffer(size)`**: owns C memory; `write(offset, data)` (with `memmove`) and `read(offset, n)` raise `IndexError` if the range doesn't fit inside the buffer; `fill(byte)` uses `memset`; `len()`; `view()` returns a writable `memoryview` of the bytes (format `"B"`).
- **`Point`**, a `Structure` of two `c_int32` fields `x` and `y`; `pack_points(pairs)` returns a C array of `Point`s, and `unpack_points(array)` the list of `(x, y)` pairs.

import ctypes

class Library:
    def __init__(self, path=None):
        self._lib = ctypes.CDLL(path)
        self._bound = {}

    def bind(self, name, argtypes, restype):
        func = getattr(self._lib, name)
        func.argtypes = list(argtypes)
        func.restype = restype
        self._bound[name] = func
        return func

    def __getattr__(self, name):
        bound = self.__dict__.get("_bound", {})
        if name in bound:
            return bound[name]
        raise AttributeError(f"{name} has not been bound")

    def signatures(self):
        out = {}
        for name, func in sorted(self._bound.items()):
            args = ", ".join(t.__name__ for t in func.argtypes)
            ret = func.restype.__name__ if func.restype is not None else "None"
            out[name] = f"({args}) -> {ret}"
        return out

libc = Library()
libc.bind("strtol", [ctypes.c_char_p, ctypes.POINTER(ctypes.c_char_p), ctypes.c_int], ctypes.c_long)
libc.bind("qsort", [ctypes.c_void_p, ctypes.c_size_t, ctypes.c_size_t, ctypes.c_void_p], None)
libc.bind("memset", [ctypes.c_void_p, ctypes.c_int, ctypes.c_size_t], ctypes.c_void_p)
libc.bind("memmove", [ctypes.c_void_p, ctypes.c_void_p, ctypes.c_size_t], ctypes.c_void_p)

def parse_int(text, base=10, strict=True):
    data = text.encode()
    end = ctypes.c_char_p()
    value = libc.strtol(data, ctypes.byref(end), base)
    rest = end.value.decode()
    if len(rest) == len(text):
        raise ValueError(f"no digits in {text!r}")
    if strict and rest.strip():
        raise ValueError(f"unexpected {rest.strip()!r} after number in {text!r}")
    return value

COMPARE = ctypes.CFUNCTYPE(ctypes.c_int, ctypes.POINTER(ctypes.c_int), ctypes.POINTER(ctypes.c_int))

def sort_ints(values, key=None, reverse=False):
    keyed = key or (lambda v: v)
    array = (ctypes.c_int * len(values))(*values)

    def compare(a, b):
        x, y = (keyed(a[0]), a[0]), (keyed(b[0]), b[0])
        result = (x > y) - (x < y)
        return -result if reverse else result

    callback = COMPARE(compare)
    if values:
        libc.qsort(ctypes.cast(array, ctypes.c_void_p), len(values), ctypes.sizeof(ctypes.c_int),
                   ctypes.cast(callback, ctypes.c_void_p))
    return list(array)

class Buffer:
    def __init__(self, size):
        self._raw = ctypes.create_string_buffer(size)
        self.size = size

    def __len__(self):
        return self.size

    def _check(self, offset, n):
        if offset < 0 or n < 0 or offset + n > self.size:
            raise IndexError(f"{n} bytes at {offset} don't fit in {self.size}")

    def write(self, offset, data):
        self._check(offset, len(data))
        libc.memmove(ctypes.addressof(self._raw) + offset, data, len(data))

    def read(self, offset, n):
        self._check(offset, n)
        return self._raw.raw[offset:offset + n]

    def fill(self, byte):
        libc.memset(ctypes.addressof(self._raw), byte, self.size)

    def view(self):
        return memoryview(self._raw).cast("B")

class Point(ctypes.Structure):
    _fields_ = [("x", ctypes.c_int32), ("y", ctypes.c_int32)]

def pack_points(points):
    return (Point * len(points))(*(Point(x, y) for x, y in points))

def unpack_points(array):
    return [(p.x, p.y) for p in array]

:::think title="What a wrapper is for"
Look at what the wrapper hides. Callers of `parse_int` never see an end pointer; they get an `int` or a `ValueError` that says what was wrong. Callers of `sort_ints` never see a function pointer type, and can't let the callback be garbage collected mid-sort, because the wrapper owns it for the duration of the call. Callers of `Buffer` can't write past the end of the memory, because every access is checked first. That's the job of every binding layer, from `ctypes` code like this to the C extensions in the standard library: take a C API that trusts its caller completely, and turn it into a Python API that checks everything and fails with exceptions. Do it in one small module, test it thoroughly, and nothing else in the program needs to know there's C underneath.
:::

A regular expression like `^\s*(.+?)\s*\b(\w+)\s*\((.*)\)\s*;\s*$` splits a prototype into return type, name and parameter list. For each parameter, the name (if any) is the last word; everything before it is the type. Normalise with `re.sub`: collapse spaces, then put exactly one space before each `*`, then join `* *` into `**`.
@@solution
import ctypes
import re

C_TYPES = {
    "int": ctypes.c_int, "long": ctypes.c_long, "size_t": ctypes.c_size_t, "double": ctypes.c_double,
    "char *": ctypes.c_char_p, "const char *": ctypes.c_char_p, "void *": ctypes.c_void_p,
    "int *": ctypes.POINTER(ctypes.c_int), "char **": ctypes.POINTER(ctypes.c_char_p), "void": None,
}

PROTO = re.compile(r"^\s*(.+?)\s*\b(\w+)\s*\((.*)\)\s*;\s*$")

def _normalise(ctype):
    ctype = re.sub(r"\s+", " ", ctype.strip())
    ctype = re.sub(r"\s*\*", " *", ctype)
    return re.sub(r"\* \*", "**", ctype)

def _param_type(param):
    param = param.strip()
    match = re.match(r"^(.*?[\s*])(\w+)$", param)
    ctype = match.group(1) if match and match.group(1).strip() else param
    return _normalise(ctype)

def parse_prototype(text):
    m = PROTO.match(text)
    if not m:
        raise ValueError(f"not a prototype: {text!r}")
    ret, name, params = m.group(1), m.group(2), m.group(3).strip()
    ret_type = _normalise(ret)
    args = [] if params in ("", "void") else [_param_type(p) for p in params.split(",")]
    for t in [ret_type] + args:
        if t not in C_TYPES:
            raise ValueError(f"unsupported type {t!r}")
    return name, ret_type, args

def bind_prototypes(declarations, library=None):
    lib = library or ctypes.CDLL(None)
    bound = {}
    for line in declarations.strip().splitlines():
        if not line.strip():
            continue
        name, ret, args = parse_prototype(line)
        func = getattr(lib, name)
        func.argtypes = [C_TYPES[a] for a in args]
        func.restype = C_TYPES[ret]
        bound[name] = func
    return bound
