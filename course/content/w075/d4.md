## Warm-up

conn = sqlite3.connect(":memory:")
conn.executescript("""
CREATE TABLE authors (id INTEGER PRIMARY KEY, name TEXT);
CREATE TABLE books (id INTEGER PRIMARY KEY, author_id INTEGER, title TEXT);
INSERT INTO authors VALUES (1, 'Austen'), (2, 'Dickens'), (3, 'Eliot');
INSERT INTO books VALUES (1, 1, 'Emma'), (2, 1, 'Persuasion'), (3, 2, 'Bleak House'), (4, 3, 'Middlemarch');
""")
sent = []
conn.set_trace_callback(sent.append)

for author_id, name in conn.execute("SELECT id, name FROM authors").fetchall():
    titles = [t for (t,) in conn.execute("SELECT title FROM books WHERE author_id = ?", (author_id,))]
    print(name, titles)
print(len(sent), "queries")
:::

One query for the authors, then **one more per author** for their books: with three authors that's four queries; with a thousand it's a thousand and one, each a trip to the database. This is the **N+1 problem**, and it's the easiest mistake to make with an ORM, because there the second query hides behind an innocent-looking `author.books`. `set_trace_callback` shows every statement a connection really sends: your best tool for catching it.

## What an ORM does

An **object-relational mapper** connects two worlds: tables, rows and foreign keys on one side; classes, objects and references on the other. It typically gives you:

- **Mapping**: a class per table, an attribute per column, an object per row. The ORM can create the tables from the classes.
- **Persistence**: `session.add(book)` and `session.commit()` write the right `INSERT` or `UPDATE`; `session.get(Book, 4)` loads one.
- **An identity map**: within a session, a row is loaded into **one** object, so two lookups of book 4 give the same Python object.
- **A unit of work**: the session tracks which objects are new, changed or deleted, and writes them all in one transaction at commit.
- **Relationships**: `book.author` and `author.books` follow foreign keys, loading related rows **lazily** (when first used) or **eagerly** (in the same query, with a join).
- **Queries in Python**: `select(Book).where(Book.year > 1850).order_by(Book.title)`, built from objects and turned into SQL with parameters.

What it costs: another layer to learn, SQL you didn't write (sometimes inefficient, as in the warm-up), and queries that are harder to see in the code. Good practice is to use the ORM for everyday work, to **look at the SQL it sends** (SQLAlchemy's `echo=True`), and to write SQL by hand for complex reports, where it's clearer.

## Classes as tables

At the heart of an ORM is a **class per table**, with a **descriptor** (Week 63) per column. A field descriptor knows its column's name and type; the base class's `__init_subclass__` collects the fields of each model class; and from those the ORM can write `CREATE TABLE`, `INSERT` and `SELECT` statements, always with parameters for the values and the class's own field names (never user input) for the identifiers.

:::example
import sqlite3

TYPES = {int: "INTEGER", str: "TEXT", float: "REAL"}

class Field:
    def __init__(self, kind, required=True):
        self.kind, self.required = kind, required
    def __set_name__(self, owner, name):
        self.name = name
    def __get__(self, obj, owner=None):
        return self if obj is None else obj.__dict__.get(self.name)
    def __set__(self, obj, value):
        if value is not None and not isinstance(value, self.kind):
            raise TypeError(f"{self.name} must be {self.kind.__name__}")
        obj.__dict__[self.name] = value

class Model:
    def __init_subclass__(cls, table, **kwargs):
        super().__init_subclass__(**kwargs)
        cls.table = table
        cls.fields = [v for v in vars(cls).values() if isinstance(v, Field)]

    def __init__(self, id=None, **values):
        self.id = id
        for f in self.fields:
            setattr(self, f.name, values.get(f.name))

    @classmethod
    def create_sql(cls):
        columns = ["id INTEGER PRIMARY KEY"] + [f"{f.name} {TYPES[f.kind]}{' NOT NULL' if f.required else ''}" for f in cls.fields]
        return f"CREATE TABLE {cls.table} ({', '.join(columns)})"

    def save(self, conn):
        names = [f.name for f in self.fields]
        values = [getattr(self, n) for n in names]
        with conn:
            if self.id is None:
                cur = conn.execute(f"INSERT INTO {self.table} ({', '.join(names)}) VALUES ({', '.join('?' * len(names))})", values)
                self.id = cur.lastrowid
            else:
                conn.execute(f"UPDATE {self.table} SET {', '.join(n + ' = ?' for n in names)} WHERE id = ?", values + [self.id])

class Book(Model, table="books"):
    title = Field(str)
    year = Field(int)
    rating = Field(float, required=False)

conn = sqlite3.connect(":memory:")
print(Book.create_sql())
conn.execute(Book.create_sql())
emma = Book(title="Emma", year=1815)
emma.save(conn)
emma.rating = 4.5
emma.save(conn)
print(emma.id, conn.execute("SELECT * FROM books").fetchall())
:::

## Sessions, identity and laziness

Real ORMs add a **session** between your objects and the connection:

- **Identity map.** The session keeps a dict from `(class, id)` to the loaded object. Loading the same row again returns the **same object**, so changes made through one reference are seen through every other, and the session knows which object to save.
- **Change tracking.** The session (or the objects themselves) records which attributes changed since loading, so it can `UPDATE` only those, and skip unchanged objects entirely.
- **Lazy loading.** `book.author` isn't loaded until it's used, and then it's one query (or none, if the identity map already has that author). That's efficient when you need related objects occasionally, and the cause of N+1 when you need them in a loop.
- **Eager loading.** When you know you'll need them, load related objects **with** the main query: a join (`joinedload` in SQLAlchemy), or one extra query for all of them at once (`selectinload`: `SELECT ... WHERE author_id IN (?, ?, ?)`). Two queries instead of N+1.

:::example
import sqlite3

conn = sqlite3.connect(":memory:")
conn.executescript("""
CREATE TABLE authors (id INTEGER PRIMARY KEY, name TEXT);
CREATE TABLE books (id INTEGER PRIMARY KEY, author_id INTEGER, title TEXT);
INSERT INTO authors VALUES (1, 'Austen'), (2, 'Dickens'), (3, 'Eliot');
INSERT INTO books VALUES (1, 1, 'Emma'), (2, 1, 'Persuasion'), (3, 2, 'Bleak House'), (4, 3, 'Middlemarch');
""")
sent = []
conn.set_trace_callback(sent.append)

authors = conn.execute("SELECT id, name FROM authors ORDER BY id").fetchall()
ids = [a[0] for a in authors]
books = {}
for author_id, title in conn.execute(f"SELECT author_id, title FROM books WHERE author_id IN ({', '.join('?' * len(ids))}) ORDER BY id", ids):
    books.setdefault(author_id, []).append(title)
for author_id, name in authors:
    print(name, books.get(author_id, []))
print(len(sent), "queries, however many authors there are")
:::

## SQLAlchemy

SQLAlchemy has two layers: **Core**, a Python way of building SQL expressions, and the **ORM** on top. In its 2.0 style, models are classes with typed attributes:

```python
from sqlalchemy import ForeignKey, String, create_engine, select
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column, relationship, selectinload

class Base(DeclarativeBase):
    pass

class Author(Base):
    __tablename__ = "authors"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    books: Mapped[list["Book"]] = relationship(back_populates="author")

class Book(Base):
    __tablename__ = "books"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]
    year: Mapped[int]
    author_id: Mapped[int] = mapped_column(ForeignKey("authors.id"))
    author: Mapped[Author] = relationship(back_populates="books")

engine = create_engine("sqlite:///library.db", echo=True)      # echo prints every SQL statement
Base.metadata.create_all(engine)

with Session(engine) as session:
    austen = Author(name="Austen", books=[Book(title="Emma", year=1815)])
    session.add(austen)
    session.commit()
    query = select(Author).options(selectinload(Author.books)).where(Author.name.like("A%"))
    for author in session.scalars(query):
        print(author.name, [b.title for b in author.books])     # no N+1: books were loaded with the authors
```

`Author.name.like("A%")` isn't a boolean: SQLAlchemy's column objects overload operators (`==`, `<`, `&`, `|`) to build **expression objects** that become SQL with parameters. Schema changes over time are handled by **Alembic**, SQLAlchemy's migration tool, which generates numbered migration scripts like yesterday's challenge.

:::key
An ORM maps classes to tables, attributes to columns and objects to rows; it saves and loads objects, keeps an identity map (one object per row in a session), tracks changes as a unit of work, follows relationships lazily or eagerly, and builds queries from Python expressions. Under the hood: descriptors for columns, class hooks to collect them, parameters for values and fixed names for identifiers. Lazy relationships in a loop cause the N+1 problem; load related rows eagerly with a join or one IN query, and watch the SQL that's sent (set_trace_callback, or echo=True). SQLAlchemy 2.0 declares models with Mapped and mapped_column, queries with select(), and migrates with Alembic.
:::

import re

TYPES = {int: "INTEGER", str: "TEXT", float: "REAL", bool: "INTEGER"}

class Field:
    def __init__(self, kind, required=True, unique=False):
        self.kind, self.required, self.unique = kind, required, unique

    def __set_name__(self, owner, name):
        if not re.fullmatch(r"[A-Za-z_][A-Za-z0-9_]*", name):
            raise ValueError(name)
        self.name = name

    def __get__(self, obj, owner=None):
        return self if obj is None else obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        if value is not None and not isinstance(value, self.kind):
            raise TypeError(f"{self.name} must be {self.kind.__name__}")
        obj.__dict__[self.name] = value

class Model:
    def __init_subclass__(cls, table=None, **kwargs):
        super().__init_subclass__(**kwargs)
        cls.table = table
        cls.fields = [v for v in vars(cls).values() if isinstance(v, Field)]

def create_sql(model):
    columns = ["id INTEGER PRIMARY KEY"]
    for f in model.fields:
        column = f"{f.name} {TYPES[f.kind]}"
        if f.required:
            column += " NOT NULL"
        if f.unique:
            column += " UNIQUE"
        columns.append(column)
    return f"CREATE TABLE {model.table} ({', '.join(columns)})"

import sqlite3

class Field:
    def __init__(self, kind):
        self.kind = kind
    def __set_name__(self, owner, name):
        self.name = name
    def __get__(self, obj, owner=None):
        return self if obj is None else obj.__dict__.get(self.name)
    def __set__(self, obj, value):
        if value is not None and not isinstance(value, self.kind):
            raise TypeError(self.name)
        obj.__dict__[self.name] = value

class Model:
    def __init_subclass__(cls, table=None, **kwargs):
        super().__init_subclass__(**kwargs)
        cls.table = table
        cls.fields = [v for v in vars(cls).values() if isinstance(v, Field)]

    def __init__(self, id=None, **values):
        self.id = id
        for f in self.fields:
            setattr(self, f.name, values.get(f.name))

    @classmethod
    def _names(cls):
        return [f.name for f in cls.fields]

    def save(self, conn):
        names = self._names()
        values = [getattr(self, n) for n in names]
        with conn:
            if self.id is None:
                sql = f"INSERT INTO {self.table} ({', '.join(names)}) VALUES ({', '.join('?' for _ in names)})"
                self.id = conn.execute(sql, values).lastrowid
            else:
                sql = f"UPDATE {self.table} SET {', '.join(n + ' = ?' for n in names)} WHERE id = ?"
                conn.execute(sql, values + [self.id])

    @classmethod
    def _from_row(cls, row):
        return cls(id=row[0], **dict(zip(cls._names(), row[1:])))

    @classmethod
    def get(cls, conn, id):
        row = conn.execute(f"SELECT id, {', '.join(cls._names())} FROM {cls.table} WHERE id = ?", (id,)).fetchone()
        return None if row is None else cls._from_row(row)

    @classmethod
    def find(cls, conn, **equals):
        names = cls._names()
        for key in equals:
            if key not in names and key != "id":
                raise ValueError(f"no field {key!r}")
        sql = f"SELECT id, {', '.join(names)} FROM {cls.table}"
        if equals:
            sql += " WHERE " + " AND ".join(f"{k} = ?" for k in equals)
        sql += " ORDER BY id"
        return [cls._from_row(r) for r in conn.execute(sql, list(equals.values()))]

    def delete(self, conn):
        with conn:
            conn.execute(f"DELETE FROM {self.table} WHERE id = ?", (self.id,))
        self.id = None

    result = {}
    rows = conn.execute("""
        SELECT a.name, b.title FROM authors a LEFT JOIN books b ON b.author_id = a.id
        ORDER BY a.id, b.id
    """).fetchall()
    for name, title in rows:
        result.setdefault(name, [])
        if title is not None:
            result[name].append(title)
    return result

import sqlite3

class Book:
    table, fields = "books", ["title", "year"]
    def __init__(self, id, title, year):
        self.id, self.title, self.year = id, title, year

class Session:
    def __init__(self, conn):
        self.conn = conn
        self.identity = {}
        self.loaded = {}

    def get(self, cls, id):
        key = (cls, id)
        if key in self.identity:
            return self.identity[key]
        row = self.conn.execute(f"SELECT {', '.join(cls.fields)} FROM {cls.table} WHERE id = ?", (id,)).fetchone()
        if row is None:
            return None
        obj = cls(id, *row)
        self.identity[key] = obj
        self.loaded[key] = dict(zip(cls.fields, row))
        return obj

    def _changes(self, key, obj):
        before = self.loaded[key]
        return {f: getattr(obj, f) for f in type(obj).fields if getattr(obj, f) != before[f]}

    def dirty(self):
        return [obj for key, obj in self.identity.items() if self._changes(key, obj)]

    def commit(self):
        with self.conn:
            for key, obj in self.identity.items():
                changes = self._changes(key, obj)
                if changes:
                    sets = ", ".join(f"{f} = ?" for f in changes)
                    self.conn.execute(f"UPDATE {type(obj).table} SET {sets} WHERE id = ?", [*changes.values(), obj.id])
                    self.loaded[key].update(changes)

class Condition:
    def __init__(self, sql, params):
        self.sql, self.params = sql, list(params)

    def __and__(self, other):
        return Condition(f"({self.sql}) AND ({other.sql})", self.params + other.params)

    def __or__(self, other):
        return Condition(f"({self.sql}) OR ({other.sql})", self.params + other.params)

class Column:
    def __init__(self, name):
        self.name = name

    def _compare(self, op, other):
        return Condition(f"{self.name} {op} ?", [other])

    def __eq__(self, other):
        return Condition(f"{self.name} IS NULL", []) if other is None else self._compare("=", other)

    def __ne__(self, other):
        return Condition(f"{self.name} IS NOT NULL", []) if other is None else self._compare("<>", other)

    def __lt__(self, other):
        return self._compare("<", other)

    def __le__(self, other):
        return self._compare("<=", other)

    def __gt__(self, other):
        return self._compare(">", other)

    def __ge__(self, other):
        return self._compare(">=", other)

    def like(self, pattern):
        return self._compare("LIKE", pattern)

class Select:
    def __init__(self, table, columns):
        self.table, self.columns = table, columns
        self.conditions, self.ordering = [], []

    def where(self, condition):
        self.conditions.append(condition)
        return self

    def order_by(self, column, descending=False):
        self.ordering.append(column.name + (" DESC" if descending else ""))
        return self

    def compile(self):
        sql = f"SELECT {', '.join(c.name for c in self.columns)} FROM {self.table}"
        params = []
        if self.conditions:
            sql += " WHERE " + " AND ".join(f"({c.sql})" for c in self.conditions)
            for c in self.conditions:
                params += c.params
        if self.ordering:
            sql += " ORDER BY " + ", ".join(self.ordering)
        return sql, params

def select(table, *columns):
    return Select(table, list(columns))

Store the conditions and ordering as tuples, and make `filter` and `order_by` return `QuerySet(..., conditions=self.conditions + new)` copies. Write one `_sql(select_part, limit=None)` method that builds the text and parameters, used by iteration (`SELECT columns`), `count` (`SELECT count(*)`) and `first`.
@@solution
import sqlite3

OPS = {"": "=", "lt": "<", "le": "<=", "gt": ">", "ge": ">=", "ne": "<>", "like": "LIKE"}

class QuerySet:
    def __init__(self, conn, table, columns, conditions=(), ordering=()):
        self.conn, self.table, self.columns = conn, table, list(columns)
        self.conditions, self.ordering = tuple(conditions), tuple(ordering)
        self._cache = None

    def _check(self, name):
        if name not in self.columns:
            raise ValueError(f"no column {name!r}")
        return name

    def filter(self, **conditions):
        new = []
        for key, value in conditions.items():
            field, _, op = key.partition("__")
            self._check(field)
            if op != "in" and op not in OPS:
                raise ValueError(f"unknown lookup {op!r}")
            new.append((field, op, value))
        return QuerySet(self.conn, self.table, self.columns, self.conditions + tuple(new), self.ordering)

    def order_by(self, *fields):
        ordering = tuple((self._check(f.lstrip("-")), f.startswith("-")) for f in fields)
        return QuerySet(self.conn, self.table, self.columns, self.conditions, self.ordering + ordering)

    def _sql(self, select_part, limit=None):
        sql, params = f"SELECT {select_part} FROM {self.table}", []
        parts = []
        for field, op, value in self.conditions:
            if op == "in":
                values = list(value)
                parts.append(f"{field} IN ({', '.join('?' for _ in values)})")
                params += values
            else:
                parts.append(f"{field} {OPS[op]} ?")
                params.append(value)
        if parts:
            sql += " WHERE " + " AND ".join(parts)
        if self.ordering and select_part != "count(*)":
            sql += " ORDER BY " + ", ".join(f + (" DESC" if desc else "") for f, desc in self.ordering)
        if limit is not None:
            sql += f" LIMIT {int(limit)}"
        return sql, params

    def _rows(self):
        if self._cache is None:
            cur = self.conn.execute(*self._sql(", ".join(self.columns)))
            self._cache = [dict(zip(self.columns, row)) for row in cur]
        return self._cache

    def __iter__(self):
        return iter(self._rows())

    def __getitem__(self, index):
        return self._rows()[index]

    def count(self):
        if self._cache is not None:
            return len(self._cache)
        return self.conn.execute(*self._sql("count(*)")).fetchone()[0]

    def first(self):
        if self._cache is not None:
            return self._cache[0] if self._cache else None
        row = self.conn.execute(*self._sql(", ".join(self.columns), limit=1)).fetchone()
        return None if row is None else dict(zip(self.columns, row))
