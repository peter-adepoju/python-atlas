## The algorithm

Breadth-first search from a start vertex s:

1. Mark s as seen and put it in a queue.
2. While the queue isn't empty: take the vertex at the front; for each neighbour not yet seen, mark it seen and add it to the back.

Two details matter:

- **Mark vertices when you add them to the queue, not when you take them out.** Otherwise a vertex reachable from several queued vertices is added several times; it's still correct, but the queue can grow far beyond V and the work far beyond O(V + E).
- **Use a `deque`** (`popleft` is O(1)); `list.pop(0)` is O(n), which makes BFS quadratic.

Each vertex enters the queue once and each edge is looked at once from each end (twice for undirected graphs), so BFS is **O(V + E)** time and O(V) extra space.

BFS finds only what's **reachable** from s. Vertices in other pieces of the graph are never seen, which is itself useful: Thursday uses it to find a graph's connected pieces.

The method is usually credited to Edward F. Moore, who described it in 1959 for finding the shortest path through a maze; C. Y. Lee published it independently in 1961 for routing wires on circuit boards.

:::example
from collections import deque

def bfs_order(adj, start):
    seen, order = {start}, []
    queue = deque([start])
    while queue:
        v = queue.popleft()
        order.append(v)
        for w in adj[v]:
            if w not in seen:
                seen.add(w)
                queue.append(w)
    return order

adj = {1: [2, 3], 2: [4], 3: [4], 4: [1], 5: [6], 6: []}
print(bfs_order(adj, 1), bfs_order(adj, 5))
:::

## Shortest paths

In an **unweighted** graph (every edge counts as 1), the order in which BFS first reaches a vertex is the order of distance: everything at distance 1 is reached before anything at distance 2, and so on. So setting `dist[w] = dist[v] + 1` when w is first seen gives the shortest distance from the start to every reachable vertex.

To get the **path** itself, record each vertex's **parent**: the vertex it was first reached from. Then walk back from the target to the start and reverse. The parent links form a tree, the **BFS tree**, holding one shortest path to every reachable vertex.

:::example
from collections import deque

def shortest_path(adj, start, goal):
    parent = {start: None}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        if v == goal:
            break
        for w in adj[v]:
            if w not in parent:
                parent[w] = v
                queue.append(w)
    if goal not in parent:
        return None
    path = []
    while goal is not None:
        path.append(goal)
        goal = parent[goal]
    return path[::-1]

flights = {"LOS": ["ACC", "LHR"], "ACC": ["NBO"], "LHR": ["NBO", "JFK"], "NBO": ["JNB"], "JFK": [], "JNB": []}
print(shortest_path(flights, "LOS", "JNB"), shortest_path(flights, "JFK", "LOS"))
:::

Stopping as soon as the goal is taken from the queue saves work when you only need one target. BFS is right **only** when every edge counts the same; with different weights (minutes, kilometres), the path with fewest edges may not be the quickest. Next week's Dijkstra's algorithm handles weights.

## Grids and puzzles

A grid is an implicit graph (Monday), so BFS works on it unchanged, with cells as vertices: it finds the shortest route through a maze in O(rows × columns). The `dist` dict doubles as the seen set.

Puzzle **states** are graphs too. Take the classic jug puzzle: a 3-litre jug and a 5-litre jug, a tap, a drain, and the task of measuring exactly 4 litres. A state is `(litres in small, litres in large)`; a move is filling a jug, emptying one, or pouring one into the other until one is empty or full. BFS from `(0, 0)` finds the fewest moves to any state with 4 litres in it.

:::example
from collections import deque

def jug_moves(state, a_size=3, b_size=5):
    a, b = state
    pour_ab = min(a, b_size - b)
    pour_ba = min(b, a_size - a)
    return {(a_size, b), (a, b_size), (0, b), (a, 0), (a - pour_ab, b + pour_ab), (a + pour_ba, b - pour_ba)} - {state}

def solve(target):
    parent = {(0, 0): None}
    queue = deque([(0, 0)])
    while queue:
        s = queue.popleft()
        if target in s:
            path = []
            while s:
                path.append(s)
                s = parent[s]
            return path[::-1]
        for t in sorted(jug_moves(s)):
            if t not in parent:
                parent[t] = s
                queue.append(t)

print(solve(4))
:::

## Many starting points

"How far is every house from its **nearest** fire station?" Running BFS from each station and taking the minimum would cost O(stations × (V + E)). Instead, start one BFS with **all** the stations in the queue at distance 0. The rings spread out from all of them together, and each house is first reached from whichever station is nearest. That's **multi-source BFS**: still O(V + E).

:::example
from collections import deque

town = ["S..#",
        "..#.",
        "...S"]

def nearest(grid):
    rows, cols = len(grid), len(grid[0])
    dist = {(r, c): 0 for r in range(rows) for c in range(cols) if grid[r][c] == "S"}
    queue = deque(dist)
    while queue:
        r, c = queue.popleft()
        for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] != "#" and (nr, nc) not in dist:
                dist[(nr, nc)] = dist[(r, c)] + 1
                queue.append((nr, nc))
    return ["".join("#" if grid[r][c] == "#" else str(dist.get((r, c), "?")) for c in range(cols)) for r in range(rows)]

print("\n".join(nearest(town)))
:::

## Two colours

Can a graph's vertices be split into two groups so that every edge goes **between** the groups, never within one? Such a graph is **bipartite**: people and the projects they work on, students and the courses they take. BFS answers it: colour the start 0, its neighbours 1, their neighbours 0, and so on; if an edge ever joins two vertices of the same colour, it's impossible. A graph is bipartite exactly when it has no cycle of odd length (a triangle can't be two-coloured).

:::example
from collections import deque

def two_colour(adj):
    colour = {}
    for s in adj:                          # every piece of the graph
        if s in colour:
            continue
        colour[s] = 0
        queue = deque([s])
        while queue:
            v = queue.popleft()
            for w in adj[v]:
                if w not in colour:
                    colour[w] = 1 - colour[v]
                    queue.append(w)
                elif colour[w] == colour[v]:
                    return None             # an edge inside one group
    return colour

square = {1: [2, 4], 2: [1, 3], 3: [2, 4], 4: [3, 1]}
triangle = {1: [2, 3], 2: [1, 3], 3: [1, 2]}
print(two_colour(square), two_colour(triangle))
:::

:::key
BFS takes vertices from the front of a deque and adds unseen neighbours to the back, marking them seen when added: O(V + E), visiting only what's reachable. In an unweighted graph, BFS reaches vertices in order of distance, so `dist[w] = dist[v] + 1` gives shortest distances, and parent links rebuild shortest paths (the BFS tree). Grids and puzzle states are graphs BFS searches unchanged. Putting many sources in the queue at distance 0 finds each vertex's nearest source in one pass. Colouring with BFS tests whether a graph is bipartite (no odd cycle). For weighted graphs, BFS isn't enough: that's Dijkstra's algorithm, next week.
:::

from collections import deque

def distances(adj, start):
    dist = {start: 0}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        for w in adj[v]:
            if w not in dist:
                dist[w] = dist[v] + 1
                queue.append(w)
    return dist

def levels(adj, start):
    dist = distances(adj, start)
    out = [[] for _ in range(max(dist.values()) + 1)]
    for v, d in dist.items():
        out[d].append(v)
    return [sorted(level) for level in out]

def farthest(adj, start):
    lv = levels(adj, start)
    return len(lv) - 1, lv[-1]

    parent = {start: None}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        if v == goal:
            break
        for w in adj[v]:
            if w not in parent:
                parent[w] = v
                queue.append(w)
    if goal not in parent:
        return None
    path = []
    while goal is not None:
        path.append(goal)
        goal = parent[goal]
    return path[::-1]

def all_shortest_counts(adj, start):
    dist, count = {start: 0}, {start: 1}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        for w in adj[v]:
            if w not in dist:
                dist[w] = dist[v] + 1
                count[w] = count[v]
                queue.append(w)
            elif dist[w] == dist[v] + 1:
                count[w] += count[v]
    return count

from collections import deque

def _search(maze):
    rows, cols = len(maze), len(maze[0])
    start = next((r, c) for r in range(rows) for c in range(cols) if maze[r][c] == "S")
    parent = {start: None}
    queue = deque([start])
    while queue:
        r, c = queue.popleft()
        if maze[r][c] == "E":
            return parent, (r, c)
        for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
            if 0 <= nr < rows and 0 <= nc < cols and maze[nr][nc] != "#" and (nr, nc) not in parent:
                parent[(nr, nc)] = (r, c)
                queue.append((nr, nc))
    return parent, None

def maze_steps(maze):
    parent, end = _search(maze)
    if end is None:
        return -1
    steps = 0
    while parent[end] is not None:
        end, steps = parent[end], steps + 1
    return steps

def maze_route(maze):
    parent, end = _search(maze)
    if end is None:
        return None
    rows = [list(row) for row in maze]
    cell = parent[end]
    while cell is not None and parent[cell] is not None:
        rows[cell[0]][cell[1]] = "*"
        cell = parent[cell]
    return ["".join(row) for row in rows]

from collections import deque

def distance_map(town):
    rows, cols = len(town), len(town[0])
    dist = [[None] * cols for _ in range(rows)]
    queue = deque()
    for r in range(rows):
        for c in range(cols):
            if town[r][c] == "H":
                dist[r][c] = 0
                queue.append((r, c))
    while queue:
        r, c = queue.popleft()
        for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
            if 0 <= nr < rows and 0 <= nc < cols and town[nr][nc] != "#" and dist[nr][nc] is None:
                dist[nr][nc] = dist[r][c] + 1
                queue.append((nr, nc))
    return dist

def worst_served(town):
    dm = distance_map(town)
    best = max((d for row in dm for d in row if d is not None), default=0)
    if best == 0:
        return 0, []
    return best, sorted((r, c) for r, row in enumerate(dm) for c, d in enumerate(row) if d == best)

from collections import deque

def two_groups(adj):
    colour = {}
    for s in adj:
        if s in colour:
            continue
        colour[s] = 0
        queue = deque([s])
        while queue:
            v = queue.popleft()
            for w in adj[v]:
                if w not in colour:
                    colour[w] = 1 - colour[v]
                    queue.append(w)
                elif colour[w] == colour[v]:
                    return None
    return sorted(v for v in colour if colour[v] == 0), sorted(v for v in colour if colour[v] == 1)

def odd_cycle_exists(adj):
    return two_groups(adj) is None

def slow(plan):
    rows, cols = len(plan), len(plan[0])
    s = next((r, c) for r in range(rows) for c in range(cols) if plan[r][c] == "S")

        d, (r, c) = heapq.heappop(heap)
        if plan[r][c] == "E":

Start with `best = {S: 0}` and `dq = deque([S])`. Pop from the front; if the cell is E, you're done. For each open neighbour, the new cost is the cell's cost plus 1 if the neighbour is a door; if it's lower than `best.get(neighbour)`, record it (and the parent), and `appendleft` for a cost of 0 or `append` for 1. from collections import deque

def _search(plan):
    rows, cols = len(plan), len(plan[0])
    start = next((r, c) for r in range(rows) for c in range(cols) if plan[r][c] == "S")
    best, parent = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        r, c = dq.popleft()
        if plan[r][c] == "E":
            return best, parent, (r, c)
        for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
            if 0 <= nr < rows and 0 <= nc < cols and plan[nr][nc] != "#":
                step = 1 if plan[nr][nc] == "D" else 0
                cost = best[(r, c)] + step
                if cost < best.get((nr, nc), float("inf")):
                    best[(nr, nc)] = cost
                    parent[(nr, nc)] = (r, c)
                    if step:
                        dq.append((nr, nc))
                    else:
                        dq.appendleft((nr, nc))
    return best, parent, None

def fewest_doors(plan):
    best, parent, end = _search(plan)
    return -1 if end is None else best[end]

def doors_on_route(plan):
    best, parent, end = _search(plan)
    if end is None:
        return None
    doors, cell = [], end
    while cell is not None:
        if plan[cell[0]][cell[1]] == "D":
            doors.append(cell)
        cell = parent[cell]
    return sorted(doors)
