Python called the tracer when `sign` started (`call`), for each line it ran (`line`), and when it finished (`return`). Line 2 of `sign`, `return -1`, never ran: a test calling `sign(5)` alone leaves it untested. That's line coverage in miniature.

## What coverage measures

**Line coverage** is the fraction of a module's statements that run while its tests run. `walkdates.py` and its test file `test_walkdates.py` are on this page: two tests, and more than half the statements never run. Coverage finds code **no test exercises**; it can't prove the tests are good (a line can run without anything checking its result, which is why Week 95's mutants matter too). Use it to find where to look, not as a score to chase. On your own computer, `coverage.py` (free) does this for real projects: `python -m coverage run -m pytest` then `python -m coverage report -m`; CPython has its own instructions in the devguide.

## Tracing

`sys.settrace(tracer)` asks Python to call `tracer(frame, event, arg)` whenever a function starts (`"call"`); whatever the tracer returns becomes the **local** tracer for that function, called for each `"line"` and for `"return"`. Return the tracer itself to keep tracing, or `None` to ignore that function. `frame.f_code.co_filename` tells you which file the code came from, so a coverage tool can record only the module it measures; `frame.f_lineno` is the line about to run. Always restore the previous tracer afterwards (a debugger may be using it).

The **statements** to count come from the syntax tree: every statement inside the module's functions, without docstrings. Compare them with the executed lines, and what's left is untested.

## Filling the gaps

For each untested line, ask which input reaches it: line 3 of `walkdates.py` (`return True` for years divisible by 400) needs 2000; line 5 needs 1900; the `ValueError` lines need a bad month or day. Then write the test so it **checks** the result, and each test for one behaviour. Coverage tells you you've reached the line; a mutant you kill tells you you've tested it.

:::key
Line coverage is the share of statements that run during the tests: it finds untested code but can't prove tests check anything. `sys.settrace` calls the tracer on `call`; its return value traces `line` and `return` events; filter by `co_filename` and restore the old tracer. Count statements from the syntax tree, subtract executed lines, and write a checking test for each gap.

import sys

def executed_lines(fn, *args):
    code, hit = fn.__code__, set()
    def tracer(frame, event, arg):
        if frame.f_code is not code:
            return None
        if event == "line":
            hit.add(frame.f_lineno - code.co_firstlineno)
        return tracer
    old = sys.gettrace()
    sys.settrace(tracer)
    try:
        fn(*args)
    finally:
        sys.settrace(old)
    return sorted(hit)

    hit = set()
    def tracer(frame, event, arg):
        if frame.f_code.co_filename != filename:
            return None
        if event == "line":
            hit.add(frame.f_lineno)
        return tracer
    old = sys.gettrace()

    finally:
        sys.settrace(old)

def missing_by_function(source, filename, action):
    namespace = {}
    exec(compile(source, filename, "exec"), namespace)
    hit = traced(filename, lambda: action(namespace))
    missing = statement_lines(source) - hit
    out = []
    for node in ast.parse(source).body:
        if isinstance(node, ast.FunctionDef):
            lines = sorted(l for l in missing if node.lineno <= l <= node.end_lineno)
            if lines:
                out.append(f"{node.name}: lines {', '.join(map(str, lines))}")
    return out

import unittest
from walkdates import days_in_month, is_leap, week_number

class TestWalkDates(unittest.TestCase):
    def test_leap_years(self):
        for year, expected in [(2024, True), (2026, False), (1900, False), (2000, True)]:
            with self.subTest(year=year):
                self.assertEqual(is_leap(year), expected)

    def test_month_lengths(self):
        for month, expected in [(1, 31), (2, 28), (4, 30), (6, 30), (9, 30), (11, 30), (12, 31)]:
            with self.subTest(month=month):
                self.assertEqual(days_in_month(2026, month), expected)
        self.assertEqual(days_in_month(2024, 2), 29)

    def test_bad_months(self):
        for month in (0, 13):
            with self.subTest(month=month), self.assertRaises(ValueError):
                days_in_month(2026, month)

    def test_weeks(self):
        self.assertEqual([week_number(d) for d in (1, 7, 8)], [1, 1, 2])
        with self.assertRaises(ValueError):
            week_number(0)

import ast
import sys
import types
import unittest

def statement_lines(source):
    lines = set()
    for node in ast.walk(ast.parse(source)):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            body = node.body
            if ast.get_docstring(node) is not None:
                body = body[1:]
            for stmt in body:
                for sub in ast.walk(stmt):
                    if isinstance(sub, ast.stmt):
                        lines.add(sub.lineno)
    return lines

def traced(filename, action):
    hit = set()
    def tracer(frame, event, arg):
        if frame.f_code.co_filename != filename:
            return None
        if event == "line":
            hit.add(frame.f_lineno)
        return tracer
    old = sys.gettrace()
    sys.settrace(tracer)
    try:
        action()
    finally:
        sys.settrace(old)
    return hit

def coverage_report(module_source, test_source, module_name="walkdates"):
    filename = f"<{module_name}>"
    module = types.ModuleType(module_name)
    saved = sys.modules.get(module_name)
    exec(compile(module_source, filename, "exec"), module.__dict__)
    sys.modules[module_name] = module
    result = unittest.TestResult()
    try:
        ns = {}
        exec(test_source, ns)
        cases = [v for v in ns.values() if isinstance(v, type) and issubclass(v, unittest.TestCase) and v is not unittest.TestCase]
        def run():
            for c in cases:
                unittest.defaultTestLoader.loadTestsFromTestCase(c).run(result)
        hit = traced(filename, run)
    finally:
        if saved is None: sys.modules.pop(module_name, None)
        else: sys.modules[module_name] = saved
    lines = statement_lines(module_source)
    missing = sorted(lines - hit)
    funcs = [(n.lineno, n.end_lineno, n.name) for n in ast.parse(module_source).body if isinstance(n, ast.FunctionDef)]
    out = [f"tests: {result.testsRun}, failing: {len(result.failures) + len(result.errors)}",
           f"covered: {len(lines) - len(missing)} of {len(lines)} lines ({round(100 * (len(lines) - len(missing)) / len(lines))}%)"]
    for start, end, name in funcs:
        m = [l for l in missing if start <= l <= end]
        if m:
            out.append(f"  {name}: lines {', '.join(map(str, m))}")
    return out
