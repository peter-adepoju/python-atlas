## Warm-up

:::predict
answer = "My greatest weakness is that I'm a perfectionist and I work too hard."
print([w for w in ("perfectionist", "work too hard", "care too much") if w in answer.lower()])
:::

Interviewers hear this answer every day, and it tells them only that the candidate prepared a dodge. A real weakness, with evidence of what you're doing about it, is far stronger, and today you'll build a check for the dodges.

## The hard questions

- **Conflict**: they want to see that you can disagree **respectfully**, understand the other view, and reach an outcome, not that you won. Describe the other person fairly ("they were worried about backports"), what you did to understand them, and what you agreed. Never blame.
- **Ambiguity**: they want to see you make progress without perfect information: what you assumed, how you checked the assumptions quickly (a prototype, a user test, a question to the right person), and how you adjusted.
- **Leading without authority**: influence by evidence and example: a measurement, a written proposal, offering to do the work.
- **Failure**: own it, say what you learned, and show the change in what you do now.

Your course has stories for all of these: the review disagreement in your first CPython pull request, the round-walk form that user testing showed was confusing, proposing to cut a feature with velocity numbers.

## Weaknesses and questions for them

**"What's your greatest weakness?"**: name a real one that won't disqualify you for the role, give a short example, and say what you're doing about it, with evidence ("I used to start coding before clarifying; since Week 97 I write the edge cases down first, and my last three mock rounds had no missed cases"). Avoid disguised strengths (perfectionism, working too hard).

**"Do you have any questions for us?"**: always have three or four, about things the website doesn't say: how the team decides what to build, what a new person's first month looks like, how code review works, what the interviewer enjoys about the work. They show interest and help you decide too.

:::key
Behind each hard question is a competency: conflict (respectful disagreement and a shared outcome), ambiguity (assumptions checked quickly), leading without authority (evidence and example), failure (ownership and change). Weakness: a real one, an example, and what you're doing, with evidence. Questions for them: three or four the website doesn't answer, about how the team works.
:::

import re

COMMON = {"where", "which", "there", "their", "about", "would", "could", "should"}

def review_questions(questions, website):
    site = website.lower()
    out = []
    for q in questions:
        words = re.findall(r"[a-z']+", q.lower())
        key = [w for w in words if len(w) >= 5 and w not in COMMON]
        if re.search(r"\b(salary|pay|holiday)\b", q.lower()):
            verdict = "later stage"
        elif key and all(w in site for w in key):
            verdict = "answered on the website"
        else:
            verdict = "good"
        out.append(f"{q}: {verdict}")
    return out

         ("leadership", ["lead", "influence", "convince"]), ("failure", ["fail", "mistake", "went wrong"]),
         ("feedback", ["feedback", "criticism"]), ("prioritising", ["priorit", "deadline", "trade-off"])]

def competency(question):
    q = question.lower()
    return next((name for name, words in RULES if any(w in q for w in words)), "general")

def conflict_problems(story):
    whole = " ".join(story.get(p, "") for p in ("situation", "task", "action", "result")).lower()
    action, result = story.get("action", "").lower(), story.get("result", "").lower()
    problems = []
    if any(w in whole for w in ("their fault", "refused to", "stupid", "wouldn't listen", "incompetent")):
        problems.append("blames the other person")
    if not any(w in action for w in ("understood", "asked why", "their concern", "their view", "they were worried")):
        problems.append("show you understood their view")
    if not any(w in result for w in ("agreed", "together", "compromise", "both")):
        problems.append("say what you agreed")
    return problems

def score_round(answers):
    lines, scores = [], []
    for question, story in answers:
        parts = [story.get(p, "") for p in ("situation", "task", "action", "result")]
        action, result = story.get("action", "").lower(), story.get("result", "").lower()
        score = all(p.strip() for p in parts)
        score += len(action.split()) >= 25
        score += len(re.findall(r"\bi\b", action)) >= len(re.findall(r"\bwe\b", action))
        score += bool(re.search(r"\d", result))
        score += bool(re.search(r"learn|now|since", result))
        kind = competency(question)
        if kind == "conflict" and conflict_problems(story):
            score = max(0, score - 1)
        scores.append(score)
        lines.append(f"{kind}: {score}/5")
    average = sum(scores) / len(scores)
    lines.append(f"average: {average:.2f}")
    verdict = "strong" if average >= 4 else "mixed" if average >= 2.5 else "weak"
    return lines, verdict
