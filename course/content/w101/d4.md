The session started well: an open question, and the learner found the cause themselves. Then the mentor took over with a leading question and a long explanation, and the learner said "Okay." That's the commonest way mentoring goes wrong, and you can see it in the numbers.

## Questions that help someone think

- **Open** questions ("what do you think happens to a month with no walks?") invite thinking, and are the mentor's main tool.
- **Closed** questions ("does it work?") get yes or no; useful for checking, not for thinking.
- **Leading** questions ("don't you think a defaultdict would be better?") are answers in disguise: the learner agrees without understanding.

When the learner is stuck, ask a smaller question rather than giving the answer. When they've found it, ask what they'd do next. Silence is fine: give them time.

## Pairing and listening

Pair with the **learner driving** (at the keyboard) and you **navigating** (thinking ahead, asking): their hands, their learning. In longer sessions swap every ten minutes or so, so they also see how you'd think. Listen for what they **don't** say: "Okay" after a long explanation usually means "I'm lost and too polite to say so". A useful rule: the learner should talk at least as much as you.

## Goals and notes

End each session with **one or two goals** for next time, small enough to finish: specific (what exactly), measurable (how you'll both know), and dated ("by Friday: the monthly summary shows every month, with a test for an empty February"). Keep short **notes**: what you talked about, what's done, what's in the way, the goals, so next week starts where this one stopped.

:::key
Ask open questions; avoid leading ones; give time. Pair with the learner at the keyboard and swap roles in longer sessions. Listen at least as much as you talk, and treat a quiet "okay" as a sign to stop explaining. Agree one or two specific, measurable, dated goals, and keep short notes from session to session.
:::

def question_kind(text):
    t = text.strip().lower()
    if any(p in t for p in LEADING):
        return "leading"
    if t.startswith(OPEN):
        return "open"
    if t.endswith("?"):
        return "closed"

@@tests

    "listen more than you talk"
    assert talk_share(open("session.txt").read()) == {"Mentor": 70, "Learner": 30, "longest": "Mentor (60 words)"}
    assert talk_share("A: one two\nB: three\n") == {"A": 67, "B": 33, "longest": "A (2 words)"}
@@solution
def talk_share(transcript):
    words, longest = {}, ("", 0)
    for line in transcript.splitlines():
        if ":" not in line:
            continue
        speaker, said = line.split(":", 1)
        n = len(said.split())
        words[speaker] = words.get(speaker, 0) + n
        if n > longest[1]:
            longest = (speaker, n)
    total = sum(words.values())
    share = {s: round(100 * n / total) for s, n in words.items()}
    share["longest"] = f"{longest[0]} ({longest[1]} words)"
    return share

    "their hands first"
    assert pairing_plan("Sam", "Ada", 35) == ["0-10: Sam drives, Ada navigates", "10-20: Ada drives, Sam navigates",
                                              "20-30: Sam drives, Ada navigates", "30-35: Ada drives, Sam navigates"]

@@solution
def pairing_plan(learner, mentor, minutes, turn=10):
    lines, start, people = [], 0, [learner, mentor]
    while start < minutes:
        end = min(minutes, start + turn)
        driver, navigator = people[(start // turn) % 2], people[(start // turn + 1) % 2]
        lines.append(f"{start}-{end}: {driver} drives, {navigator} navigates")
        start = end
    return lines

def session_notes(date, topics, done, blockers, goals):
    lines = [f"## Session {date}", "", f"Talked about: {', '.join(topics)}.",
             f"Done: {'; '.join(done)}." if done else "Done: nothing yet.",
             f"In the way: {'; '.join(blockers)}." if blockers else "In the way: nothing.", "", "Goals:"]
    lines += [f"- {g}" for g in goals]
    return "\n".join(lines)

import re

def talk_share(transcript):
    words = {}
    for line in transcript.splitlines():
        if ":" in line:
            speaker, said = line.split(":", 1)
            words[speaker] = words.get(speaker, 0) + len(said.split())
    total = sum(words.values()) or 1
    return {s: round(100 * n / total) for s, n in words.items()}

def goal_problems(goal):
    g = goal.lower()
    words = re.findall(r"[a-z0-9']+", g)
    problems = []
    if len(words) < 6:
        problems.append("say exactly what")
    if not re.search(r"\d", g) and not set(words) & {"test", "tests", "passes", "shows", "prints"}:
        problems.append("say how you'll know")
    if not re.search(r"\bby \w+", g):
        problems.append("give a date")
    return problems

def mentoring_review(sessions):
    possible = sum(len(s["goals"]) for s in sessions[:-1])
    met = sum(s["met"] for s in sessions[1:])
    goals_line = f"goals met: {met} of {possible} ({round(100 * met / possible)}%)" if possible else "goals met: - of 0"
    seen, order = {}, []
    for s in sessions:
        for b in {b.lower(): b for b in s["blockers"]}.items():
            key, text = b
            if key not in seen:
                seen[key] = [text, 0]
                order.append(key)
            seen[key][1] += 1
    recurring = [seen[k][0] for k in order if seen[k][1] >= 2]
    first, last = talk_share(sessions[0]["transcript"]).get("Mentor", 0), talk_share(sessions[-1]["transcript"]).get("Mentor", 0)
    rewrite = sum(1 for s in sessions for g in s["goals"] if goal_problems(g))
    return [f"sessions: {len(sessions)}", goals_line, "recurring blockers: " + (", ".join(recurring) if recurring else "none"),
            f"mentor talk: {first}% to {last}%", f"goals to rewrite: {rewrite}",
            "advice: listen more" if last > 50 else "advice: keep going"]
