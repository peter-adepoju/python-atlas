## Warm-up

:::predict
from itertools import accumulate

nums = [3, 4, 7, 2, -3, 1, 4, 2]
print(list(accumulate(nums)))
:::

Any stretch `nums[i:j]` sums to `prefix[j] - prefix[i]`. So "how many stretches add up to 7?" becomes "how many earlier prefix sums equal the current one minus 7?", which a dictionary of counts answers in one pass.

## Five more patterns

- **Prefix sums**: totals of stretches from differences of running totals; with a dictionary of counts, "how many subarrays sum to k" is O(n).
- **Monotonic stack**: keep indices whose values are still waiting for something larger (or smaller); each new value pops the ones it answers. "Days until a warmer day" in O(n).
- **Union-find** (disjoint sets): `find` a group's representative with **path compression**, `union` two groups by size; nearly O(1) per operation. Counting connected parts of a network as links arrive.
- **Matrices in place**: a 90° clockwise rotation is a **transpose** then reversing each row.
- **Grouping by a key**: anagrams share their sorted letters; a dictionary from key to list does the rest.

@@hint
Keep a stack of indices still waiting; while today is warmer than the day on top, pop it and record the gap.
@@solution
def days_until_warmer(temps):
    answer, waiting = [0] * len(temps), []
    for i, t in enumerate(temps):
        while waiting and temps[waiting[-1]] < t:
            j = waiting.pop()
            answer[j] = i - j
        waiting.append(i)
    return answer

@@tests
import random, time

def test_groups():
    "union-find"
    assert groups_after_each(5, [(0, 1), (1, 2), (3, 4), (0, 2), (2, 3)]) == [4, 3, 2, 2, 1]
    assert groups_after_each(3, []) == [] and groups_after_each(2, [(0, 0)]) == [2]

def test_fast():
    "200,000 links"
    rng = random.Random(2)
    n = 100_000
    links = [(rng.randrange(n), rng.randrange(n)) for _ in range(200_000)]
    start = time.perf_counter()
    result = groups_after_each(n, links)
    assert len(result) == 200_000 and result[-1] < 20_000 and time.perf_counter() - start < 3
@@hint
`parent = list(range(n))`. `find(x)` follows parents to the root, pointing nodes closer to it on the way; a union of two different roots reduces the count by one.
@@solution
def groups_after_each(n, links):
    parent, size = list(range(n)), [1] * n
    count, out = n, []

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for a, b in links:
        ra, rb = find(a), find(b)
        if ra != rb:
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
            count -= 1
        out.append(count)
    return out
:::

@@solution
def rotate(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()

:::exercise id=challenge points=25 title="Challenge: a running median"
Write a class `RunningMedian` with `add(x)` and `median()`: the median of all numbers added so far (the middle one, or the mean of the two middle ones as a float), each operation O(log n). Use two heaps.
@@starter
import heapq

class RunningMedian:
    ___
@@tests
import random, statistics, time

def test_median():
    "two heaps"
    m = RunningMedian()
    out = []
    for x in [5, 15, 1, 3, 8]:
        m.add(x)
        out.append(m.median())
    assert out == [5, 10.0, 5, 4.0, 5]

def test_random():
    "matches statistics.median"
    rng = random.Random(6)
    m, values = RunningMedian(), []
    for _ in range(500):
        x = rng.randint(-100, 100)
        m.add(x)
        values.append(x)
        assert m.median() == statistics.median(values)

def test_fast():
    "100,000 numbers"
    m = RunningMedian()
    start = time.perf_counter()
    for i in range(100_000):
        m.add((i * 7919) % 100_003)
        m.median()
    assert time.perf_counter() - start < 3
@@hint
`low` is a max-heap (store negatives) of the smaller half, `high` a min-heap of the larger half. Push to `low`, move its largest to `high`, and if `high` gets bigger move its smallest back. The median is `-low[0]`, or the mean of `-low[0]` and `high[0]`.
@@solution
import heapq

class RunningMedian:
    def __init__(self):
        self.low, self.high = [], []

    def add(self, x):
        heapq.heappush(self.low, -x)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def median(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2
:::
