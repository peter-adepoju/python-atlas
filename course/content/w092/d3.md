## Warm-up

:::predict

:::

`2.3` isn't exactly 2.3 in binary, so `seconds % 1` is a hair under 0.3 and `int` cuts it to 299 milliseconds. Caption times are written to the millisecond, so they need rounding, not cutting.

## Planning the demo

Two to three minutes is enough. Structure it like the write-up, but shown:

1. **The problem**, in one sentence and one picture: a walker surprised by a climb.
2. **Three tasks**, the ones users tested on Day 5 (plan a walk, find a round walk, share it), each done for real, at normal speed, with real data.
3. **A close**: what it is, that it's free, and where to find it.

Write the narration as a **script** first, one scene per task, with a time budget for each. Prepare the screen: a clean browser profile or terminal, large text (zoom to 150%), notifications off, sample data loaded, nothing private visible.

## Timing the script

People speak about **150 words a minute** when explaining something clearly. So a scene's length can be estimated before recording: words divided by 150, times 60 seconds. A 63-word scene takes about 25 seconds; if its budget is 20, cut words now rather than talking faster later.

## Captions

**SRT** is the simplest caption format, accepted almost everywhere. Each caption is a block: its number, a time range, and one or two lines of text, with a blank line between blocks:

```
1
00:00:00,000 --> 00:00:03,500
Waymark plans walks with honest times,

2
00:00:03,500 --> 00:00:06,000
counting the climbing as well as the distance.
```

Times are `HH:MM:SS,mmm`, with a **comma** before the milliseconds. Common guidelines (the BBC's subtitle guidelines are a good free reference) say: at most two lines, about **42 characters** a line, on screen for at least a second, no overlaps, and no more than about **17 characters a second** of reading.

## Chapters and recording

Video sites turn lines like `0:00 Intro` in a description into **chapters**. YouTube's rules: the first must start at `0:00`, there must be at least three, and each must be at least 10 seconds long. Generate them from the script's timings, then adjust after recording.

Record with a free tool such as OBS Studio, in short takes (one per scene) so a mistake costs one scene; then cut, add the captions file, and watch it once with the sound off.

def srt_time(seconds):
    ms = round(seconds * 1000)
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"

def to_srt(captions):
    blocks = [f"{n}\n{srt_time(start)} --> {srt_time(end)}\n{text}" for n, (start, end, text) in enumerate(captions, start=1)]
    return "\n\n".join(blocks) + "\n"

import re

def _seconds(stamp):
    h, m, s, ms = map(int, re.fullmatch(r"(\d+):(\d+):(\d+),(\d+)", stamp.strip()).groups())
    return h * 3600 + m * 60 + s + ms / 1000

def parse_srt(text):
    captions = []
    for block in re.split(r"\n\s*\n", text.strip()):
        lines = block.strip().splitlines()
        if len(lines) < 2:
            continue
        start, end = lines[1].split("-->")
        captions.append((_seconds(start), _seconds(end), "\n".join(lines[2:])))
    return captions

def script_timing(scenes, wpm=150):
    lines, total = [], 0.0
    for name, narration, budget in scenes:
        secs = round(len(narration.split()) / wpm * 60, 1)
        total += secs
        line = f"{name}: {secs:g} s"
        if secs > budget:
            line += f" (over by {secs - budget:.1f} s)"
        lines.append(line)
    lines.append(f"total: {round(total, 1):g} s")
    return lines

def _clock(seconds):
    seconds = int(seconds)
    h, rest = divmod(seconds, 3600)
    m, s = divmod(rest, 60)
    return f"{h}:{m:02d}:{s:02d}" if h else f"{m}:{s:02d}"

def chapters(items):
    if len(items) < 3:
        raise ValueError("need at least 3 chapters")
    if items[0][1] != 0:
        raise ValueError("first chapter must start at 0:00")
    for (title, start), (_, following) in zip(items, items[1:]):
        if following - start < 10:
            raise ValueError(f"chapter {title} is shorter than 10 s")
    return [f"{_clock(start)} {title}" for title, start in items]

def caption_problems(captions):
    problems, previous_end = [], None
    for n, (start, end, text) in enumerate(captions, start=1):
        if previous_end is not None and start < previous_end:
            problems.append(f"{n}: overlaps the previous caption")
        duration = end - start
        if duration < 1:
            problems.append(f"{n}: shorter than 1 s")
        if any(len(line) > 42 for line in text.split("\n")):
            problems.append(f"{n}: line over 42 characters")
        chars = len(text.replace("\n", ""))
        if duration > 0 and chars / duration > 17:
            problems.append(f"{n}: too fast ({chars / duration:.1f} characters a second)")
        previous_end = end
    return problems

def _clock(seconds):
    seconds = int(seconds)
    h, rest = divmod(seconds, 3600)
    m, s = divmod(rest, 60)
    return f"{h}:{m:02d}:{s:02d}" if h else f"{m}:{s:02d}"

def _caption_problems(captions):
    problems, previous_end = [], None
    for n, (start, end, text) in enumerate(captions, start=1):
        if previous_end is not None and start < previous_end:
            problems.append(f"{n}: overlaps the previous caption")
        duration = end - start
        if duration < 1:
            problems.append(f"{n}: shorter than 1 s")
        if any(len(line) > 42 for line in text.split("\n")):
            problems.append(f"{n}: line over 42 characters")
        chars = len(text.replace("\n", ""))
        if duration > 0 and chars / duration > 17:
            problems.append(f"{n}: too fast ({chars / duration:.1f} characters a second)")
        previous_end = end
    return problems

def demo_plan(scenes, captions, limit=180, wpm=150):
    lines, failing, chapter_lines, start = [], [], [], 0.0
    for name, narration, budget in scenes:
        secs = round(len(narration.split()) / wpm * 60, 1)
        line = f"{name}: {secs:g} s"
        if secs > budget:
            line += f" (over by {secs - budget:.1f} s)"
            if "scenes" not in failing:
                failing.append("scenes")
        lines.append(line)
        chapter_lines.append(f"  {_clock(start)} {name}")
        start += secs
    total = round(start, 1)
    lines.append(f"total: {total:g} s of {limit} s" + (" (over)" if total > limit else ""))
    if total > limit:
        failing.append("length")
    problems = _caption_problems(captions)
    lines.append("captions: ok" if not problems else f"captions: {len(problems)} problems")
    lines += [f"  {p}" for p in problems]
    if problems:
        failing.append("captions")
    lines += ["chapters:"] + chapter_lines
    return lines, "ready to record" if not failing else "fix: " + ", ".join(failing)
