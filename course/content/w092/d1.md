As text, `"v0.9.0"` comes after `"v0.10.0"`, because `9` comes after `1`. Version numbers are tuples of numbers, and every tool that compares them has to treat them that way.

## Version numbers

**Semantic versioning** (semver.org, by Tom Preston-Werner) writes versions as `MAJOR.MINOR.PATCH` and gives each part a meaning:

- **PATCH** (1.0.0 to 1.0.1): bug fixes only; nothing anyone relies on changes.
- **MINOR** (1.0.1 to 1.1.0): new features that don't break anything; PATCH goes back to 0.
- **MAJOR** (1.1.0 to 2.0.0): something that worked before may not now (a renamed option, a removed API route); MINOR and PATCH go back to 0.

Before `1.0.0`, anything may change, and many projects bump the MINOR for breaking changes. Releasing `1.0.0` is a promise: from now on, a breaking change means a new MAJOR. Waymark's first public release is `1.0.0`.

## Commits that write the notes

If commit messages follow a pattern, the next version and the release notes can be worked out from them. **Conventional Commits** (conventionalcommits.org) starts each message with a type, an optional scope and a description:

- `feat(share): open a shared route as GeoJSON`: a new feature, so a MINOR release;
- `fix: round walks ignored the target time`: a fix, so a PATCH;
- `feat(api)!: rename /plan to /v1/routes`, or a body line `BREAKING CHANGE: ...`: a MAJOR;
- `docs:`, `test:`, `refactor:`, `ci:`, `chore:`: no release on their own.

Release notes are for users: group the entries under **Breaking**, **Added** and **Fixed**, in their words, and put them in `CHANGELOG.md` under the version and date (Week 90's changelog, now per release).

## The package

`pyproject.toml` (PEP 621) describes the package: its `name` (unique on the Python Package Index), `version`, a one-line `description`, the `readme`, `requires-python`, the `license`, its `dependencies` (with lower bounds, so an install doesn't pick a version that's too old), and `[project.scripts]`, which makes `waymark` a command when the package is installed. `[build-system]` says what builds it.

On your own computer, `python -m build` makes two files in `dist/`: a **source distribution** (`waymark_walks-1.0.0.tar.gz`) and a **wheel** (`waymark_walks-1.0.0-py3-none-any.whl`), with the name normalised to lower case and underscores. `twine upload --repository testpypi dist/*` publishes to TestPyPI first, so you can try `pip install` from there before the real thing. Both are free.

## Tags and checksums

Tag the commit that was released, `git tag -a v1.0.0 -m "Waymark 1.0.0"`, and push the tag; the tag, the version in `pyproject.toml` and the changelog heading must agree. Then publish a `SHA256SUMS` file: one line per file, the SHA-256 digest, two spaces and the file name (the format `sha256sum` writes and `sha256sum -c` checks). Anyone can then check that what they downloaded is what you built.

import re

VERSION = re.compile(r"v?(0|[1-9]\d*)\.(0|[1-9]\d*)\.(0|[1-9]\d*)")

def parse_version(text):
    match = VERSION.fullmatch(text)
    if not match:
        raise ValueError(f"not a version: {text}")
    return tuple(int(part) for part in match.groups())

def bump(version, part):
    major, minor, patch = parse_version(version)
    if part == "major":
        return f"{major + 1}.0.0"
    if part == "minor":
        return f"{major}.{minor + 1}.0"
    if part == "patch":
        return f"{major}.{minor}.{patch + 1}"
    raise ValueError(f"unknown part: {part}")

import re

HEADER = re.compile(r"(\w+)(\([\w-]+\))?(!)?: .+")

def _bump(version, part):
    major, minor, patch = (int(p) for p in version.lstrip("v").split("."))
    if part == "major":
        return f"{major + 1}.0.0"
    if part == "minor":
        return f"{major}.{minor + 1}.0"
    return f"{major}.{minor}.{patch + 1}"

def next_version(current, commits):
    level = 0
    for message in commits:
        lines = message.splitlines()
        match = HEADER.fullmatch(lines[0]) if lines else None
        if match and match.group(3) or any(line.startswith("BREAKING CHANGE:") for line in lines):
            level = max(level, 3)
        elif match and match.group(1) == "feat":
            level = max(level, 2)
        elif match and match.group(1) in ("fix", "perf"):
            level = max(level, 1)
    if level == 0:
        return None
    if level == 3 and current.lstrip("v").startswith("0."):
        level = 2
    return _bump(current, {1: "patch", 2: "minor", 3: "major"}[level])

import re

HEADER = re.compile(r"(\w+)(?:\(([\w-]+)\))?(!)?: (.+)")

def release_notes(version, date, commits):
    sections = {"Breaking": [], "Added": [], "Fixed": []}
    for message in commits:
        lines = message.splitlines()
        match = HEADER.fullmatch(lines[0]) if lines else None
        if not match:
            continue
        kind, scope, bang, description = match.groups()
        entry = f"- {description}" + (f" ({scope})" if scope else "")
        if bang or any(line.startswith("BREAKING CHANGE:") for line in lines):
            sections["Breaking"].append(entry)
        elif kind == "feat":
            sections["Added"].append(entry)
        elif kind in ("fix", "perf"):
            sections["Fixed"].append(entry)
    out = [f"## [{version}] - {date}"]
    for name, entries in sections.items():
        if entries:
            out += ["", f"### {name}"] + entries
    return "\n".join(out)

import re
import tomllib

KEYS = ["name", "version", "description", "readme", "requires-python", "license"]

def pyproject_problems(text):
    try:
        data = tomllib.loads(text)
    except tomllib.TOMLDecodeError:
        return ["not valid TOML"]
    project = data.get("project")
    if project is None:
        return ["no [project] table"]
    problems = [f"missing project.{key}" for key in KEYS if key not in project]
    version = project.get("version")
    if version is not None and not re.fullmatch(r"\d+\.\d+\.\d+", version):
        problems.append(f"version {version} is not MAJOR.MINOR.PATCH")
    if not project.get("scripts"):
        problems.append("no command in [project.scripts]")
    for dep in project.get("dependencies", []):
        if not any(c in dep for c in "<>=!~"):
            problems.append(f"unbounded dependency {dep}")
    if "build-system" not in data:
        problems.append("no [build-system]")
    return problems

import hashlib

def checksums(files):
    return "".join(f"{hashlib.sha256(files[name]).hexdigest()}  {name}\n" for name in sorted(files))

def verify(text, files):
    problems = []
    for line in text.splitlines():
        if not line.strip():
            continue
        digest, name = line.split("  ", 1)
        if name not in files:
            problems.append(f"{name}: missing")
        elif hashlib.sha256(files[name]).hexdigest() != digest:
            problems.append(f"{name}: checksum mismatch")
    return problems

import hashlib
import re
import tomllib

KEYS = ["name", "version", "description", "readme", "requires-python", "license"]

def _pyproject_problems(data):
    project = data.get("project")
    if project is None:
        return ["no [project] table"]
    problems = [f"missing project.{key}" for key in KEYS if key not in project]
    version = project.get("version")
    if version is not None and not re.fullmatch(r"\d+\.\d+\.\d+", version):
        problems.append(f"version {version} is not MAJOR.MINOR.PATCH")
    if not project.get("scripts"):
        problems.append("no command in [project.scripts]")
    problems += [f"unbounded dependency {d}" for d in project.get("dependencies", []) if not any(c in d for c in "<>=!~")]
    if "build-system" not in data:
        problems.append("no [build-system]")
    return problems

def release_check(pyproject_text, changelog, tag, dist):
    data = tomllib.loads(pyproject_text)
    project = data.get("project", {})
    version, name = project.get("version", "?"), project.get("name", "?")
    results = {}
    problems = _pyproject_problems(data)
    results["pyproject"] = "; ".join(problems) if problems else "ok"
    results["tag"] = "ok" if tag == f"v{version}" else f"{tag} doesn't match version {version}"
    has_entry = any(line.startswith(f"## [{version}]") for line in changelog.splitlines())
    results["changelog"] = "ok" if has_entry else f"no entry for {version}"
    base = re.sub(r"[-.]", "_", name.lower())
    wanted = [f"{base}-{version}.tar.gz", f"{base}-{version}-py3-none-any.whl"]
    missing = [w for w in wanted if w not in dist]
    results["dist"] = "ok" if not missing else "missing " + ", ".join(missing)
    if "SHA256SUMS" not in dist:
        results["checksums"] = "no SHA256SUMS"
    else:
        listed, found = set(), []
        for line in dist["SHA256SUMS"].decode().splitlines():
            if not line.strip():
                continue
            digest, file = line.split("  ", 1)
            listed.add(file)
            if file not in dist:
                found.append(f"{file}: missing")
            elif hashlib.sha256(dist[file]).hexdigest() != digest:
                found.append(f"{file}: checksum mismatch")
        unlisted = [f"{f} not listed" for f in sorted(dist) if f != "SHA256SUMS" and f not in listed]
        problems = unlisted + found
        results["checksums"] = "; ".join(problems) if problems else "ok"
    lines = [f"{check}: {result}" for check, result in results.items()]
    failing = [check for check, result in results.items() if result != "ok"]
    return lines, "RELEASE" if not failing else "STOP: " + ", ".join(failing)
