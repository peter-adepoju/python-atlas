## Endless sources

- `count(start=0, step=1)`: start, start + step, ... for ever (floats and negative steps work).
- `cycle(iterable)`: the items over and over (it keeps a copy of the first pass).
- `repeat(item, times=None)`: the same item for ever, or `times` times.

Pair an endless source with something that stops: `zip` against a finite iterable, `islice`, `takewhile`, or a `break`. `zip(count(1), names)` numbers names without `enumerate`; `zip(cycle(["red", "blue"]), rows)` alternates colours.

:::example
from itertools import count, cycle, repeat, islice

print(list(zip(count(1), ["ada", "ben", "cy"])))
print(list(zip(cycle(["red", "blue"]), range(5))))
print(list(repeat("-", 3)), list(map(pow, range(5), repeat(2))))
:::

## Slicing and selecting

| Function | Yields |
|---|---|
| `islice(it, stop)` / `islice(it, start, stop, step)` | a slice of any iterator (no negative indexes) |
| `takewhile(pred, it)` | items while pred is True; stops at the first False |
| `dropwhile(pred, it)` | skips items while pred is True, then yields everything after |
| `filterfalse(pred, it)` | the items where pred is False (the opposite of `filter`) |
| `compress(data, selectors)` | the items of data whose selector is truthy |

`takewhile` and `dropwhile` look only at the **start**: once the condition fails, they stop checking. For "skip the header lines, then process the rest", `dropwhile` is exactly right.

:::example
from itertools import islice, takewhile, dropwhile, filterfalse, compress

lines = ["# title", "# author", "data 1", "# note", "data 2"]
print(list(dropwhile(lambda l: l.startswith("#"), lines)))
print(list(takewhile(lambda x: x < 10, [1, 4, 9, 16, 2])))
print(list(filterfalse(str.isdigit, "a1b2c3")), list(compress("abcdef", [1, 0, 1, 0, 0, 1])))
print(list(islice("abcdefgh", 2, 7, 2)))
:::

## Combining

- `chain(a, b, ...)` and `chain.from_iterable(iterable_of_iterables)`: one stream after another; the second flattens one level, lazily.
- `zip_longest(a, b, fillvalue=None)`: like `zip`, but continues to the end of the **longest**, filling gaps. (`zip` stops at the shortest, silently; since Python 3.10, `zip(a, b, strict=True)` raises if the lengths differ.)
- `pairwise(it)`: each item with the next, `(a, b), (b, c), ...` (3.10).
- `batched(it, n)`: tuples of n items, the last possibly shorter (3.12), the same job as Monday's `Chunks`.
- `product(a, b, ...)`: every combination of one item from each, like nested loops; `product(range(6), repeat=2)` is two dice.

:::example
from itertools import chain, zip_longest, pairwise, batched, product

print(list(chain("ab", [1, 2])), list(chain.from_iterable([[1, 2], [], [3]])))
print(list(zip_longest("abc", "12", fillvalue="?")), list(zip("abc", "12")))
print([b - a for a, b in pairwise([3, 7, 8, 12])], list(batched("abcdefg", 3)))
print(list(product("xy", [0, 1])))
:::

## Grouping

`groupby(iterable, key=None)` yields `(key, group)` pairs for each run of **neighbouring** items with the same key. It's run-length grouping, not SQL's GROUP BY: equal keys that aren't next to each other form separate groups, so **sort by the same key first** if you want one group per key. Each group is itself an iterator that shares the underlying stream: use (or copy) it **before** moving to the next group, because advancing `groupby` discards it.

:::example
from itertools import groupby

text = "aaabccdddd"
print("".join(f"{k}{len(list(g))}" for k, g in groupby(text)))

words = ["apple", "bean", "avocado", "beet", "cherry"]
print([(k, list(g)) for k, g in groupby(words, key=lambda w: w[0])])            # a, b, a, b, c: separate runs
print([(k, list(g)) for k, g in groupby(sorted(words), key=lambda w: w[0])])    # sorted first: one group each
:::

## Accumulating and combinatorics

`accumulate(iterable, func=operator.add, initial=None)` yields running results: totals, products, running maxima, balances. `initial` puts a starting value in front.

The combinatoric four, all lazy and all in a fixed order (lexicographic by position):

| | Order matters | Order doesn't |
|---|---|---|
| no repeats | `permutations(it, r)` | `combinations(it, r)` |
| repeats allowed | `product(it, repeat=r)` | `combinations_with_replacement(it, r)` |

Their sizes are Week 55's formulas: n!/(n − r)!, C(n, r), nʳ and C(n + r − 1, r).

`tee(it, n)` splits one iterator into n independent ones, but it must **store** every item that one copy has seen and another hasn't. If one copy runs far ahead, that's the whole stream in memory: when you can, use a list instead, or restructure so one pass does both jobs.

:::example
from itertools import accumulate, permutations, combinations, combinations_with_replacement
import operator

print(list(accumulate([100, -30, -50, 20], initial=0)), list(accumulate([1, 2, 3, 4], operator.mul)))
print(len(list(permutations(range(5), 2))), len(list(combinations(range(5), 2))), list(combinations_with_replacement("ab", 2)))
:::

The "recipes" section at the end of the `itertools` documentation shows how to build more tools from these pieces; the challenge uses some of them, and they're well worth reading.

:::key
itertools gives lazy, C-speed stages. count, cycle and repeat are endless sources: bound them with zip, islice or takewhile. islice slices any iterator; takewhile and dropwhile act on the start of a stream; filterfalse and compress select. chain joins streams, zip_longest pads instead of truncating, pairwise gives neighbours, batched gives fixed-size groups, product gives nested-loop combinations. groupby groups neighbouring equal keys only, so sort first, and use each group before moving on. accumulate gives running results; permutations, combinations, product and combinations_with_replacement cover the four counting cases. tee stores whatever one copy is ahead by, so prefer a list when copies drift apart.
:::

def longest_run(items):
    best = None
    for k, g in groupby(items):
        n = len(list(g))
        if best is None or n > best[1]:
            best = (k, n)
    return best

def by_length(words):
    return {k: list(g) for k, g in groupby(sorted(words, key=lambda w: (len(w), w)), key=len)}

def codes(digits, length):
    return sum(1 for _ in product(digits, repeat=length))

def scoops(flavours, k):

For `roundrobin`: `nexts = cycle(iter(it).__next__ for it in iterables)` and a count of how many are still active; call each in turn, and on `StopIteration` decrease the count and rebuild `nexts = cycle(islice(nexts, active))`, which drops the one just used up.
@@solution
from itertools import islice, cycle, tee, filterfalse
from collections import deque

def unique_everseen(iterable, key=None):
    seen = set()
    for item in iterable:
        k = item if key is None else key(item)
        if k not in seen:
            seen.add(k)
            yield item

def sliding_window(iterable, n):
    it = iter(iterable)
    window = deque(islice(it, n - 1), maxlen=n)
    for x in it:
        window.append(x)
        yield tuple(window)

def roundrobin(*iterables):
    active = len(iterables)
    nexts = cycle(iter(it).__next__ for it in iterables)
    while active:
        try:
            for nxt in nexts:
                yield nxt()
        except StopIteration:
            active -= 1
            nexts = cycle(islice(nexts, active))

def partition(pred, iterable):
    a, b = tee(iterable)
    return filterfalse(pred, a), filter(pred, b)

def nth(iterable, n, default=None):
    return next(islice(iterable, n, None), default)
