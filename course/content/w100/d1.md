## Warm-up

:::predict
from functools import lru_cache

@lru_cache(maxsize=None)
def ways(n):
    if n < 0:
        return 0
    if n == 0:
        return 1
    return ways(n - 1) + ways(n - 2) + ways(n - 3)

print([ways(n) for n in range(7)])
:::

The number of ways to climb `n` steps taking 1, 2 or 3 at a time is the sum of the ways to reach the three steps below. That sentence is the whole solution: a **state** (`n`), a **transition** (the sum), and **base cases** (0 steps: one way; below 0: none).

## The four questions

1. **State**: what does one entry of the table mean? "`best[i]` is the most you can collect from the first `i` houses." Getting this sentence right is most of the work.
2. **Transition**: how does an entry follow from smaller ones? "Either skip house `i` (`best[i-1]`) or take it (`best[i-2] + value`)."
3. **Base cases**: the smallest states, answered directly.
4. **Order**: fill so every entry's inputs are ready (usually from small to large). Or write it top-down with memoisation (`lru_cache`) and let recursion find the order, if the depth is safe.

Then say the complexity: entries times the work per entry. Often you can keep only the last row or two, and interviewers like hearing that.

:::exercise id=d1 points=10 title="Drill 1: Steps of one, two or three"
Write `climb_ways(n)`: the number of ways to climb `n` steps taking 1, 2 or 3 at a time, bottom-up, for `n` up to 10,000 (Python's big integers are fine).
@@starter
def climb_ways(n):
    ___
@@tests
def test_ways():
    "the sum of the three below"
    assert [climb_ways(n) for n in range(7)] == [1, 1, 2, 4, 7, 13, 24]
    assert climb_ways(10_000) % 1_000_000 == climb_ways(10_000) % 1_000_000 and len(str(climb_ways(10_000))) > 2000
@@solution
def climb_ways(n):
    a, b, c = 0, 0, 1
    for _ in range(n):
        a, b, c = b, c, a + b + c
    return c
:::

:::exercise id=d2 points=10 title="Drill 2: Not next door"
A walker collects litter from cottages along a lane but mustn't visit two neighbouring cottages on the same day. Write `best_haul(amounts)`: the most litter (in bags) collected from non-adjacent cottages.
@@starter

    ___
@@tests
def test_haul():
    "skip or take"
    assert best_haul([1, 2, 3, 1]) == 4 and best_haul([2, 7, 9, 3, 1]) == 12 and best_haul([]) == 0 and best_haul([5]) == 5
    assert best_haul([2, 1, 1, 2]) == 4
@@solution
def best_haul(amounts):
    skip, take = 0, 0
    for x in amounts:
        skip, take = max(skip, take), skip + x
    return max(skip, take)

:::exercise id=d3 points=15 title="Drill 3: Paths round the bogs"
A grid of `"."` (passable) and `"#"` (bog) cells; you start top left and may move only right or down. Write `paths(grid)`: the number of routes to the bottom right.
@@starter
def paths(grid):
    ___
@@tests
def test_paths():
    "from above plus from the left"
    assert paths(["...", ".#.", "..."]) == 2 and paths(["..", ".."]) == 2 and paths(["#."]) == 0
    assert paths(["." * 10] * 10) == 48620 and paths(["."]) == 1 and paths([".#", "#."]) == 0
@@solution
def paths(grid):
    if not grid:
        return 0
    cols = len(grid[0])
    row = [0] * cols
    row[0] = 1 if grid[0][0] == "." else 0
    for r, line in enumerate(grid):
        for c, cell in enumerate(line):
            if cell == "#":
                row[c] = 0
            elif c > 0:
                row[c] += row[c - 1]
    return row[-1]
:::

@@tests
import time

def test_common():
    "a table of prefixes"
    assert common_stops(["Mill", "Weir", "Church", "Ridge"], ["Mill", "Church", "Farm", "Ridge"]) == 3
    assert common_stops(list("abcde"), list("ace")) == 3 and common_stops([], ["x"]) == 0 and common_stops(list("abc"), list("def")) == 0

    "500 by 500"
    start = time.perf_counter()
    assert common_stops(list("ab" * 250), list("ba" * 250)) == 499 and time.perf_counter() - start < 3
@@hint
`table[i][j]` is the answer for `a[:i]` and `b[:j]`: one more than `table[i-1][j-1]` if `a[i-1] == b[j-1]`, else the larger of `table[i-1][j]` and `table[i][j-1]`. Keep one previous row.
@@solution
def common_stops(a, b):
    previous = [0] * (len(b) + 1)
    for x in a:
        current = [0]
        for j, y in enumerate(b, start=1):
            current.append(previous[j - 1] + 1 if x == y else max(previous[j], current[j - 1]))
        previous = current
    return previous[-1]
:::

:::exercise id=d5 points=15 title="Drill 5: Packing the rucksack"
Each item of kit is `(name, weight, value)`; the rucksack holds at most `limit` weight (whole numbers). Write `pack(items, limit)`: the greatest total value, each item at most once (the 0/1 knapsack).
@@starter
def pack(items, limit):
    ___
@@tests
import time

def test_pack():
    "each item once"
    kit = [("map", 1, 6), ("flask", 2, 10), ("coat", 3, 12), ("stove", 4, 13)]
    assert pack(kit, 5) == 22 and pack(kit, 0) == 0 and pack(kit, 10) == 41 and pack([], 7) == 0

def test_fast():
    "100 items, limit 1000"
    items = [(f"i{k}", k % 17 + 1, (k * 37) % 50 + 1) for k in range(100)]
    start = time.perf_counter()
    assert pack(items, 1000) == sum(v for _, _, v in items) and time.perf_counter() - start < 3
@@hint
`best[w]` is the most value within weight `w`. For each item, go through `w` from `limit` **down** to its weight, so the item is used at most once: `best[w] = max(best[w], best[w - weight] + value)`.
@@solution
def pack(items, limit):
    best = [0] * (limit + 1)
    for _, weight, value in items:
        for w in range(limit, weight - 1, -1):
            best[w] = max(best[w], best[w - weight] + value)
    return best[limit]
:::

:::exercise id=d6 points=15 title="Drill 6: Splitting a run-together name"
Junction names have been run together without spaces (`"millweirridge"`). Write `splits(text, words)`: the number of ways to split `text` into words from the set `words`.
@@starter
def splits(text, words):
    ___
@@tests
def test_splits():
    "DP in disguise"
    words = {"mill", "weir", "ridge", "mil", "lweir", "l"}
    assert splits("millweirridge", words) == 3 and splits("mill", words) == 2 and splits("moor", words) == 0 and splits("", words) == 1
    assert splits("a" * 30, {"a", "aa"}) == 1346269
@@hint
`ways[i]` is the number of ways to split `text[:i]`; `ways[0] = 1`, and `ways[i]` adds `ways[j]` for every `j < i` where `text[j:i]` is a word.
@@solution
def splits(text, words):
    ways = [1] + [0] * len(text)
    longest = max((len(w) for w in words), default=0)
    for i in range(1, len(text) + 1):
        for j in range(max(0, i - longest), i):
            if ways[j] and text[j:i] in words:
                ways[i] += ways[j]
    return ways[-1]
:::

:::bughunt id=bug2 points=10 title="Recursion that never finished"
Without memoisation, this recursion recomputes the same states exponentially often and takes far too long for 35. Cache it with `functools.lru_cache` so it prints `1132436852` quickly.
@@starter
import functools

def ways(n):
    if n < 0:
        return 0
    if n == 0:

def test_output():
    "each state once"
    expect_output("1132436852")
@@solution
import functools

@functools.lru_cache(maxsize=None)

    if n < 0:
        return 0
    if n == 0:
        return 1
    return ways(n - 1) + ways(n - 2) + ways(n - 3)

print(ways(35))
:::

:::exercise id=challenge points=25 title="Challenge: two equal loads"
Two walkers share the kit so both carry exactly the same weight. Write `equal_split(weights)`: whether the whole numbers in `weights` can be split into two groups of equal total, and, if so, one group as a sorted list (`(True, group)`), else `(False, [])`. Use a table of reachable sums.
@@starter
def equal_split(weights):
    ___
@@tests
def test_split():
    "subset sum"
    ok, group = equal_split([1, 5, 11, 5])
    assert ok and sum(group) == 11 and sorted(group) == group
    assert equal_split([1, 2, 3, 5]) == (False, []) and equal_split([]) == (True, []) and equal_split([7]) == (False, [])
    weights = list(range(1, 41))
    ok, group = equal_split(weights)
    assert ok and sum(group) == sum(weights) // 2
    remaining = list(weights)
    for g in group:
        remaining.remove(g)
@@hint
`reach` maps each reachable sum to the index of the item that first reached it (and its previous sum). Fill it item by item; if half the total is reachable, walk back to recover the group.
@@solution
def equal_split(weights):
    total = sum(weights)
    if total % 2:
        return False, []
    target = total // 2
    came_from = {0: None}
    for i, w in enumerate(weights):
        for s in list(came_from):
            if s + w <= target and s + w not in came_from:
                came_from[s + w] = (s, i)
    if target not in came_from:
        return False, []
    group, s = [], target
    while came_from[s] is not None:
        previous, i = came_from[s]
        group.append(weights[i])
        s = previous
    return True, sorted(group)
:::
