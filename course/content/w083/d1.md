## Warm-up

:::predict
import numpy as np

scores = np.array([[70, 85, 90],
                   [55, 60, 75],
                   [95, 80, 88]])
print(scores.shape)
print(scores[1].tolist(), scores[:, 2].tolist())
print(scores.mean(axis=0).round(1).tolist())
print(scores.max(axis=1).tolist())
:::

A two-dimensional array is a table: here, three students (rows) and three tests (columns). `scores[1]` is a row, `scores[:, 2]` a column. **axis=0** collapses the rows, giving one answer per column (each test's average); **axis=1** collapses the columns, one answer per row (each student's best). Most of data work is choosing the right axis.

## Building arrays

Arrays rarely come from typing lists. NumPy builds them from a description:

- `np.arange(start, stop, step)`: like `range`, but an array (and steps may be floats, though `linspace` is safer for those);
- `np.linspace(start, stop, num)`: `num` evenly spaced values **including** both ends;
- `np.zeros(shape)`, `np.ones(shape)`, `np.full(shape, value)`: filled arrays of a given shape (a tuple for more than one dimension);
- `a.reshape(rows, cols)`: the same values in a new shape (`-1` means "work it out").

Every array has a **shape** (a tuple of sizes), an **ndim** (the number of dimensions), a **size** (the number of elements) and a **dtype**, the one type all its elements share. `np.array([1, 2, 3])` holds integers; one float makes them all floats.

:::example
import numpy as np

print(np.arange(0, 10, 3).tolist())
print(np.linspace(0, 1, 5).tolist())
grid = np.arange(12).reshape(3, 4)
print(grid.tolist())
print(grid.shape, grid.ndim, grid.size)
print(np.full((2, 3), 7).tolist())
print(np.arange(6).reshape(-1, 2).shape)
:::

`.tolist()` turns an array back into plain Python lists, which print the same everywhere; this page uses it so that outputs are easy to read.

## Indexing tables

Two-dimensional indexing takes a **row** part and a **column** part, separated by a comma:

- `a[r, c]`: one element; `a[r]` or `a[r, :]`: row `r`; `a[:, c]`: column `c`;
- `a[0:2, 1:]`: a block (slices in both directions); slices are **views** that share memory (Week 65), so copy with `.copy()` before changing one;
- `a[mask]`: with a boolean array of the same shape, the elements where it's `True`, as a flat array; a mask of **rows** (one `True`/`False` per row) picks whole rows: `a[a[:, 0] > 60]`;
- `a[[2, 0]]`: **fancy indexing** with a list of positions picks those rows in that order (always a copy).

:::example
import numpy as np

scores = np.array([[70, 85, 90],
                   [55, 60, 75],
                   [95, 80, 88],
                   [40, 65, 58]])
names = np.array(["Ada", "Bo", "Cy", "Dee"])

print(scores[2, 0], scores[1:3, :2].tolist())
passed_first = scores[:, 0] >= 60
print(names[passed_first].tolist())
print(scores[passed_first].tolist())
print(scores[[3, 0]].tolist())
print(names[(scores >= 60).all(axis=1)].tolist())
:::

The last line combines everything: `scores >= 60` is a table of booleans, `.all(axis=1)` asks "is every test passed?" for each row, and the resulting mask picks names.

## Statistics along an axis

`sum`, `mean`, `median` (as `np.median(a, axis=...)`), `std`, `min`, `max`, `argmin` and `argmax` (the **position** of the smallest or largest) all take an `axis`. `cumsum` gives running totals; `np.diff` the change from each element to the next; `np.percentile(a, q)` the value below which `q`% of the data lies.

To use a per-row or per-column result back on the table, it needs a shape that broadcasts. A column's means have shape `(cols,)`, which broadcasts across rows automatically; a row's means have shape `(rows,)`, which does **not** line up with the columns. **`keepdims=True`** keeps the collapsed axis with size 1, giving `(rows, 1)`, which does.

:::example
import numpy as np

temps = np.array([[3.0, 5.5, 4.0],     # London, three days
                  [12.5, 14.0, 15.5],  # Lisbon
                  [-2.0, 0.5, 1.5]])   # Oslo
print(temps.mean(axis=1).round(2).tolist())
print(temps.argmax(axis=0).tolist())        # which city was warmest each day
print(np.diff(temps, axis=1).tolist())      # day-to-day change in each city
centred = temps - temps.mean(axis=1, keepdims=True)
print(centred.round(2).tolist())
print(np.cumsum([3, 1, 4, 1, 5]).tolist(), float(np.percentile([1, 2, 3, 4, 100], 50)))
:::

`centred` shows each day relative to its own city's average: the same calculation for every row, written once.

## Missing values, sorting and counting

Real data has gaps. NumPy marks a missing float as **`np.nan`** ("not a number"), which spreads: any sum or mean involving it is `nan`. And `nan` isn't equal to anything, not even itself, so `a == np.nan` finds nothing: use **`np.isnan(a)`**. The `nan` versions of the statistics (`np.nansum`, `np.nanmean`, `np.nanmax`, ...) skip the gaps. `np.where(np.isnan(a), fill, a)` fills them.

Integers have no `nan`, so a column with gaps is always floats.

For order: `np.sort(a)` returns the sorted values; **`np.argsort(a)`** returns the **positions** that would sort them, which you use to sort something else (names by their scores) the same way. `np.unique(a, return_counts=True)` gives the distinct values and how often each appears, and `np.bincount` counts small non-negative integers.

:::example
import numpy as np

rain = np.array([2.0, np.nan, 0.0, 5.5, np.nan, 1.5])
print(float(rain.sum()), float(np.nansum(rain)), int(np.isnan(rain).sum()))
print((rain == np.nan).any(), np.isnan(rain).any())
print(np.where(np.isnan(rain), 0.0, rain).tolist())

sales = np.array([120, 340, 90, 410])
shops = np.array(["Leeds", "York", "Hull", "Bath"])
order = np.argsort(sales)[::-1]
print(shops[order].tolist(), sales[order].tolist())
values, counts = np.unique(np.array(["b", "a", "b", "c", "b"]), return_counts=True)
print(values.tolist(), counts.tolist(), np.bincount([0, 2, 2, 3]).tolist())
:::

## Random numbers

For simulations and samples, create a **Generator** with a **seed**: `rng = np.random.default_rng(42)`. The same seed gives the same numbers every time, so results can be checked and repeated; pass the generator into functions rather than using a global one. It has `rng.integers(low, high, size)` (high excluded), `rng.random(size)` (floats in [0, 1)), `rng.normal(mean, sd, size)`, `rng.choice(a, size, replace=False)` and `rng.permutation(a)`.

:::example
import numpy as np

rng = np.random.default_rng(7)
rolls = rng.integers(1, 7, size=10_000)
print(rolls.min(), rolls.max(), round(float(rolls.mean()), 1))
again = np.random.default_rng(7).integers(1, 7, size=10_000)
print((rolls == again).all())
heights = rng.normal(170, 8, size=5000)
print(round(float(heights.mean())), round(float(heights.std())))
:::

The exact numbers a seed produces can change between NumPy versions, so tests compare against a second generator with the same seed, or check properties (the range, the mean), rather than writing the numbers down.

:::key
Build arrays with `arange`, `linspace` (both ends included), `zeros`, `ones`, `full` and `reshape` (`-1` works out a size); read `shape`, `ndim`, `size` and `dtype`. Index tables as `a[rows, cols]`: slices give views, a boolean mask of rows picks rows, a list of positions picks rows in that order (a copy). Statistics take `axis` (0 collapses rows, giving one answer per column; 1 collapses columns); `argmax` gives positions, `cumsum` and `diff` running totals and changes, and `keepdims=True` keeps a collapsed axis so the result broadcasts back. Missing floats are `nan`: find them with `np.isnan`, never `==`; use `nansum` and friends; fill with `np.where`. `argsort` sorts one array by another; `unique(..., return_counts=True)` and `bincount` count. Make random numbers with a seeded `np.random.default_rng(seed)` passed into functions.
:::

def standardise_rows(a):

    sd = a.std(axis=1, keepdims=True)

    return ((a - mean) / safe).round(2)

    lo, hi = a.min(axis=0), a.max(axis=0)
    return ((a - lo) / (hi - lo)).round(2)

    per = gaps.sum(axis=0)

    means = np.nanmean(a, axis=0)
    return np.where(np.isnan(a), means, a).round(2)

    return a[~np.isnan(a).any(axis=1)]

    sales = np.array([120, 340, 90, 410, 200])
    assert top(names, sales, 3) == [("Bath", 410), ("York", 340), ("Ely", 200)]

import numpy as np

def top(names, values, k):
    order = np.argsort(values)[::-1][:k]
    return [(str(names[i]), values[i].item()) for i in order]

def most_common(a):
    values, counts = np.unique(a, return_counts=True)
    i = counts.argmax()
    return values[i].item(), int(counts[i])

def ranks(values):
    order = np.argsort(-values)
    result = np.empty(len(values), dtype=int)
    result[order] = np.arange(1, len(values) + 1)
    return result.tolist()
@@hint
`np.argsort(values)[::-1]` lists positions from largest to smallest. `.item()` turns a NumPy number into a plain Python one. For ranks, the position that comes first in the sorted order gets rank 1.

import numpy as np

def crop(img, top, left, height, width):
    return img[top:top + height, left:left + width].copy()

def flip(img, direction):
    if direction == "horizontal":
        return img[:, ::-1].copy()
    if direction == "vertical":
        return img[::-1].copy()
    raise ValueError("unknown direction")

def threshold(img, level):
    return np.where(img >= level, 255, 0)

def brighten(img, amount):
    return np.clip(img.astype(int) + amount, 0, 255)

def blur(img):
    padded = np.pad(img.astype(float), 1, mode="edge")
    h, w = img.shape
    total = sum(padded[dy:dy + h, dx:dx + w] for dy in range(3) for dx in range(3))
    return np.round(total / 9).astype(int)

def histogram(img, bins):
    return np.bincount((img * bins // 256).ravel(), minlength=bins).tolist()
