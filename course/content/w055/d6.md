def the_odd_one(values):
    bits = max(values).bit_length()
    result = 0
    for i in range(bits):
        count = 0
        for v in values:
            count += v >> i & 1
        if count % 3:
            result |= 1 << i
    return result
:::

def fib_mod(n, m):
    def times(a, b):
        return [[(a[0][0] * b[0][0] + a[0][1] * b[1][0]) % m, (a[0][0] * b[0][1] + a[0][1] * b[1][1]) % m],
                [(a[1][0] * b[0][0] + a[1][1] * b[1][0]) % m, (a[1][0] * b[0][1] + a[1][1] * b[1][1]) % m]]
    result = [[1 % m, 0], [0, 1 % m]]
    base = [[1, 1], [1, 0]]
    while n:
        if n & 1:
            result = times(result, base)
        base = times(base, base)
        n >>= 1
    return result[0][1]

## Forge: a ticket office

A theatre sells tickets whose codes are printed and sometimes read out over the phone, so they must be short, hard to mistype, and checked for errors. Each ticket has an **event** (0 to 1023, 10 bits), a **day** of the season (0 to 511, 9 bits) and a **seat** (0 to 4095, 12 bits). Write `TicketOffice()` (no arguments) with:

- `pack(event, day, seat)`: one 31-bit number, `event << 21 | day << 12 | seat`; `ValueError` if a field doesn't fit. `unpack(value)` reverses it.
- `check_digits(value)`: the two check digits of **ISO 7064 MOD 97-10** (used in IBAN bank account numbers): `98 - (value * 100) % 97`, so that `(value * 100 + check) % 97 == 1`. Any single wrong digit, and most swaps, then fail the check.
- `code(event, day, seat)`: `value * 100 + check`, written as exactly 8 characters in Douglas Crockford's base 32 alphabet, `0123456789ABCDEFGHJKMNPQRSTVWXYZ` (no I, L, O or U, which are easily confused or rude).
- `read(code)`: the `(event, day, seat)` back. Accept lower case, ignore hyphens, read `I` and `L` as `1` and `O` as `0`, and raise `ValueError` for any other character not in the alphabet or if the check fails.
- `draw(codes, k, seed)`: k different winning codes, chosen fairly and repeatably with a **partial** Fisher-Yates shuffle (for i from 0 to k − 1, swap position i with a random position from i to the end, using `random.Random(seed).randint`), in the order drawn. `ValueError` if k is impossible.
- `chance_any(n, k, m)`: the exact probability, as a `Fraction`, that at least one of m tickets you hold is among k winners drawn from n tickets: 1 − C(n − m, k) / C(n, k).

Write the code like Day 1's `to_base`: take `number % 32` eight times, then reverse. For `read`, build the number back by `number * 32 + ALPHABET.index(ch)`, check `number % 97 == 1`, and unpack `number // 100`.
@@solution
import random
from fractions import Fraction
from math import comb

ALPHABET = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"

class TicketOffice:
    def pack(self, event, day, seat):
        for value, bits, name in ((event, 10, "event"), (day, 9, "day"), (seat, 12, "seat")):
            if not 0 <= value < 1 << bits:
                raise ValueError(f"{name} {value} doesn't fit in {bits} bits")
        return event << 21 | day << 12 | seat

    def unpack(self, value):
        return value >> 21 & 0x3FF, value >> 12 & 0x1FF, value & 0xFFF

    def check_digits(self, value):
        return 98 - value * 100 % 97

    def code(self, event, day, seat):
        value = self.pack(event, day, seat)
        number = value * 100 + self.check_digits(value)
        out = []
        for _ in range(8):
            number, d = divmod(number, 32)
            out.append(ALPHABET[d])
        return "".join(reversed(out))

    def read(self, code):
        number = 0
        for ch in code.upper().replace("-", ""):
            ch = {"I": "1", "L": "1", "O": "0"}.get(ch, ch)
            if ch not in ALPHABET:
                raise ValueError(f"{ch!r} isn't a code character")
            number = number * 32 + ALPHABET.index(ch)
        if number % 97 != 1:
            raise ValueError("the check digits don't match")
        return self.unpack(number // 100)

    def draw(self, codes, k, seed):
        if not 0 <= k <= len(codes):
            raise ValueError("can't draw that many winners")
        pool = list(codes)
        rng = random.Random(seed)
        for i in range(k):
            j = rng.randint(i, len(pool) - 1)
            pool[i], pool[j] = pool[j], pool[i]
        return pool[:k]

    def chance_any(self, n, k, m):
        if not (0 <= k <= n and 0 <= m <= n):
            raise ValueError("bad counts")
        return 1 - Fraction(comb(n - m, k), comb(n, k))
:::

:::think title="Why mod 97 catches typos"
Changing one base-32 character changes the number by d × 32ⁱ, where d is between −31 and 31 (not 0). For the check to miss it, 97 would have to divide that change. But 97 is prime, larger than 31, and shares no factor with 32, so it never divides d × 32ⁱ: every single-character error is caught. The same reasoning, with a prime bigger than the alphabet, is why ISBNs use 11 and bank numbers use 97.
:::

## Forge bonus: sharing a secret

:::exercise id=forge2 points=30 title="Forge bonus: sharing a secret"
Adi Shamir (the S in RSA) showed in 1979 how to split a secret number into n **shares** so that any k of them recover it, but k − 1 reveal nothing. Choose a random polynomial of degree k − 1 whose constant term is the secret, working mod a prime p; share x is the point (x, f(x)) for x = 1 to n. Any k points fix the polynomial, and **Lagrange interpolation** recovers f(0):

f(0) = Σᵢ yᵢ × Πⱼ≠ᵢ (0 − xⱼ) / (xᵢ − xⱼ), all mod p, dividing with inverses.

Write, with `PRIME = 2 ** 127 - 1` (a Mersenne prime) as the default p:

- `evaluate(coefficients, x, p=PRIME)`: the polynomial c₀ + c₁x + c₂x² + ... mod p, by Horner's method (work from the highest coefficient down: `result = result * x + c`).
- `split(secret, n, k, rng, p=PRIME)`: the list of shares `(x, y)` for x = 1 to n, with the other k − 1 coefficients from `rng.randrange(p)`. `ValueError` unless 1 ≤ k ≤ n and 0 ≤ secret < p.
- `combine(shares, p=PRIME)`: the secret from a list of shares (`ValueError` if two have the same x).
- `text_to_number(text)` and `number_to_text(number)`, via UTF-8 bytes, so words can be shared.

As with RSA on Wednesday, this is for understanding: real systems use audited libraries.

PRIME = 2 ** 127 - 1

def evaluate(coefficients, x, p=PRIME):
    result = 0
    for c in reversed(coefficients):
        result = (result * x + c) % p
    return result

def split(secret, n, k, rng, p=PRIME):
    if not 1 <= k <= n:
        raise ValueError("need 1 <= k <= n")
    if not 0 <= secret < p:
        raise ValueError("the secret must be smaller than the prime")
    coefficients = [secret] + [rng.randrange(p) for _ in range(k - 1)]
    return [(x, evaluate(coefficients, x, p)) for x in range(1, n + 1)]

def combine(shares, p=PRIME):
    xs = [x for x, _ in shares]
    if len(set(xs)) != len(xs):
        raise ValueError("two shares have the same x")
    secret = 0
    for i, (xi, yi) in enumerate(shares):
        top, bottom = 1, 1
        for j, (xj, _) in enumerate(shares):
            if j != i:
                top = top * (-xj) % p
                bottom = bottom * (xi - xj) % p
        secret = (secret + yi * top * pow(bottom, -1, p)) % p
    return secret

def text_to_number(text):
    return int.from_bytes(text.encode("utf-8"), "big")

def number_to_text(number):
    return number.to_bytes((number.bit_length() + 7) // 8, "big").decode("utf-8")
