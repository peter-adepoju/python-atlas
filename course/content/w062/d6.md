import gc
from contextlib import contextmanager

@contextmanager
def gc_paused():
    was_enabled = gc.isenabled()
    gc.disable()
    try:
        yield
    finally:
        if was_enabled:
            gc.enable()

@@solution
import functools
import weakref

def weak_memo(func):
    cache = weakref.WeakKeyDictionary()

    @functools.wraps(func)
    def wrapper(obj):
        if obj not in cache:
            cache[obj] = func(obj)
        return cache[obj]

    wrapper.cache_size = lambda: len(cache)
    return wrapper

## Forge: an identity map

An **identity map** makes sure each record is represented by exactly **one** live object, so that a change made through one part of a program is seen by every other part holding that record. Write `Repository(loader)`:

- `get(key)`: return the live object for `key` if there is one; otherwise call `loader(key)`, remember the object **weakly**, and return it. `loads` counts calls to the loader. (Loaders that return objects which can't be weakly referenced make `get` raise `TypeError`, which `weakref` does for you.)
- `live()`: the sorted keys whose objects are alive. `evicted`: a list of keys, in order, appended to **when each loaded object dies** (use `weakref.finalize`).
- `meta(obj)`: a **copy** of the metadata dict `{"key": key, "load": n}` for an object this repository loaded, where `n` is the value of `loads` just after loading it; `KeyError` for other objects. Store metadata in a `WeakKeyDictionary`.
- `pin(key)` returns the object and keeps it alive (strongly) until a matching number of `unpin(key)` calls; `unpin` of a key that isn't pinned raises `ValueError`; `pinned()` lists pinned keys, sorted.
- `edit(key)`: a context manager yielding a **deep copy** of the object (loading it if needed, and keeping it alive during the edit). If the block finishes normally, the draft's attributes **replace** the live object's attributes (so everyone holding the object sees the change) and `version(key)` goes up by one; if the block raises, the live object is untouched and the exception propagates. `version(key)` is 0 for keys never edited.

@@hint
Keep a `WeakValueDictionary` from key to object, a `WeakKeyDictionary` from object to metadata, a plain dict of pins (key to `[obj, count]`, the list holding the strong reference) and a dict of versions. In `get`, register `weakref.finalize(obj, self.evicted.append, key)`: the finaliser refers to the list, not the object. In `edit`, the `@contextmanager` generator holds the live object in a local; after the `yield`, use `vars(live).clear()` and `vars(live).update(vars(draft))`.
@@solution
import copy
import weakref
from contextlib import contextmanager

class Repository:
    def __init__(self, loader):
        self._loader = loader
        self._live = weakref.WeakValueDictionary()
        self._meta = weakref.WeakKeyDictionary()
        self._pins = {}
        self._versions = {}
        self.loads = 0
        self.evicted = []

    def get(self, key):
        obj = self._live.get(key)
        if obj is None:
            obj = self._loader(key)
            self._live[key] = obj
            self.loads += 1
            self._meta[obj] = {"key": key, "load": self.loads}
            weakref.finalize(obj, self.evicted.append, key)
        return obj

    def live(self):
        return sorted(self._live.keys())

    def meta(self, obj):
        return dict(self._meta[obj])

    def pin(self, key):
        obj = self.get(key)
        entry = self._pins.setdefault(key, [obj, 0])
        entry[1] += 1
        return obj

    def unpin(self, key):
        if key not in self._pins:
            raise ValueError(f"{key!r} is not pinned")
        entry = self._pins[key]
        entry[1] -= 1
        if entry[1] == 0:
            del self._pins[key]

    def pinned(self):
        return sorted(self._pins)

    def version(self, key):
        return self._versions.get(key, 0)

    @contextmanager
    def edit(self, key):
        live = self.get(key)
        draft = copy.deepcopy(live)
        yield draft
        state = vars(live)
        state.clear()
        state.update(vars(draft))
        self._versions[key] = self.version(key) + 1
:::

:::think title="Who owns what"
Every part of today's repository is an answer to "who keeps this alive?". The weak dictionary means the repository never decides an object's lifetime; the code using the object does. Pins are an explicit, counted decision to keep something. Metadata rides along in a weak side table, so it can't become the reason an object survives. And the edit works on a deep copy, so a half-finished change can't leak into the shared object: sharing is the point of an identity map, so changes to the shared object have to be all or nothing. When you design anything that holds references to other people's objects, ask the same question for each reference.
:::

## Forge bonus: copy-on-write

:::exercise id=forge2 points=30 title="Forge bonus: copy-on-write"
Copying a big list just in case is wasteful when most copies are never changed. **Copy-on-write** shares the data until someone writes. Write `CowList(items=())`:

- The items live in a shared **buffer** object that records how many `CowList`s own it. `CowList(items)` copies `items` into a new buffer (so the caller's list isn't shared).
- `copy()` returns a new `CowList` sharing the **same** buffer, at no cost: no items are copied.
- Reads (`len`, indexing, iteration, `==` with a list or another `CowList`, `repr` as `CowList([1, 2])`) use the buffer directly.
- Writes (`append`, `extend`, item assignment, `pop(i=-1)`) first make sure this list is the buffer's **only** owner: if not, it copies the items into a new buffer of its own and adds one to its `copied` counter (which starts at 0). A sole owner writes in place.
- `owners()` is the number of owners of this list's buffer, and `shares_with(other)` is True if two lists share a buffer.
- When a `CowList` is garbage collected, its buffer must lose an owner, so the remaining owner can write without copying. Use `weakref.finalize` (and `detach()` the old finaliser when a list moves to a new buffer).
@@starter
import weakref

class CowList:

@@tests
def test_copy_on_write():
    "share until written"
    a = CowList([1, 2])
    b = a.copy()
    assert a.shares_with(b) and a.owners() == 2 and b == [1, 2] and a == b
    a.append(3)
    assert a == [1, 2, 3] and b == [1, 2] and a.copied == 1 and not a.shares_with(b)
    assert a.owners() == 1 and b.owners() == 1
    b.append(4)
    assert b.copied == 0 and b == [1, 2, 4]
    c = b.copy()
    d = c.copy()
    assert b.owners() == 3 and d.shares_with(b)
    del c
    assert b.owners() == 2
    del d
    b[0] = 9
    assert b.copied == 0 and b[0] == 9 and len(b) == 3 and list(b) == [9, 2, 4]
    e = b.copy()
    assert e.pop() == 4 and e.copied == 1 and b == [9, 2, 4] and e == [9, 2]
    assert repr(e) == "CowList([9, 2])"
    e.extend([7, 8])
    assert e.copied == 1 and e == [9, 2, 7, 8]

def test_lifetimes():
    "owners follow object lifetimes"
    a = CowList(["x"])
    copies = [a.copy() for _ in range(5)]
    assert a.owners() == 6
    copies.clear()
    assert a.owners() == 1
    b = a.copy()
    b.append("y")
    assert a.owners() == 1 and b.owners() == 1
    del b
    assert a.owners() == 1
    a.append("z")
    assert a.copied == 0
    source = ["s"]
    c = CowList(source)
    source.append("t")
    assert c == ["s"] and CowList([1]) != [2] and CowList([1]) == CowList([1])
    import gc
    f = a.copy()
    f.me = f
    del f
    gc.collect()
    assert a.owners() == 1
@@hint
A small class `_Buffer` with `items` and `owners`, and a module-level function `_release(buffer)` that subtracts one owner. In a helper `_attach(buffer)`, store the buffer and `weakref.finalize(self, _release, buffer)`. When a write needs a private copy: `self._finalizer.detach()`, subtract the owner yourself, then `_attach` a new buffer.
@@solution
import weakref

class _Buffer:
    def __init__(self, items):
        self.items, self.owners = items, 1

def _release(buffer):
    buffer.owners -= 1

class CowList:
    def __init__(self, items=()):
        self._attach(_Buffer(list(items)))
        self.copied = 0

    def _attach(self, buffer):
        self._buffer = buffer
        self._finalizer = weakref.finalize(self, _release, buffer)

    def copy(self):
        new = CowList.__new__(CowList)
        self._buffer.owners += 1
        new._attach(self._buffer)
        new.copied = 0
        return new

    def _own(self):
        if self._buffer.owners > 1:
            old = self._buffer
            self._finalizer.detach()
            old.owners -= 1
            self._attach(_Buffer(list(old.items)))
            self.copied += 1
        return self._buffer.items

    def shares_with(self, other):
        return self._buffer is other._buffer

    def owners(self):
        return self._buffer.owners

    def __len__(self):
        return len(self._buffer.items)

    def __getitem__(self, i):
        return self._buffer.items[i]

    def __iter__(self):
        return iter(list(self._buffer.items))

    def __eq__(self, other):
        if isinstance(other, CowList):
            return self._buffer.items == other._buffer.items
        if isinstance(other, list):
            return self._buffer.items == other
        return NotImplemented

    def __repr__(self):
        return f"CowList({self._buffer.items!r})"

    def append(self, item):
        self._own().append(item)

    def extend(self, items):
        self._own().extend(items)

    def __setitem__(self, i, value):
        self._own()[i] = value

    def pop(self, i=-1):
        return self._own().pop(i)
