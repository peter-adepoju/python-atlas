## System design

- **Estimate first** (Week 81): requests per second from daily users and actions (a day is about 10⁵ seconds), peak as a multiple of average, storage per year, and servers at a safe utilisation (about 70%). **Little's law**: requests in progress = arrival rate × time in the system.
- **Caches** (LRU, with a time to live) take load off slow stores; the hard part is **invalidation** (delete or update the cached copy when the data changes) and **stampedes** (many misses at once).
- **Queues** decouple producers from consumers, smooth bursts and allow retries; consumers must be **idempotent** because messages can arrive twice.
- **Replicas** spread reads and survive failures (with replication lag); **partitions** (shards) spread writes; **consistent hashing** moves only about 1/n of the keys when a node joins.
- **Distributed systems** (Week 82): no shared clock (Lamport and vector clocks order events), majorities (quorums, Raft) agree on one history, and sagas undo multi-step work with compensations.

:::example
import bisect
import zlib

def h(text):
    return zlib.crc32(text.encode())

def ring(nodes, vnodes=50):
    points = sorted((h(f"{n}#{i}"), n) for n in nodes for i in range(vnodes))
    return [p for p, _ in points], [n for _, n in points]

def owner(key, r):
    hashes, names = r
    return names[bisect.bisect(hashes, h(key)) % len(hashes)]

keys = [f"user{i}" for i in range(1000)]
before = ring(["a", "b", "c"])
after = ring(["a", "b", "c", "d"])
moved = sum(owner(k, before) != owner(k, after) for k in keys)
print(moved, "of 1000 keys moved")
print(sum(owner(k, after) == "d" for k in keys) == moved)
:::

Every key that moved went to the new node, and only about a quarter moved. With `hash(key) % n`, most keys would have moved.

## Reliability

- **Measure what users feel**: rate, errors and duration (RED); percentiles, not averages; traces that follow one request through many services (Week 82).
- **Service level objectives**: an SLO such as "99.9% of requests succeed" leaves an **error budget** of 0.1%; the **burn rate** is how fast you're spending it (1 means exactly on budget). Alert on fast burns over short and long windows together.
- **Retries** only for transient failures and idempotent operations, with **exponential backoff** and **jitter** (so clients don't retry in step), a cap, and a retry budget. **Circuit breakers** stop calling a failing dependency and try again after a pause. **Deadlines** bound the whole request, not each step.
- **Availability** multiplies in series (0.999 × 0.999 ≈ 0.998) and improves in parallel (1 − 0.001²).

:::example
import random

def backoff_delays(attempts, base, cap, rng):
    return [round(rng.uniform(0, min(cap, base * 2 ** i)), 3) for i in range(attempts)]

print(backoff_delays(5, 0.1, 2.0, random.Random(1)))
slo, total, failed = 0.999, 2_000_000, 1300
budget = (1 - slo) * total
print(round(budget), round(failed / budget, 2), "of the budget used")
print(round(0.999 * 0.999, 6), round(1 - 0.001 ** 2, 6))
:::

## Machine learning

- **The workflow** (Week 84): split off a test set first (stratified for classes); build a **pipeline** (scaling, encoding, model) so preprocessing is fitted on training data only; tune hyperparameters with **cross-validation** on the training set (`GridSearchCV`); score on the test set **once**; compare with a **baseline** (`DummyClassifier`).
- **Metrics**: accuracy misleads on imbalanced classes; use the confusion matrix, **precision** (flags that were right) and **recall** (positives caught), choose the threshold by the costs of each mistake, and ROC AUC to compare rankings; MAE, RMSE and R² for regression.
- **Models**: linear and logistic regression (explainable), nearest neighbours (needs scaling), trees and forests (flexible, can overfit), Naive Bayes (text), neural networks (layers, activations, backpropagation, gradient descent); training error far below test error means **overfitting**.

:::example
from sklearn.datasets import load_wine
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
search = GridSearchCV(make_pipeline(StandardScaler(), KNeighborsClassifier()),
                      {"kneighborsclassifier__n_neighbors": [1, 3, 5, 9]}, cv=5).fit(X_train, y_train)
baseline = DummyClassifier(strategy="most_frequent").fit(X_train, y_train).score(X_test, y_test)
print(search.best_params_, round(search.best_score_, 3))
print("test:", round(search.score(X_test, y_test), 3), "baseline:", round(baseline, 3))

## Classic mistakes

- Averages instead of percentiles; caches with no invalidation; `hash(key) % n` sharding; retries on non-idempotent requests, or without jitter.
- Chained indexing in pandas; joins that duplicate rows; filling missing values with zero before averaging; bars that don't start at zero.
- Scaling before splitting; tuning on the test set; reporting accuracy on imbalanced data; judging a model by its training score.

:::key
Design starts with estimates (rates, peaks, storage, servers at 70%) and uses caches (with invalidation), queues (with idempotent consumers), replicas and partitions (consistent hashing moves about 1/n keys). Reliability is measured with RED and percentiles against SLOs and error budgets, and protected with jittered backoff, retry budgets, circuit breakers and deadlines. Data work uses vectorised NumPy and pandas (groupby, merge with validate, pivot, resample, one `.loc` for changes), deliberate cleaning, and honest charts. ML splits first, puts preprocessing in a pipeline, tunes by cross-validation, tests once, compares with a baseline, and chooses metrics and thresholds by the cost of each kind of mistake.
:::

from collections import OrderedDict

class TTLCache:
    def __init__(self, capacity, ttl, clock):
        self.capacity, self.ttl, self.clock = capacity, ttl, clock
        self.data = OrderedDict()
        self.hits = self.misses = 0

    def get(self, key):
        entry = self.data.get(key)
        if entry is not None and self.clock() - entry[1] > self.ttl:
            del self.data[key]
            entry = None
        if entry is None:
            self.misses += 1
            return None
        self.hits += 1
        self.data.move_to_end(key)
        return entry[0]

    def put(self, key, value):
        self.data[key] = (value, self.clock())
        self.data.move_to_end(key)
        while len(self.data) > self.capacity:
            self.data.popitem(last=False)

    def invalidate(self, key):
        self.data.pop(key, None)

import bisect
import zlib

class Ring:
    def __init__(self, nodes, vnodes=50):
        self.vnodes = vnodes
        self.points = []
        for n in nodes:
            self.add(n)

    def add(self, node):
        for i in range(self.vnodes):
            bisect.insort(self.points, (zlib.crc32(f"{node}#{i}".encode()), node))

    def remove(self, node):
        self.points = [p for p in self.points if p[1] != node]

    def node_for(self, key):
        h = zlib.crc32(key.encode())
        i = bisect.bisect_left(self.points, (h, ""))
        return self.points[i % len(self.points)][1]

def moved(keys, before, after):
    return sum(before.node_for(k) != after.node_for(k) for k in keys)

import random

class TransientError(Exception):
    pass

def call_with_retry(call, attempts, base, cap, rng, sleep):
    for k in range(attempts):
        try:
            return call()
        except TransientError:
            if k == attempts - 1:
                raise
            sleep(rng.uniform(0, min(cap, base * 2 ** k)))

import math
import pandas as pd

def _p95(values):
    ordered = sorted(values)
    return int(ordered[math.ceil(0.95 * len(ordered)) - 1])

def endpoint_stats(df):
    rows = []
    for endpoint, part in df.groupby("endpoint"):
        rows.append({"endpoint": endpoint, "requests": len(part),
                     "error_rate": round(float((part["status"] >= 500).mean()), 3),
                     "p95": _p95(part["ms"].tolist())})
    return sorted(rows, key=lambda r: (-r["p95"], r["endpoint"]))

def errors_by_hour(df):
    hours = pd.to_datetime(df["time"]).dt.hour
    errors = (df["status"] >= 500).groupby(hours).sum()
    return {int(h): int(n) for h, n in errors.items()}

import math
import pandas as pd
import matplotlib.pyplot as plt

def _p95(values):
    ordered = sorted(values)
    return int(ordered[math.ceil(0.95 * len(ordered)) - 1])

def health_report(path, slo=0.99):
    df = pd.read_csv(path)
    df["error"] = df["status"] >= 500
    df["hour"] = pd.to_datetime(df["time"]).dt.hour
    per = []
    for endpoint, part in df.groupby("endpoint"):
        per.append({"endpoint": endpoint, "requests": len(part),
                    "error_rate": round(float(part["error"].mean()), 3), "p95": _p95(part["ms"].tolist())})
    per.sort(key=lambda r: (-r["p95"], r["endpoint"]))
    error_fraction = float(df["error"].mean())
    budget_used = round(error_fraction / (1 - slo), 2)
    errors = df.groupby("hour")["error"].sum()
    worst = int(errors.idxmax()) if errors.max() > 0 else None
    gets = set(df.loc[df["method"] == "GET", "endpoint"])
    candidates = sorted(r["endpoint"] for r in per if r["endpoint"] in gets and r["requests"] >= 10 and r["p95"] > 100)
    report = {"per_endpoint": per, "availability": round(1 - error_fraction, 4), "budget_used": budget_used,
              "verdict": "over budget" if budget_used > 1 else "ok", "worst_hour": worst,
              "cache_candidates": candidates}

    fig, (left, right) = plt.subplots(1, 2, figsize=(10, 4))
    left.bar([r["endpoint"] for r in per], [r["p95"] for r in per])
    left.set_title("p95 latency")
    left.set_ylabel("ms")
    left.set_ylim(bottom=0)
    hours = range(int(df["hour"].min()), int(df["hour"].max()) + 1)
    per_hour = df.groupby("hour").size().reindex(hours, fill_value=0)
    right.plot(list(per_hour.index), per_hour.values, marker="o")
    right.set_title("Requests per hour")
    right.set_xlabel("hour")
    right.set_ylabel("requests")
    fig.tight_layout()
    return report, fig
