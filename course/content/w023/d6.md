:::exercise id=mix_email points=10 title="Email addresses"
Write `emails(text)` returning every email address in the text, lower-cased, without duplicates, in the order first seen. An address here is: one or more of letters, digits, `.`, `_`, `%`, `+` or `-`; then `@`; then one or more labels of letters, digits or hyphens separated by dots, ending with a dot and at least 2 letters.
@@starter
import re

@@tests
def test_values():
    "several"
    t = "Mail Ada.L+club@Example.co.uk or ben_9@mail.ng; again ada.l+club@example.co.uk. Not me@home or @x.com."
    assert emails(t) == ["ada.l+club@example.co.uk", "ben_9@mail.ng"]
@@solution
import re

EMAIL = re.compile(r"[\w.%+-]+@(?:[A-Za-z0-9-]+\.)+[A-Za-z]{2,}")

def emails(text):
    seen = []
    for m in EMAIL.findall(text):
        e = m.lower()
        if e not in seen:
            seen.append(e)
    return seen
:::

:::exercise id=mix_json points=10 title="Count by type"
Write `count_types(text)` that loads JSON text and counts every value at every depth by its JSON type name, returning a dictionary like `{"object": 2, "string": 3, ...}` with keys from `object`, `array`, `string`, `number`, `boolean` and `null` (only those that occur).
@@starter
import json

@@tests
def test_values():
    "several"
    t = '{"a": [1, 2.5, "x"], "b": {"c": null, "d": true}, "e": "y"}'
    assert count_types(t) == {"object": 2, "array": 1, "number": 2, "string": 2, "null": 1, "boolean": 1}
    assert count_types("3") == {"number": 1}
@@solution
import json

def kind(v):
    if isinstance(v, dict):
        return "object"
    if isinstance(v, list):
        return "array"
    if isinstance(v, bool):
        return "boolean"
    if v is None:
        return "null"
    if isinstance(v, (int, float)):
        return "number"
    return "string"

def count_types(text):
    counts = {}
    def walk(v):
        k = kind(v)
        counts[k] = counts.get(k, 0) + 1
        if isinstance(v, dict):
            for x in v.values():
                walk(x)
        elif isinstance(v, list):
            for x in v:
                walk(x)
    walk(json.loads(text))
    return counts
:::

:::exercise id=mix_csv points=10 title="CSV to JSON lines"
Write `to_json_lines(csv_text)` that turns CSV text (with a header) into "JSON Lines": one compact JSON object per line (`separators=(",", ":")`), with fields that look like whole numbers converted to `int`, and empty fields as `null`.
@@starter
import csv, io, json

@@tests
def test_values():
    "several"
    t = "name,age,town\nAda,36,Leeds\nBen,,Bath\n"
    assert to_json_lines(t) == '{"name":"Ada","age":36,"town":"Leeds"}\n{"name":"Ben","age":null,"town":"Bath"}\n'
@@solution
import csv, io, json

def convert(v):
    if v == "":
        return None
    if v.lstrip("-").isdigit():
        return int(v)
    return v

def to_json_lines(csv_text):
    lines = []
    for row in csv.DictReader(io.StringIO(csv_text)):
        lines.append(json.dumps({k: convert(v) for k, v in row.items()}, separators=(",", ":")))
    return "".join(l + "\n" for l in lines)
:::

:::exercise id=mix_tz points=10 title="Local office hours"
Write `is_open(utc_text, zone)` returning `True` if the moment `utc_text` (ISO form ending in `Z`) falls between 09:00 and 17:00 local time (17:00 itself is closed), Monday to Friday, in the given zone.
@@starter
from datetime import datetime
from zoneinfo import ZoneInfo

@@tests
def test_values():
    "several"
    assert is_open("2026-11-02T08:30:00Z", "Africa/Lagos") is True
    assert is_open("2026-11-02T08:30:00Z", "Europe/London") is False
    assert is_open("2026-11-02T16:00:00Z", "Africa/Lagos") is False
    assert is_open("2026-11-01T10:00:00Z", "Africa/Lagos") is False
@@solution
from datetime import datetime
from zoneinfo import ZoneInfo

def is_open(utc_text, zone):
    moment = datetime.fromisoformat(utc_text.replace("Z", "+00:00"))
    local = moment.astimezone(ZoneInfo(zone))
    return local.weekday() < 5 and 9 <= local.hour < 17

## Forge: cleaning a members export

A running club's old membership system exports a CSV like this. People typed things however they liked, and the system recorded sign-up times in the club's local time, Lagos.

```
Name;Email;Phone;Joined;Distance
 ada  OKAFOR ;Ada.Okafor@Example.com;0803 123 4567;31/10/2026 18:05;10k
Bisi Adeyemi;bisi@mail;+234 805 987 6543;2026-11-01 07:30;half
CHEN wei;chen.wei@club.ng;(0701) 222-3333;1 Nov 2026 9:00;5K
;dee@club.ng;08031112222;2026-11-02 10:00;marathon
Eze Nnamdi;eze@club.ng;0803 123;2026-13-01 10:00;10K
```

:::exercise id=forge points=50 title="Forge: cleaning a members export"
Write `clean(text)` that returns `(members, problems)`. Read the text as `;`-separated CSV with a header. For each row (`reader.line_num` gives N for problem messages), clean each field:

1. **name**: strip, collapse runs of spaces to one, and give each word a capital first letter and lower case after (`"ada  OKAFOR"` becomes `"Ada Okafor"`). Empty: problem `"line N: missing name"`.
2. **email**: strip and lower-case; must fully match the email pattern from the mixed review. Otherwise: `"line N: bad email"`.
3. **phone**: keep the digits; a leading `234` (from `+234`) becomes `0`; must then be exactly 11 digits starting with `0`. Otherwise `"line N: bad phone"`.
4. **joined**: one of three formats, `DD/MM/YYYY HH:MM`, `YYYY-MM-DD HH:MM`, or `D Mon YYYY H:MM` (like `1 Nov 2026 9:00`); a Lagos local time, converted to UTC and written as ISO with `Z` (`"2026-10-31T17:05:00Z"`). If none of the formats fits: `"line N: bad date"`.
5. **distance**: map case-insensitively `5k` to `"5K"`, `10k` to `"10K"`, `half` to `"Half marathon"`, `marathon` to `"Marathon"`. Anything else: `"line N: bad distance"`.

A row with any problem is left out of `members`, and **all** its problems are reported, in the field order above. Each member is a dictionary with keys `name`, `email`, `phone`, `joined`, `distance`. Then `to_json(text)` returns `json.dumps({"members": members, "problems": problems}, indent=2)`.
@@starter
import csv, io, json, re
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

EMAIL = re.compile(r"[\w.%+-]+@(?:[A-Za-z0-9-]+\.)+[A-Za-z]{2,}")
LAGOS = ZoneInfo("Africa/Lagos")
FORMATS = ["%d/%m/%Y %H:%M", "%Y-%m-%d %H:%M", "%d %b %Y %H:%M"]
DISTANCES = {"5k": "5K", "10k": "10K", "half": "Half marathon", "marathon": "Marathon"}

@@tests
TEXT = """Name;Email;Phone;Joined;Distance
 ada  OKAFOR ;Ada.Okafor@Example.com;0803 123 4567;31/10/2026 18:05;10k
Bisi Adeyemi;bisi@mail;+234 805 987 6543;2026-11-01 07:30;half
CHEN wei;chen.wei@club.ng;(0701) 222-3333;1 Nov 2026 9:00;5K
;dee@club.ng;08031112222;2026-11-02 10:00;marathon
Eze Nnamdi;eze@club.ng;0803 123;2026-13-01 10:00;10K
"""
def test_members():
    "members"
    members, problems = clean(TEXT)
    assert members == [
        {"name": "Ada Okafor", "email": "ada.okafor@example.com", "phone": "08031234567", "joined": "2026-10-31T17:05:00Z", "distance": "10K"},
        {"name": "Chen Wei", "email": "chen.wei@club.ng", "phone": "07012223333", "joined": "2026-11-01T08:00:00Z", "distance": "5K"},
    ]
def test_problems():
    "problems"
    members, problems = clean(TEXT)
    assert problems == ["line 3: bad email", "line 5: missing name", "line 6: bad phone", "line 6: bad date"]
def test_json():
    "to_json"
    import json
    data = json.loads(to_json(TEXT))
    assert len(data["members"]) == 2 and len(data["problems"]) == 4
    assert to_json(TEXT).startswith('{\n  "members": [')
@@hint
Write one small function per field, each returning the cleaned value or `None` if it can't be cleaned; then `clean` calls them in order, collects a message for each `None`, and keeps the row only if there were no messages.
@@hint
For dates, try each format in `FORMATS` with `datetime.strptime` inside `try`/`except ValueError`. Then `.replace(tzinfo=LAGOS).astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")`.
@@solution
import csv, io, json, re
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

EMAIL = re.compile(r"[\w.%+-]+@(?:[A-Za-z0-9-]+\.)+[A-Za-z]{2,}")
LAGOS = ZoneInfo("Africa/Lagos")
FORMATS = ["%d/%m/%Y %H:%M", "%Y-%m-%d %H:%M", "%d %b %Y %H:%M"]
DISTANCES = {"5k": "5K", "10k": "10K", "half": "Half marathon", "marathon": "Marathon"}

def clean_name(v):
    words = re.sub(r"\s+", " ", v.strip()).split(" ")
    name = " ".join(w[:1].upper() + w[1:].lower() for w in words if w)
    return name or None

def clean_email(v):
    v = v.strip().lower()
    return v if EMAIL.fullmatch(v) else None

def clean_phone(v):
    digits = re.sub(r"\D", "", v)
    if digits.startswith("234"):
        digits = "0" + digits[3:]
    return digits if re.fullmatch(r"0\d{10}", digits) else None

def clean_joined(v):
    for fmt in FORMATS:
        try:
            local = datetime.strptime(v.strip(), fmt)
        except ValueError:
            continue
        return local.replace(tzinfo=LAGOS).astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    return None

def clean_distance(v):
    return DISTANCES.get(v.strip().lower())

CLEANERS = [("name", "Name", clean_name, "missing name"), ("email", "Email", clean_email, "bad email"),
            ("phone", "Phone", clean_phone, "bad phone"), ("joined", "Joined", clean_joined, "bad date"),
            ("distance", "Distance", clean_distance, "bad distance")]

def clean(text):
    reader = csv.DictReader(io.StringIO(text), delimiter=";")
    members, problems = [], []
    for row in reader:
        member, mine = {}, []
        for key, column, cleaner, message in CLEANERS:
            value = cleaner(row.get(column) or "")
            if value is None:
                mine.append(f"line {reader.line_num}: {message}")
            member[key] = value
        if mine:
            problems += mine
        else:
            members.append(member)
    return members, problems

def to_json(text):
    members, problems = clean(text)
    return json.dumps({"members": members, "problems": problems}, indent=2)
:::

:::think title="Clean once, at the edge"
All the messiness was handled in one place, as the data came in. Everything after `clean` can trust the data completely: every phone has 11 digits, every time is UTC, every distance is one of four labels. That's the pattern professional systems follow: validate and normalise at the boundary, report what you can't fix (never silently drop it), and keep the rest of the program simple.
:::

## Forge bonus: reading a calendar file

Calendar apps exchange events as **iCalendar** files (`.ics`), plain text with one property per line:

```
BEGIN:VEVENT
SUMMARY:Club run
DTSTART;TZID=Africa/Lagos:20261107T063000
DTEND;TZID=Africa/Lagos:20261107T080000
LOCATION:Lekki Phase 1
END:VEVENT
```

`DTSTART` is the start time in the basic ISO form `YYYYMMDDTHHMMSS`; `TZID=` names its time zone, or a time ending in `Z` is UTC.

:::exercise id=forge2 points=30 title="Forge bonus: reading a calendar file"
Write `read_events(ics_text)` returning a list of events (in the file's order), each a dictionary with `"summary"`, `"location"` (or `None`), `"start"` and `"end"` (both aware datetimes **in UTC**), between `BEGIN:VEVENT` and `END:VEVENT` lines. Parse each property line with a regex with named groups for the name, optional parameters after `;`, and the value after `:`. Then `agenda(ics_text, zone)` returning lines like `"Sat 07 Nov 06:30-08:00 Club run (Lekki Phase 1)"` in that zone's local time, sorted by start time (without the location in brackets if there isn't one).
@@starter
import re
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

@@tests
ICS = """BEGIN:VCALENDAR
BEGIN:VEVENT
SUMMARY:Club run
DTSTART;TZID=Africa/Lagos:20261107T063000
DTEND;TZID=Africa/Lagos:20261107T080000
LOCATION:Lekki Phase 1
END:VEVENT
BEGIN:VEVENT
SUMMARY:Online committee meeting
DTSTART:20261104T180000Z
DTEND:20261104T190000Z
END:VEVENT
END:VCALENDAR
"""

    "read_events"
    from datetime import datetime, timezone
    events = read_events(ICS)
    assert events[0]["summary"] == "Club run" and events[0]["location"] == "Lekki Phase 1"
    assert events[0]["start"] == datetime(2026, 11, 7, 5, 30, tzinfo=timezone.utc)
    assert events[1]["location"] is None and events[1]["end"] == datetime(2026, 11, 4, 19, 0, tzinfo=timezone.utc)
def test_agenda():
    "agenda"
    assert agenda(ICS, "Africa/Lagos") == ["Wed 04 Nov 19:00-20:00 Online committee meeting", "Sat 07 Nov 06:30-08:00 Club run (Lekki Phase 1)"]
    assert agenda(ICS, "Europe/London")[0] == "Wed 04 Nov 18:00-19:00 Online committee meeting"
@@hint
A pattern like `^(?P<name>[A-Z-]+)(?:;(?P<params>[^:]*))?:(?P<value>.*)$`. For a time value: if it ends in `Z`, parse `value[:-1]` with `"%Y%m%dT%H%M%S"` and attach UTC; otherwise find `TZID=` in the parameters and attach that zone, then convert to UTC.
@@solution
import re
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

LINE = re.compile(r"^(?P<name>[A-Z-]+)(?:;(?P<params>[^:]*))?:(?P<value>.*)$")

def parse_time(value, params):
    if value.endswith("Z"):
        return datetime.strptime(value[:-1], "%Y%m%dT%H%M%S").replace(tzinfo=timezone.utc)
    m = re.search(r"TZID=([^;]+)", params or "")
    zone = ZoneInfo(m.group(1)) if m else timezone.utc
    return datetime.strptime(value, "%Y%m%dT%H%M%S").replace(tzinfo=zone).astimezone(timezone.utc)

def read_events(ics_text):
    events, current = [], None
    for line in ics_text.splitlines():
        m = LINE.match(line.strip())
        if not m:
            continue
        name, params, value = m["name"], m["params"], m["value"]
        if name == "BEGIN" and value == "VEVENT":
            current = {"summary": None, "location": None, "start": None, "end": None}
        elif name == "END" and value == "VEVENT" and current is not None:
            events.append(current)
            current = None
        elif current is not None:
            if name == "SUMMARY":
                current["summary"] = value
            elif name == "LOCATION":
                current["location"] = value
            elif name == "DTSTART":
                current["start"] = parse_time(value, params)
            elif name == "DTEND":
                current["end"] = parse_time(value, params)
    return events

def agenda(ics_text, zone):
    tz = ZoneInfo(zone)
    lines = []
    for e in sorted(read_events(ics_text), key=lambda e: e["start"]):
        s, f = e["start"].astimezone(tz), e["end"].astimezone(tz)
        where = f" ({e['location']})" if e["location"] else ""
        lines.append(f"{s:%a %d %b %H:%M}-{f:%H:%M} {e['summary']}{where}")
    return lines
