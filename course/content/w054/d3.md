The loop lists every node after its parent (a depth-first order using a stack). Reading that list **backwards** puts every child before its parent, which is exactly the fill order a tree DP needs: by the time a node is processed, all its children are done.

## Children before parents

A rooted tree's DP defines a value per node from the values of its **children**: the size of its subtree, the best answer within its subtree, and so on. Recursion expresses that naturally, but a tree can be a long path (a "stick" of 100,000 nodes), far past the recursion limit. The standard fix:

1. Build the tree as an adjacency list from the edges, then walk it from the root with a stack, recording each node's **parent** and the **order** nodes were reached.
2. Process the nodes in **reverse** order: every child is then handled before its parent.

The walk from the root must skip the node it came from (each undirected edge appears in both nodes' lists). Forgetting the parent check makes the walk go back up the tree.

:::example
def rooted(n, edges, root=0):
    """Parent of each node and an order with parents before children."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    parent, order, stack = [None] * n, [], [root]
    seen = [False] * n
    seen[root] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v] = u
                stack.append(v)
    return parent, order

parent, order = rooted(6, [(0, 1), (0, 2), (1, 3), (1, 4), (2, 5)])
print(parent, order)
:::

## Take it or leave it

A company wants a party: each employee has a "fun" score, and nobody should attend with their **direct manager** (the org chart is a tree). Maximise the total fun. It's house robber on a tree: for each node keep two values,

- **take(v)** = the best in v's subtree if v attends = fun(v) + sum of skip(c) over children c;
- **skip(v)** = the best if v doesn't = sum of max(take(c), skip(c)) over children.

The answer is max(take(root), skip(root)). Two values per node, children first: O(n). (The general problem, a maximum-weight independent set, is NP-hard on arbitrary graphs; on trees it's this easy. Many hard graph problems become DPs on trees.)

:::example
def rooted(n, edges, root=0):
    """Parent of each node and an order with parents before children."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    parent, order, stack = [None] * n, [], [root]
    seen = [False] * n
    seen[root] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v] = u
                stack.append(v)
    return parent, order


def best_party(fun, edges):
    n = len(fun)
    parent, order = rooted(n, edges)
    take, skip = list(fun), [0] * n
    for v in reversed(order):
        p = parent[v]
        if p is not None:
            take[p] += skip[v]
            skip[p] += max(take[v], skip[v])
    return max(take[0], skip[0])

print(best_party([5, 3, 6, 2, 4, 1], [(0, 1), (0, 2), (1, 3), (1, 4), (2, 5)]))
:::

The children push their values into the parent's running totals, which avoids building a list of children at all.

## Combining children

Some answers aren't "a value in this subtree" but "a path through this node". The **diameter** of a weighted tree, the longest path between any two nodes, passes through some highest node v and goes down into two different children's subtrees. So keep

**down(v) = the longest path from v down into its subtree**,

and at each node combine the two largest values of down(c) + w(v, c) over its children: that's the longest path whose highest node is v. The diameter is the best over all nodes. It's "best ending here" again, with a tree for the line.

## Rerooting

Some questions want an answer for **every** node as if it were the root: "for each town, the total distance to all the other towns". Running a DP from every root costs O(n²). **Rerooting** gets all n answers in O(n) with two passes:

1. **Down pass** (children first): for a root of 0, compute `size(v)`, the number of nodes in v's subtree, and `down(v)`, the total distance from v to the nodes in its subtree: down(v) = sum of down(c) + size(c) over children (every node under c is one edge further from v).
2. **Up pass** (parents first): the answer at the root is down(0). Moving the root from p to its child c, the size(c) nodes in c's subtree each get one edge closer, and the other n − size(c) nodes one edge further: ans(c) = ans(p) − size(c) + (n − size(c)).

The second pass walks the order **forwards**, so each parent's answer is ready before its children's. The same pattern answers "the furthest node from each node", "the best place to put a depot" and more.

:::example
def rooted(n, edges, root=0):
    """Parent of each node and an order with parents before children."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    parent, order, stack = [None] * n, [], [root]
    seen = [False] * n
    seen[root] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v] = u
                stack.append(v)
    return parent, order


def all_distances(n, edges):
    parent, order = rooted(n, edges)
    size, down = [1] * n, [0] * n
    for v in reversed(order):
        p = parent[v]
        if p is not None:
            size[p] += size[v]
            down[p] += down[v] + size[v]
    ans = [0] * n
    ans[order[0]] = down[order[0]]
    for v in order[1:]:
        ans[v] = ans[parent[v]] - size[v] + (n - size[v])
    return ans

print(all_distances(6, [(0, 1), (0, 2), (2, 3), (2, 4), (2, 5)]))
:::

## DAGs in topological order

In a directed acyclic graph, a **topological order** lists every node before all the nodes it points to (Week 50's Kahn's algorithm). That's a fill order for any DP where a node's value depends on its predecessors:

- **Longest path** from a source: longest(v) = max over edges u → v of longest(u) + w. (On general graphs longest path is hard; on DAGs it's this loop. Shortest paths work the same way, even with negative weights.)
- **Counting paths** from s to t: paths(v) = sum of paths(u) over edges u → v, with paths(s) = 1.
- **Project scheduling**: tasks with durations and "must finish before" dependencies. The earliest each task can finish is its duration plus the latest finish among its prerequisites. The project's length is the longest path, and the tasks on it are **critical**: delay any one and the whole project slips. This is the **critical path method**, developed by James Kelley and Morgan Walker in the late 1950s for planning chemical plant work.

:::example
from collections import deque

def earliest_finish(durations, before):
    """before: (a, b) pairs, meaning a must finish before b starts."""
    succ = {t: [] for t in durations}
    need = {t: 0 for t in durations}
    for a, b in before:
        succ[a].append(b)
        need[b] += 1
    start = {t: 0 for t in durations}
    queue = deque(t for t in durations if need[t] == 0)
    finish = {}
    while queue:
        t = queue.popleft()
        finish[t] = start[t] + durations[t]
        for nxt in succ[t]:
            start[nxt] = max(start[nxt], finish[t])
            need[nxt] -= 1
            if need[nxt] == 0:
                queue.append(nxt)
    return finish

tasks = {"dig": 3, "pour": 2, "frame": 4, "wire": 2, "roof": 3, "paint": 1}
deps = [("dig", "pour"), ("pour", "frame"), ("frame", "wire"), ("frame", "roof"), ("wire", "paint"), ("roof", "paint")]
print(earliest_finish(tasks, deps))
:::

:::key
On a tree, walk from the root with a stack (skipping the parent) to get an order with parents first, then process it backwards so children come first: no deep recursion. Take-or-skip problems keep two values per node; path problems combine the best two children's values at each node; rerooting gets every node's answer in O(n) with a down pass and an up pass that adjusts the parent's answer for the child. On a DAG, a topological order is the fill order: longest and shortest paths, path counts, and the critical path of a project, whose tasks have no slack.
:::

def best_party(fun, edges):
    n = len(fun)
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    parent, order, stack = [None] * n, [], [0]
    seen = [False] * n
    seen[0] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v] = u
                stack.append(v)
    take, skip = list(fun), [0] * n
    for v in reversed(order):
        p = parent[v]
        if p is not None:
            take[p] += skip[v]
            skip[p] += max(take[v], skip[v])
    attends = [False] * n
    for v in order:
        p = parent[v]
        if (p is None or not attends[p]) and take[v] >= skip[v]:
            attends[v] = True
    return max(take[0], skip[0]), [v for v in range(n) if attends[v]]

def longest_trail(n, trails):
    adj = [[] for _ in range(n)]
    for a, b, w in trails:
        adj[a].append((b, w))
        adj[b].append((a, w))
    parent, weight_up, order, stack = [None] * n, [0] * n, [], [0]
    seen = [False] * n
    seen[0] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v], weight_up[v] = u, w
                stack.append(v)
    down = [0] * n
    first, second = [0] * n, [0] * n          # the two longest branches below each node
    best = 0
    for v in reversed(order):
        down[v] = first[v]
        best = max(best, first[v] + second[v])
        p = parent[v]
        if p is not None:
            branch = down[v] + weight_up[v]
            if branch > first[p]:
                first[p], second[p] = branch, first[p]
            elif branch > second[p]:
                second[p] = branch
    return best

from collections import deque

def _order(n, edges):
    succ = [[] for _ in range(n)]
    need = [0] * n
    for u, v, w in edges:
        succ[u].append((v, w))
        need[v] += 1
    queue = deque(v for v in range(n) if need[v] == 0)
    order = []
    while queue:
        u = queue.popleft()
        order.append(u)
        for v, _ in succ[u]:
            need[v] -= 1
            if need[v] == 0:
                queue.append(v)
    return order, succ

def count_paths(n, edges, s, t):
    order, succ = _order(n, edges)
    ways = [0] * n
    ways[s] = 1
    for u in order:
        if ways[u]:
            for v, _ in succ[u]:
                ways[v] += ways[u]
    return ways[t]

def longest_path(n, edges, s, t):
    order, succ = _order(n, edges)
    NEG = float("-inf")
    best, prev = [NEG] * n, [None] * n
    best[s] = 0
    for u in order:
        if best[u] == NEG:
            continue
        for v, w in succ[u]:
            if best[u] + w > best[v]:
                best[v], prev[v] = best[u] + w, u
    if best[t] == NEG:
        return None
    path = [t]
    while path[-1] != s:
        path.append(prev[path[-1]])
    return best[t], path[::-1]

from collections import deque

def schedule(durations, before):
    succ = {t: [] for t in durations}
    pred = {t: [] for t in durations}
    need = {t: 0 for t in durations}
    for a, b in before:
        succ[a].append(b)
        pred[b].append(a)
        need[b] += 1
    queue = deque(sorted(t for t in durations if need[t] == 0))
    order = []
    while queue:
        t = queue.popleft()
        order.append(t)
        for nxt in succ[t]:
            need[nxt] -= 1
            if need[nxt] == 0:
                queue.append(nxt)
    if len(order) != len(durations):
        raise ValueError("the dependencies have a cycle")
    earliest = {}
    for t in order:
        earliest[t] = max((earliest[p] + durations[p] for p in pred[t]), default=0)
    length = max((earliest[t] + durations[t] for t in order), default=0)
    latest = {}
    for t in reversed(order):
        latest[t] = min((latest[s] for s in succ[t]), default=length) - durations[t]
    critical = sorted(t for t in order if earliest[t] == latest[t])
    return length, critical

import itertools, random
def watches(n, edges, cams):
    seen = set(cams)
    for a, b in edges:
        if a in cams:
            seen.add(b)
        if b in cams:
            seen.add(a)
    return len(seen) == n
def brute(n, edges):
    for k in range(1, n + 1):
        for cams in itertools.combinations(range(n), k):
            if watches(n, edges, set(cams)):
                return k
    return 0

For the reconstruction, record each node's chosen state from the top: the root takes whichever of has and watched is cheaper. A child of a "has" node takes its cheapest of the three; a child of a "needs" node must be "watched"; for a "watched" node, children take the cheaper of has and watched, except the one child forced to "has" (the one where has(c) − min(has(c), watched(c)) is smallest), so remember which child that was.
@@solution
def _tree(n, corridors):
    adj = [[] for _ in range(n)]
    for a, b in corridors:
        adj[a].append(b)
        adj[b].append(a)
    parent, order, stack = [None] * n, [], [0]
    seen = [False] * n
    seen[0] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                parent[v] = u
                stack.append(v)
    children = [[] for _ in range(n)]
    for v in order[1:]:
        children[parent[v]].append(v)
    return order, children

def _solve(n, corridors):
    order, children = _tree(n, corridors)
    INF = float("inf")
    has, watched, needs, forced = [0] * n, [0] * n, [0] * n, [None] * n
    for v in reversed(order):
        kids = children[v]
        has[v] = 1 + sum(min(has[c], watched[c], needs[c]) for c in kids)
        needs[v] = sum(watched[c] for c in kids)
        if not kids:
            watched[v] = INF
        else:
            base = sum(min(has[c], watched[c]) for c in kids)
            c = min(kids, key=lambda c: has[c] - min(has[c], watched[c]))
            watched[v] = base + has[c] - min(has[c], watched[c])
            forced[v] = c
    return order, children, has, watched, needs, forced

def fewest_cameras(n, corridors):
    order, children, has, watched, needs, forced = _solve(n, corridors)
    return min(has[0], watched[0])

def camera_plan(n, corridors):
    order, children, has, watched, needs, forced = _solve(n, corridors)
    state = [None] * n
    state[0] = "has" if has[0] <= watched[0] else "watched"
    for v in order:
        for c in children[v]:
            if state[v] == "has":
                best = min(has[c], watched[c], needs[c])
                state[c] = "has" if has[c] == best else ("watched" if watched[c] == best else "needs")
            elif state[v] == "needs":
                state[c] = "watched"
            else:
                if c == forced[v]:
                    state[c] = "has"
                else:
                    state[c] = "has" if has[c] <= watched[c] else "watched"
    return [v for v in range(n) if state[v] == "has"]
