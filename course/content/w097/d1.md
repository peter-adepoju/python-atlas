## Warm-up

:::predict
nums, target = [3, 2, 4], 6
print([(i, j) for i in range(len(nums)) for j in range(i + 1, len(nums)) if nums[i] + nums[j] == target])
:::

That checks every pair: fine for three numbers, hopeless for a million (about half a million million pairs). Today's checks time your solutions on large inputs, so each problem needs the better idea, not just a correct one.

## The method

Interviewers want to see how you think as much as whether you finish. A method keeps you calm and shows your thinking:

1. **Clarify** (2 minutes): restate the problem; ask about input sizes, empty inputs, duplicates, negative numbers, what to return when there's no answer.
2. **Examples**: work one small example by hand, and one edge case. Say them aloud.
3. **A simple solution first**: describe the brute force and its complexity ("checking every pair is O(n²)"). It proves you understand the problem, and it's a fallback.
4. **Improve it**: what work is repeated? Could a dictionary, a sort, two pointers or a window remove it? Say the new complexity before coding.
5. **Code** it cleanly, talking as you go: good names, small helper functions.
6. **Test** by tracing your example through the code, then the edge cases. Find your own bugs before the interviewer does.
7. **Complexity**: time and space, with a reason.

If you're stuck, say what you're thinking; interviewers give hints to people who show their reasoning.

## Patterns to look for

- "Find a pair (or a complement)": a **dictionary** of what you've seen, O(n).
- "Longest or shortest stretch with a property": a **sliding window** with two indices.
- "Sorted input" or "pairs from both ends": **two pointers**.
- "Matching, nesting, most recent first": a **stack**.
- "Overlapping ranges": **sort by start**, then sweep.
- "Top k" or "most frequent": **count, then sort or use a heap**.

@@solution
def pair_with_sum(nums, target):
    seen = {}
    for j, x in enumerate(nums):
        if target - x in seen:
            return seen[target - x], j
        seen.setdefault(x, j)
    return None

@@solution
def longest_unique(s):
    last, start, best = {}, 0, 0
    for i, ch in enumerate(s):
        if last.get(ch, -1) >= start:
            start = last[ch] + 1
        last[ch] = i
        best = max(best, i - start + 1)
    return best

@@hint
Push opening brackets on a stack; a closing bracket must match the top.
@@solution
PAIRS = {")": "(", "]": "[", "}": "{"}

def balanced(s):
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in PAIRS:
            if not stack or stack.pop() != PAIRS[ch]:
                return False
    return not stack

@@tests
import random, time

def test_merge():
    "overlapping and touching"
    assert merge_intervals([(1, 3), (2, 6), (8, 10), (15, 18)]) == [(1, 6), (8, 10), (15, 18)]
    assert merge_intervals([(1, 4), (4, 5)]) == [(1, 5)] and merge_intervals([(5, 7), (1, 2)]) == [(1, 2), (5, 7)]
    assert merge_intervals([(1, 10), (2, 3), (4, 5)]) == [(1, 10)] and merge_intervals([]) == []

def test_fast():
    "100,000 intervals"
    rng = random.Random(1)
    items = [(x, x + 1) for x in range(0, 200_000, 2)]
    rng.shuffle(items)
    start = time.perf_counter()
    assert len(merge_intervals(items)) == 100_000
    assert time.perf_counter() - start < 2, "too slow: sort, then sweep once"
@@hint
Sort by start. Walk through, extending the last merged interval while the next one starts at or before its end.
@@solution
def merge_intervals(intervals):
    merged = []
    for start, end in sorted(intervals):
        if merged and start <= merged[-1][1]:
            merged[-1] = (merged[-1][0], max(merged[-1][1], end))
        else:
            merged.append((start, end))
    return merged
:::

import heapq
from collections import Counter

def top_words(words, k):
    counts = Counter(words)
    return heapq.nsmallest(k, counts, key=lambda w: (-counts[w], w))

import time

def test_windows():
    "repeats count"
    assert min_window("ADOBECODEBANC", "ABC") == "BANC"
    assert min_window("a", "a") == "a" and min_window("a", "aa") == "" and min_window("", "a") == ""
    assert min_window("aaflslflsldkalskaaa", "aaa") == "aaa" and min_window("abcabc", "cb") == "bc"

def test_fast():
    "100,000 characters"
    s = "x" * 100_000 + "abc"
    start = time.perf_counter()
    assert min_window(s, "cab") == "abc"
    assert time.perf_counter() - start < 2, "too slow: one window, moving forwards"
@@hint
Grow the window to the right until it contains everything (track how many characters are still missing), then shrink it from the left while it still does, recording the best.
@@solution
from collections import Counter

def min_window(s, t):
    if not t:
        return ""
    need, missing = Counter(t), len(t)
    best, left = (0, 0), 0
    for right, ch in enumerate(s, start=1):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        if missing == 0:
            while need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if best == (0, 0) or right - left < best[1] - best[0]:
                best = (left, right)
            need[s[left]] += 1
            missing += 1
            left += 1
    return s[best[0]:best[1]]
:::
