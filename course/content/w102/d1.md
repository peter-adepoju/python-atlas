## Values, decisions and loops

Everything is an object with a **type** (`int`, `float`, `str`, `bool`, `None`), and the type decides what operations mean (`3 * "ab"` repeats). Strings are immutable sequences: slicing, `split`, `join`, `replace`, f-strings with format specs (`f"{km:.1f}"`). Decisions use `if`/`elif`/`else` and truthiness (empty things are false). Loops: `while` for "until", `for` over any iterable, `range` for counting, `break` and `else` on loops.

:::example
for n in range(2, 20):
    for d in range(2, n):
        if n % d == 0:
            break
    else:
        print(n, end=" ")
print()
print(f"{1234.5678:,.2f}", 7 // 2, -7 // 2, 7 % -3, round(2.5), round(3.5))
:::

## Functions and collections

Functions take positional and keyword arguments, defaults (never mutable ones), `*args` and `**kwargs`; they return one object (often a tuple). Lists (ordered, mutable), tuples (fixed), dictionaries (key to value, insertion-ordered), sets (unique, fast membership). Comprehensions build them in one expression. `sorted(items, key=...)` is stable: sort by the secondary key first, or use a tuple key.

:::example
walks = [("Ada", 6.0), ("Bo", 12.5), ("Cy", 6.0), ("Ada", 3.5)]
totals = {}
for name, km in walks:
    totals[name] = totals.get(name, 0) + km
print(totals)
print(sorted(totals.items(), key=lambda kv: (-kv[1], kv[0])))
print({name for name, km in walks if km > 5}, [km * 2 for _, km in walks][:2])
:::

## Files, errors and recursion

Open files with `with`, and read text with an explicit encoding. Formats: `csv` for tables, `json` for nested data (keys become strings). Catch the **specific** exceptions you expect, and raise your own with clear messages. Recursion needs a base case and progress towards it; memoise overlapping calls. Complexity: count how work grows: a loop inside a loop over the same data is O(n²); a dictionary lookup is O(1) on average; sorting is O(n log n); binary search is O(log n).

:::example
import json

def depth(value):
    if isinstance(value, list):
        return 1 + max((depth(v) for v in value), default=0)
    return 0

print(depth([1, [2, [3, [4]]], []]))
text = json.dumps({1: "Mill", "km": [1.5, 2.0]})
print(text, json.loads(text)["1"])
try:
    int("six")
except ValueError as e:
    print("not a number:", e)
:::

## Objects

A class bundles data and behaviour; `__init__` sets up each instance; methods take `self`. Properties validate or compute attributes. The **data model** (`__repr__`, `__eq__`, `__lt__`, `__len__`, `__iter__`, `__contains__`) makes your objects work with Python's syntax. `@dataclass` writes `__init__`, `__repr__` and `__eq__` for you (`order=True` adds comparisons, `frozen=True` makes them immutable and hashable). Inheritance shares behaviour (`super()`), abstract base classes require methods, and composition ("has a") is often better than inheritance ("is a"). Type hints document intent. Patterns such as strategy (pass a function in) keep code open to change.

:::example
from dataclasses import dataclass, field

@dataclass(order=True)
class Walk:
    km: float
    route: str = field(compare=False)
    tags: list = field(default_factory=list, compare=False)

a, b = Walk(6.0, "Ridge"), Walk(3.5, "Lake")
a.tags.append("hilly")
print(sorted([a, b]), b.tags, a == Walk(6.0, "Other"))
:::

:::key
Types decide what operations mean; strings are immutable; loops can `break` and have `else`. Functions: no mutable defaults; collections: list, tuple, dict, set, comprehensions, stable `sorted` with tuple keys. Files with `with` and an encoding; JSON keys become strings; catch specific errors. Recursion: base case, progress, memoise. Complexity by how work grows. Classes, properties, the data model, dataclasses (`order`, `frozen`, `default_factory`), inheritance with `super()`, abstract methods, composition and strategy.
:::

@@tests

import csv
import io

def read_walks(text):
    walks, errors = [], []
    rows = csv.reader(io.StringIO(text))
    next(rows, None)
    for n, row in enumerate(rows, start=2):
        if len(row) != 3:
            errors.append(f"line {n}: expected 3 fields")
            continue
        date, km, minutes = row
        try:
            km, minutes = float(km), int(minutes)
        except ValueError:
            errors.append(f"line {n}: bad number")
            continue
        if km < 0 or minutes < 0:
            errors.append(f"line {n}: negative value")
            continue
        walks.append({"date": date, "km": km, "minutes": minutes})
    return walks, errors

def flatten(value):
    if not isinstance(value, (list, tuple)):
        return [value]
    out = []
    for item in value:
        out += flatten(item)
    return out

@@tests
import bisect

def test_search():
    "lo and hi"

    for t in (0, 1.5, 2.0, 2.1, 12.0, 13):

def first_at_least(sorted_km, target):
    lo, hi = 0, len(sorted_km)
    while lo < hi:
        mid = (lo + hi) // 2
        if sorted_km[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

@@starter

    ___
@@tests

    "the data model"
    m = Map()
    m.add("Mill", "Weir", 1.5)
    m.add("Weir", "Church", 2.0)
    assert len(m) == 3 and "Mill" in m and "Ridge" not in m and list(m) == ["Church", "Mill", "Weir"]
    assert m["Weir"] == {"Mill": 1.5, "Church": 2.0} and repr(m) == "Map(3 junctions, 2 paths)"

    except ValueError:

@@solution
class Map:
    def __init__(self):
        self._paths = {}

    def add(self, a, b, km):
        if km <= 0:
            raise ValueError("km must be positive")
        self._paths.setdefault(a, {})[b] = km
        self._paths.setdefault(b, {})[a] = km

    def __len__(self):
        return len(self._paths)

    def __contains__(self, name):
        return name in self._paths

    def __iter__(self):
        return iter(sorted(self._paths))

    def __getitem__(self, name):
        return dict(self._paths[name])

    def __repr__(self):
        paths = sum(len(n) for n in self._paths.values()) // 2
        return f"Map({len(self)} junctions, {paths} paths)"
:::

:::exercise id=abstract points=15 title="Inheritance with a contract"
Write an abstract base class `Exporter` (from `abc`) with an abstract method `format_route(stops, km)` and a concrete method `export(routes)` that joins `format_route` of each `(stops, km)` with newlines. Then two subclasses: `TextExporter` (`"Mill to Ridge (6.0 km)"`) and `CsvExporter` (`"Mill;Ridge,6.0"`: stops joined by `;`, then a comma and km). `Exporter()` itself must raise `TypeError`.
@@starter

    ___
@@tests
def test_exporters():
    "one interface, two behaviours"
    routes = [(["Mill", "Weir", "Ridge"], 6.0), (["Lake", "Mill"], 3.5)]
    assert TextExporter().export(routes) == "Mill to Weir to Ridge (6.0 km)\nLake to Mill (3.5 km)"
    assert CsvExporter().export(routes) == "Mill;Weir;Ridge,6.0\nLake;Mill,3.5"
    assert issubclass(TextExporter, Exporter) and isinstance(CsvExporter(), Exporter)
    try:
        Exporter()
    except TypeError:
        pass
    else:
        raise AssertionError("abstract")
@@solution
from abc import ABC, abstractmethod

class Exporter(ABC):
    @abstractmethod
    def format_route(self, stops, km):
        ...

    def export(self, routes):
        return "\n".join(self.format_route(stops, km) for stops, km in routes)

class TextExporter(Exporter):
    def format_route(self, stops, km):
        return f"{' to '.join(stops)} ({km} km)"

class CsvExporter(Exporter):
    def format_route(self, stops, km):
        return f"{';'.join(stops)},{km}"
:::

:::exercise id=challenge points=25 title="Challenge: a club ledger"
Write a class `Ledger` for a walking club's money. `record(date, account, amount, note)` adds a transaction (amounts in pence as ints; negative for spending); spending that would take an account below 0 raises `ValueError("not enough in ACCOUNT")`. `balance(account)` (0 for unknown accounts), `statement(account)` (lines `"DATE NOTE: +AMOUNT"` or `-AMOUNT` in pounds with 2 decimal places, oldest first, then `"balance: £X.XX"`), `to_json()` and `Ledger.from_json(text)` (a class method) round-trip every transaction.
@@starter
import json

class Ledger:
    ___
@@tests
def test_ledger():
    "classes, errors, formats"
    led = Ledger()
    led.record("2026-12-01", "kitty", 2500, "subs")
    led.record("2026-12-03", "kitty", -1250, "minibus")
    led.record("2026-12-02", "kitty", 500, "raffle")
    assert led.balance("kitty") == 1750 and led.balance("other") == 0
    assert led.statement("kitty") == ["2026-12-01 subs: +25.00", "2026-12-02 raffle: +5.00", "2026-12-03 minibus: -12.50", "balance: £17.50"]
    try:
        led.record("2026-12-04", "kitty", -5000, "too much")
    except ValueError as e:
        assert str(e) == "not enough in kitty"
    else:
        raise AssertionError("overspent")
    copy = Ledger.from_json(led.to_json())
    assert copy.statement("kitty") == led.statement("kitty") and isinstance(json.loads(led.to_json()), list)
@@solution
import json

class Ledger:
    def __init__(self):
        self.transactions = []

    def balance(self, account):
        return sum(t["amount"] for t in self.transactions if t["account"] == account)

    def record(self, date, account, amount, note):
        if amount < 0 and self.balance(account) + amount < 0:
            raise ValueError(f"not enough in {account}")
        self.transactions.append({"date": date, "account": account, "amount": amount, "note": note})

    def statement(self, account):
        rows = sorted((t for t in self.transactions if t["account"] == account), key=lambda t: t["date"])
        lines = [f"{t['date']} {t['note']}: {'+' if t['amount'] >= 0 else '-'}{abs(t['amount']) / 100:.2f}" for t in rows]
        lines.append(f"balance: £{self.balance(account) / 100:.2f}")
        return lines

    def to_json(self):
        return json.dumps(self.transactions)

    @classmethod
    def from_json(cls, text):
        ledger = cls()
        ledger.transactions = json.loads(text)
        return ledger
