## Warm-up

:::predict

Queue, stack, heap, and three bitwise operations: four structures answer "which comes next?" in four different ways (first in, last in, smallest), and bits answer questions about sets of flags in one machine operation.

## Linear structures

- **Arrays**: index in O(1); patterns: two pointers (sorted pairs, reversing), sliding windows (best stretch), prefix sums (stretch totals).
- **Linked lists**: O(1) insertion at a known node, O(n) to find it; slow and fast pointers.
- **Stacks**: most recent first: matching brackets, undo, evaluating expressions, monotonic stacks.
- **Queues** (`deque`): first in, first out: breadth-first search, buffers.
- **Hash tables** (`dict`, `set`): O(1) average lookup: counting, seen-before, grouping.

:::example
def evaluate(tokens):
    stack = []
    for t in tokens:
        if t in "+-*/":
            b, a = stack.pop(), stack.pop()
            stack.append({"+": a + b, "-": a - b, "*": a * b, "/": a / b}[t])
        else:
            stack.append(float(t))
    return stack.pop()

print(evaluate("3 4 + 2 *".split()), evaluate("10 2 8 * + 3 -".split()))
:::

## Trees, heaps and tries

- **Binary search trees**: left smaller, right larger; search, insert and delete in O(height); in-order traversal gives sorted order.
- **Heaps** (`heapq`): the smallest in O(1), push and pop in O(log n): top k, merging, running medians, Dijkstra.
- **Tries**: a tree of characters; everything under a prefix in O(prefix length) to find.

:::example
import heapq

walks = [("Ridge", 12.0), ("Lake", 3.5), ("Wood", 7.5), ("Weir", 1.5), ("Moor", 15.0)]
print(heapq.nlargest(2, walks, key=lambda w: w[1]), heapq.nsmallest(1, walks, key=lambda w: w[1]))
:::

## Graphs and strategies

- **Graphs**: adjacency lists; BFS for fewest steps, DFS for exploring and cycles, Dijkstra for weighted shortest paths, topological sort for dependencies, union-find for merging groups, Kruskal for spanning trees.
- **Greedy**: take the locally best choice when you can prove it's safe (interval scheduling by earliest end).
- **Backtracking**: try a choice, recurse, undo (combinations, word search).
- **Dynamic programming**: state, transition, base cases, order, when choices overlap and greedy fails.
- **Bits**: `n & (n - 1)` clears the lowest set bit; a power of two has exactly one bit set.

:::example
def max_walks(slots):
    count, free_at = 0, float("-inf")
    for start, end in sorted(slots, key=lambda s: s[1]):
        if start >= free_at:
            count, free_at = count + 1, end
    return count

print(max_walks([(1, 4), (3, 5), (0, 6), (5, 7), (8, 9), (5, 9)]), bin(40), 40 & 39, (64 & 63) == 0)
:::

:::key

@@solution
def pairs_summing(sorted_nums, target):
    lo, hi, out = 0, len(sorted_nums) - 1, []
    while lo < hi:
        total = sorted_nums[lo] + sorted_nums[hi]
        if total < target:
            lo += 1
        elif total > target:
            hi -= 1
        else:
            pair = (sorted_nums[lo], sorted_nums[hi])
            if not out or out[-1] != pair:
                out.append(pair)
            lo, hi = lo + 1, hi - 1
    return out

@@tests

    "left smaller, right larger"
    t = BST()
    for v in [50, 30, 70, 20, 40, 60, 80, 30]:
        t.insert(v)
    assert len(t) == 7 and 40 in t and 45 not in t and t.in_order() == [20, 30, 40, 50, 60, 70, 80] and t.height() == 3
    chain = BST()

@@solution
class _Node:
    def __init__(self, value):
        self.value, self.left, self.right = value, None, None

class BST:
    def __init__(self):
        self.root, self.size = None, 0

    def insert(self, value):
        if self.root is None:
            self.root, self.size = _Node(value), 1
            return
        node = self.root
        while True:
            if value == node.value:
                return
            side = "left" if value < node.value else "right"
            child = getattr(node, side)
            if child is None:
                setattr(node, side, _Node(value))
                self.size += 1
                return
            node = child

    def __contains__(self, value):
        node = self.root
        while node is not None:
            if value == node.value:
                return True
            node = node.left if value < node.value else node.right
        return False

    def __len__(self):
        return self.size

    def in_order(self):
        out, stack, node = [], [], self.root
        while stack or node:
            while node:
                stack.append(node)
                node = node.left
            node = stack.pop()
            out.append(node.value)
            node = node.right
        return out

    def height(self):
        best, stack = 0, [(self.root, 1)] if self.root else []
        while stack:
            node, depth = stack.pop()
            best = max(best, depth)
            stack += [(c, depth + 1) for c in (node.left, node.right) if c]
        return best

    for w in ["mill", "mile", "milestone", "moor", "mill"]:

@@solution
class PrefixCounter:
    def __init__(self):
        self.root = {"count": 0}

    def add(self, word):
        node = self.root
        node["count"] += 1
        for ch in word:
            node = node.setdefault(ch, {"count": 0})
            node["count"] += 1

    def count(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node:
                return 0
            node = node[ch]
        return node["count"]

`ways[0] = 1`; for each coin in turn (outer loop), for each amount from the coin up, `ways[a] += ways[a - coin]`. Coins on the outside count combinations, not orders.
@@solution
def fare_ways(coins, amount):
    ways = [1] + [0] * amount
    for coin in coins:
        for a in range(coin, amount + 1):
            ways[a] += ways[a - coin]
    return ways[amount]

        count += 1

:::exercise id=challenge points=25 title="Challenge: finding a word on a sign"

Use backtracking.
@@starter
def find_word(grid, word):
    ___
@@tests
GRID = ["MILL", "IRAE", "DGEK", "ERID"]

def test_find():
    "choose, recurse, undo"
    assert find_word(GRID, "MILL") == [(0, 0), (0, 1), (0, 2), (0, 3)]
    assert find_word(GRID, "RIDGE") == [(1, 1), (1, 0), (2, 0), (2, 1), (2, 2)]
    assert find_word(GRID, "GRID") == [(2, 1), (1, 1), (1, 0), (2, 0)] and find_word(GRID, "LAKE") is None
    assert find_word(GRID, "MID") == [(0, 0), (1, 0), (2, 0)] and find_word(GRID, "MIM") is None and find_word(GRID, "") == []
    assert find_word(["AB", "CD"], "ABDC") == [(0, 0), (0, 1), (1, 1), (1, 0)]
@@solution
def find_word(grid, word):
    if not word:
        return []
    rows, cols = len(grid), len(grid[0]) if grid else 0
    path, used = [], set()

    def explore(r, c, i):
        if not (0 <= r < rows and 0 <= c < cols) or (r, c) in used or grid[r][c] != word[i]:
            return False
        path.append((r, c))
        used.add((r, c))
        if i == len(word) - 1:
            return True
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            if explore(r + dr, c + dc, i + 1):
                return True
        path.pop()
        used.discard((r, c))
        return False

    for r in range(rows):
        for c in range(cols):
            if explore(r, c, 0):
                return path
    return None
