:::exercise id=mix_freeze points=10 title="Pin everything"
Write `pins(freeze_text)` returning a dictionary from lower-case package name to version from `pip freeze` output (lines of `name==version`; ignore other lines), and `outdated(pins_dict, latest)` returning sorted `"name: old -> new"` strings for packages whose latest version (from the `latest` dictionary) is newer, comparing versions as tuples of numbers.
@@starter

@@tests
def test_values():
    "several"
    p = pins("Requests==2.31.0\nrich==13.7.1\n-e git+https://example/x\nidna==3.4\n")
    assert p == {"requests": "2.31.0", "rich": "13.7.1", "idna": "3.4"}
    assert outdated(p, {"requests": "2.32.3", "rich": "13.7.1", "idna": "3.10"}) == ["idna: 3.4 -> 3.10", "requests: 2.31.0 -> 2.32.3"]
@@solution
def pins(freeze_text):
    out = {}
    for line in freeze_text.splitlines():
        if "==" in line and not line.startswith("-"):
            name, version = line.split("==")
            out[name.strip().lower()] = version.strip()
    return out

def as_tuple(v):
    return tuple(int(x) for x in v.split("."))

def outdated(pins_dict, latest):
    return sorted(f"{n}: {v} -> {latest[n]}" for n, v in pins_dict.items() if n in latest and as_tuple(latest[n]) > as_tuple(v))
:::

:::exercise id=mix_trace points=10 title="Count the calls"
Write `call_counts(func, *args)` that runs `func(*args)` with `sys.settrace` and returns a dictionary from function name to how many times functions with that name were called, counting only functions defined in the same file as `func`.
@@starter
import sys

@@tests
def test_values():
    "several"
    def fib(n):
        return n if n < 2 else fib(n - 1) + fib(n - 2)
    def outer():
        return fib(4) + len("abc")
    assert call_counts(outer) == {"outer": 1, "fib": 9}
@@solution
import sys

def call_counts(func, *args):
    counts = {}
    target = func.__code__.co_filename
    def tracer(frame, event, arg):
        if event == "call" and frame.f_code.co_filename == target:
            name = frame.f_code.co_name
            counts[name] = counts.get(name, 0) + 1
        return None
    old = sys.gettrace()
    sys.settrace(tracer)
    try:
        func(*args)
    finally:
        sys.settrace(old)
    return counts
:::

:::exercise id=mix_style points=10 title="Name checker"
Write `bad_names(source)` returning a sorted list of `(line, name, kind)` for top-level functions whose names aren't snake_case (`kind` is `"function"`), classes whose names don't start with a capital or contain `_` (`"class"`), and module-level variables whose names mix upper- and lower-case letters (`"variable"`), since variables should be `snake_case` and constants `UPPER_CASE`.
@@starter
import ast

@@tests
def test_values():
    "several"
    src = "MAX_SIZE = 10\nmaxSize = 3\ndef getTotal():\n    pass\ndef get_total():\n    pass\nclass bank_account:\n    pass\nclass BankAccount:\n    pass\n"
    assert bad_names(src) == [(2, "maxSize", "variable"), (3, "getTotal", "function"), (7, "bank_account", "class")]
@@solution
import ast

def bad_names(source):
    found = []
    for node in ast.parse(source).body:
        if isinstance(node, ast.FunctionDef) and node.name != node.name.lower():
            found.append((node.lineno, node.name, "function"))
        elif isinstance(node, ast.ClassDef) and (not node.name[0].isupper() or "_" in node.name):
            found.append((node.lineno, node.name, "class"))
        elif isinstance(node, ast.Assign):
            for t in node.targets:
                if isinstance(t, ast.Name) and t.id != t.id.lower() and t.id != t.id.upper():
                    found.append((node.lineno, t.id, "variable"))
    return sorted(found)

:::exercise id=mix_doc points=10 title="Docstring examples"
Write `example_count(func)` returning how many `>>>` examples a function's docstring has (0 if no docstring), and `passes(func)` returning `True` if every example passes, using `doctest.DocTestFinder` and `doctest.DocTestRunner` with the function's own name in the globals and output discarded.
@@starter
import doctest

@@tests
def test_values():
    "several"
    def double(x):
        """Twice x.

        >>> double(2)
        4
        >>> double("ab")
        'abab'
        """
        return x * 2
    def wrong(x):
        """>>> wrong(1)
        3
        """
        return x
    assert example_count(double) == 2 and passes(double)
    assert example_count(wrong) == 1 and not passes(wrong)
@@solution
import doctest

def example_count(func):
    return (func.__doc__ or "").count(">>>")

def passes(func):
    runner = doctest.DocTestRunner(verbose=False)
    for test in doctest.DocTestFinder().find(func, func.__name__, globs={func.__name__: func}):
        runner.run(test, out=lambda s: None)
    return runner.failures == 0
:::

## Forge: a project starter

A tidy Python project, ready for Git, GitHub and everything this week, looks like this:

```
weather/
├── .gitignore            keeps .venv, caches and secrets out of Git
├── README.md             what it is and how to run it
├── pyproject.toml        settings for tools (and, later, packaging)
├── requirements.txt      the packages it needs
├── src/
│   └── weather/
│       ├── __init__.py
│       └── main.py       def main() ... if __name__ == "__main__": main()
└── tests/
    └── test_main.py      (Week 24)
```

Putting the code in `src/` keeps it separate from the project's other files, a common layout for real projects.

:::exercise id=forge points=50 title="Forge: a project starter"
Write these functions, working with real files in the current folder (use the starter's `write` helper).

1. `create_project(name, packages=())`: create the layout above under a folder `name`, and return the sorted list of the paths created (relative, using `/`). File contents:
   - `.gitignore`: the lines `.venv/`, `__pycache__/`, `*.pyc`, `.env`, `dist/`.
   - `README.md`: `# NAME`, a blank line, `## Setup`, a blank line, then the four lines `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`, `python3 -m NAME.main` each indented by four spaces (a Markdown code block).
   - `pyproject.toml`: `[project]`, `name = "NAME"`, `version = "0.1.0"`, `requires-python = ">=3.10"`, a blank line, `[tool.ruff]`, `line-length = 88`.
   - `requirements.txt`: one package per line, sorted (empty if none).
   - `src/NAME/__init__.py`: a one-line docstring `"""NAME."""`.
   - `src/NAME/main.py`: a module docstring, a `main()` that prints `Hello from NAME`, and the `__main__` guard.
   - `tests/test_main.py`: `from NAME.main import main` and a `test_main()` function containing `main()`.
   Every file ends with a newline. Refuse to overwrite: if the folder already exists, raise `FileExistsError(name)`.
2. `check_project(name)`: return a sorted list of problems with an existing project folder: `"missing FILE"` for each of `README.md`, `.gitignore`, `requirements.txt`, `pyproject.toml` that's absent; `".gitignore does not ignore .venv"` if it exists without a `.venv/` line; `"no main.py with a __main__ guard"` unless some `main.py` under `src/` contains `__name__ == "__main__"`; and `"code without docstring: PATH"` for each `.py` file under `src/` whose module has no docstring (`ast.get_docstring`).
@@starter
import ast
import os

def write(path, text):
    """Write text to path, making folders first."""
    os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
    with open(path, "w") as f:
        f.write(text)

@@solution
import ast
import os

def write(path, text):
    """Write text to path, making folders first."""
    os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
    with open(path, "w") as f:
        f.write(text)

def create_project(name, packages=()):
    if os.path.exists(name):
        raise FileExistsError(name)
    files = {
        ".gitignore": ".venv/\n__pycache__/\n*.pyc\n.env\ndist/\n",
        "README.md": (f"# {name}\n\n## Setup\n\n    python3 -m venv .venv\n    source .venv/bin/activate\n"
                      f"    pip install -r requirements.txt\n    python3 -m {name}.main\n"),
        "pyproject.toml": (f'[project]\nname = "{name}"\nversion = "0.1.0"\nrequires-python = ">=3.10"\n\n'
                           "[tool.ruff]\nline-length = 88\n"),
        "requirements.txt": "".join(p + "\n" for p in sorted(packages)),
        f"src/{name}/__init__.py": f'"""{name}."""\n',
        f"src/{name}/main.py": (f'"""The {name} program."""\n\n\ndef main():\n    print("Hello from {name}")\n\n\n'
                                 'if __name__ == "__main__":\n    main()\n'),
        "tests/test_main.py": f"from {name}.main import main\n\n\ndef test_main():\n    main()\n",
    }
    for rel, text in files.items():
        write(os.path.join(name, rel), text)
    return sorted(files)

def check_project(name):
    problems = []
    for required in ("README.md", ".gitignore", "requirements.txt", "pyproject.toml"):
        if not os.path.exists(os.path.join(name, required)):
            problems.append(f"missing {required}")
    ignore = os.path.join(name, ".gitignore")
    if os.path.exists(ignore):
        with open(ignore) as f:
            if ".venv/" not in f.read().splitlines():
                problems.append(".gitignore does not ignore .venv")
    guarded = False
    for folder, dirs, files in os.walk(os.path.join(name, "src")):
        for file in files:
            if not file.endswith(".py"):
                continue
            full = os.path.join(folder, file)
            with open(full) as f:
                text = f.read()
            if file == "main.py" and '__name__ == "__main__"' in text:
                guarded = True
            if not ast.get_docstring(ast.parse(text)):
                rel = os.path.relpath(full, name).replace(os.sep, "/")
                problems.append(f"code without docstring: {rel}")
    if not guarded:
        problems.append("no main.py with a __main__ guard")
    return sorted(problems)
:::

## Forge bonus: are the requirements right?

Two common mistakes: importing a package that isn't in `requirements.txt` (the project works on your computer and fails everywhere else), and listing packages that are never used. A tool can check both, with one complication: some packages are imported under a different name from the one you install.

:::exercise id=forge2 points=30 title="Forge bonus: are the requirements right?"
Write `check_requirements(sources, requirements_text, local_modules=())` where `sources` is a dictionary from file name to code. Find every top-level module imported (as in Week 20's `imports_of`), ignore the standard library (`sys.stdlib_module_names`), `__future__` and the project's own `local_modules`, and translate module names to package names with the `IMPORT_TO_PACKAGE` table in the starter (anything not in it has the same name, lower-cased). Compare with the package names in `requirements_text` (lower-cased, without versions or comments) and return `{"missing": [...], "unused": [...]}`, both sorted.
@@starter
import ast
import sys

IMPORT_TO_PACKAGE = {"bs4": "beautifulsoup4", "PIL": "pillow", "yaml": "pyyaml", "sklearn": "scikit-learn", "cv2": "opencv-python"}

@@tests
SOURCES = {
    "app.py": "import os\nimport requests\nfrom bs4 import BeautifulSoup\nimport yaml\nfrom weather import helpers\n",
    "plots.py": "import json\nimport matplotlib.pyplot as plt\nfrom PIL import Image\n",
}
REQS = "requests==2.31.0\nbeautifulsoup4>=4.12\nrich  # pretty output\nPillow\n"
def test_values():
    "several"
    assert check_requirements(SOURCES, REQS, local_modules=["weather"]) == {"missing": ["matplotlib", "pyyaml"], "unused": ["rich"]}
    assert check_requirements({}, "") == {"missing": [], "unused": []}
@@hint
Parse requirements with the same name-then-specifier idea as Day 2: take characters while they're letters, digits, `-`, `_` or `.`.
@@solution
import ast
import sys

IMPORT_TO_PACKAGE = {"bs4": "beautifulsoup4", "PIL": "pillow", "yaml": "pyyaml", "sklearn": "scikit-learn", "cv2": "opencv-python"}

def imports_of(source):
    found = set()
    for node in ast.walk(ast.parse(source)):
        if isinstance(node, ast.Import):
            for a in node.names:
                found.add(a.name.split(".")[0])
        elif isinstance(node, ast.ImportFrom) and node.module and node.level == 0:
            found.add(node.module.split(".")[0])
    return found

def required_names(text):
    names = set()
    for line in text.splitlines():
        line = line.split("#")[0].strip()
        if not line:
            continue
        i = 0
        while i < len(line) and (line[i].isalnum() or line[i] in "-_."):
            i += 1
        names.add(line[:i].lower())
    return names

def check_requirements(sources, requirements_text, local_modules=()):
    skip = set(sys.stdlib_module_names) | {"__future__"} | set(local_modules)
    used = set()
    for code in sources.values():
        for module in imports_of(code):
            if module not in skip:
                used.add(IMPORT_TO_PACKAGE.get(module, module).lower())
    declared = required_names(requirements_text)
    return {"missing": sorted(used - declared), "unused": sorted(declared - used)}
