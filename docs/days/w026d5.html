Before you start

The rules. You have 2 hours and 50 minutes in total. Work alone. Close your notes, don’t use the tutor, and don’t search the web: the point is to find out what you can do, and the debrief can only help with gaps it can see. You may run your code and use Check my answer as often as you like.

The marks.

Part What Marks

Count a problem’s full marks only when every check passes. 108 (60%) passes Phase 2; 144 (80%) is a distinction. If you don’t pass, tomorrow’s debrief tells you what to revise, and you can take the exam again after the rest week.

Strategy. Read every problem first. Do the ones you’re sure of first, and don’t stay stuck on one for more than 20 minutes. Test small and awkward cases before pressing Check.

Part B: eight problems

Exercise10 points
B1: Count in nested lists

Write count_in(x, target): how many times target appears in x, where x may be a list containing values and further lists, to any depth. A value that isn’t a list counts as 1 if it equals target. Use recursion.

Exercise10 points
B2: Fewest coins

Write fewest_coins(amount, coins): the smallest number of coins (any number of each value in the tuple coins) that add up to exactly amount, or -1 if it can’t be done. fewest_coins(6, (1, 3, 4)) is 2. It must handle amounts up to 400 quickly.

Exercise10 points
B3: Predict

Answer each without running code.

Exercise15 points
B4: Whole square roots

Write int_sqrt(n): the largest whole number r with r * r <= n, for any whole number n of 0 or more, including very large ones like 10**40. Use binary search, without math, ** or pow.

Exercise15 points
B5: Sort like a person

Computers sort "photo10.jpg" before "photo2.jpg", because "1" comes before "2". Write natural_key(name) and natural_sort(names): sort ignoring case, with each run of digits compared as a number. Names that are equal by this rule keep their original order.

Exercise15 points
B6: Sessions across time zones

Write minutes_by_user(text) for JSON text: a list of sessions like {"user": "ada", "start": "2026-11-02T09:15:00+01:00", "end": "2026-11-02T08:45:00Z"}, with times in ISO format and any UTC offset. Return a dictionary from each user to their total minutes (a whole number), users in alphabetical order. A session that ends before it starts raises ValueError.

Bug hunt15 points
B7: Three bugs

top_customers(orders) takes (customer, pence) pairs and should return the three biggest spenders as (customer, total), biggest first, and A to Z for equal totals. It has three bugs. Fix them.

Exercise20 points
B8: Test an ISBN checker

is_isbn10(text) in isbn.py checks a 10-character book number: hyphens are ignored; the first nine characters must be digits; the last may be a digit or X (meaning 10, capital only); and the sum of each digit times its weight (10 for the first, down to 1 for the last) must divide by 11. Write pytest tests that pass on the real code and catch all six broken versions.

isbn.py
def is_isbn10(text):
    s = text.replace("-", "")
    if len(s) != 10 or not s[:9].isdigit():
        return False
    if not (s[9].isdigit() or s[9] == "X"):
        return False
    values = [int(c) for c in s[:9]] + [10 if s[9] == "X" else int(s[9])]
    return sum(v * w for v, w in zip(values, range(10, 0, -1))) % 11 == 0

Part C: a larger program

Exercise50 points
C: Train journeys

A small railway’s timetable arrives as CSV text with columns train, from, to, departs and arrives (times HH:MM, all on one day; no train runs past midnight). Write:

  1. load(text) returning (trains, problems). Each train is a dictionary with train, from and to (stripped) and departs and arrives in minutes after midnight. A row whose times can’t be read, or that doesn’t arrive after it departs, gives the problem line N (from reader.line_num) and is left out.
  2. departures(trains, station, after): the trains leaving station at or after minute after, sorted by departure time, then by train name.
  3. best_journey(trains, start, end, after): the journey from start to end, leaving at or after after, that arrives earliest, using one train, or two trains with a change at a station in between, where the second train leaves at least 5 minutes after the first arrives. Return (arrival, [train names]), or None if there’s no such journey. If journeys arrive at the same time, prefer the one with fewer trains, then the one that leaves latest (less waiting), then the list of names in alphabetical order.
  4. plan(text, start, end, after) with after as "HH:MM", returning one line: Take R1, arrive 10:42 or Take R1 then R7, arrive 10:42, or No journey.
