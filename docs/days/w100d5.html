Warm-up

For walking along a line, the point that minimises the total distance is the median, not the mean: moving towards the side with more people always helps until there are as many on each side. On a grid with paths along the axes, take the median separately in each direction: today’s second coding problem.

The loop

Coding round

Exercise10 points
Coding 1: The k-th smallest

Write kth_smallest(nums, k): the k-th smallest value (k counts from 1), in O(n log k) with a heap of size k, without sorting the whole list.

Exercise15 points
Coding 2: Where should we meet?

Walkers live at grid cells (row, col) and walk along grid lines. Write meeting_point(homes): the cell minimising the total walking distance, and that total, as ((row, col), total), using the median row and median column (the lower median when there’s an even number).

Design round

Exercise15 points
Design: storing walk-group chat

Write chat_plan(groups, messages_per_group_per_day, bytes_per_message, years, recent=50, copies=3): return a dict with messages_per_s (1 decimal place), stored_tb (all messages for the years, times copies, TB of 10^12 bytes, 1 decimal place), and cache_gb (the most recent recent messages of every group, kept in memory once, GB of 10^9 bytes, 1 decimal place).

Debugging round

Bug hunt10 points
Bytes are not text

The file was read as bytes, and adding bytes to a string raises TypeError: can't concat str to bytes. Decode it as UTF-8 so this prints Route: Mill to Ridge.

Bug hunt10 points
A default that was never stored

dict.get(key, []) returns a new empty list that isn’t stored, so appending to it changes nothing and this prints {}. Use setdefault so it prints {'Mill': ['ada', 'bo']}.

Exercise10 points
Debugging: durations that didn’t parse

parse_duration(text) should turn "1h05m", "45m", "2h" or "1h 5m" into minutes, but it only handles one shape. Rewrite it with a regular expression that allows optional hours and optional minutes (at least one), with optional spaces; raise ValueError("bad duration: TEXT") otherwise.

Python deep-dive round

Exercise15 points
Deep dive: a class decorator that writes repr

Write a class decorator auto_repr that reads the parameters of the class’s __init__ with inspect.signature (leaving out self) and gives the class a __repr__ showing ClassName(param=value, ...) with each value from the attribute of the same name, written with repr. It returns the same class.
