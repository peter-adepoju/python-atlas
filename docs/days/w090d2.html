Week 90, Day 2

Build

Today’s story is S12: share a route with someone who doesn’t use Waymark, by a link they can open, that stops working after a few days or when you revoke it, and that downloads as GeoJSON, the open format map tools understand. Sharing means strangers can reach part of the program, so it has to be designed with Week 79 in mind from the first line: codes nobody can guess, stored only as hashes, the same answer for “never existed”, “expired” and “revoked”, and careful checking of any GeoJSON that comes back in. You’ll build share codes, a share store, GeoJSON export and import, and the sharing API.

By the end of today you can

  • Generate unguessable share codes, and reason about their entropy
  • Store share codes as hashes, with expiry, revocation and a view count
  • Export a route as a GeoJSON Feature, and validate GeoJSON coming in
  • Turn imported coordinates back into junctions, refusing points that aren’t on the map
  • Design public endpoints that reveal nothing to people without a valid code

waymark_domain.py
import heapq


class UnknownPlace(LookupError):
    pass


class NoRoute(Exception):
    pass


def naismith_minutes(km, climb_m):
    return round(km / 5 * 60 + climb_m / 600 * 60)


class Route:
    def __init__(self, stops, km, climb_m):
        self.stops, self.km, self.climb_m = list(stops), km, climb_m

    @property
    def minutes(self):
        return naismith_minutes(self.km, self.climb_m)

    def __repr__(self):
        return f"Route({self.stops}, {self.km} km, {self.climb_m} m)"


class PathNetwork:
    def __init__(self, heights):
        self.heights = dict(heights)
        self.paths = {name: {} for name in self.heights}

    def _check(self, *names):
        for name in names:
            if name not in self.heights:
                raise UnknownPlace(name)

    def add_path(self, a, b, km):
        self._check(a, b)
        if km <= 0:
            raise ValueError("km must be positive")
        self.paths[a][b] = km
        self.paths[b][a] = km

    def climb(self, stops):
        return sum(max(0, self.heights[b] - self.heights[a]) for a, b in zip(stops, stops[1:]))

    def shortest(self, start, end):
        self._check(start, end)
        dist, prev, done = {start: 0}, {}, set()
        heap = [(0, start)]
        while heap:
            d, node = heapq.heappop(heap)
            if node in done:
                continue
            done.add(node)
            if node == end:
                break
            for nxt, km in sorted(self.paths[node].items()):
                if d + km < dist.get(nxt, float("inf")):
                    dist[nxt] = d + km
                    prev[nxt] = node
                    heapq.heappush(heap, (d + km, nxt))
        if end not in done:
            raise NoRoute(f"no route from {start} to {end}")
        stops = [end]
        while stops[-1] != start:
            stops.append(prev[stops[-1]])
        stops.reverse()
        return Route(stops, round(dist[end], 2), self.climb(stops))

waymark_geo.py
import math
from waymark_domain import PathNetwork
from waymark_map import HEIGHTS, PATHS

POSITIONS = {"Mill": (0.0, 0.0), "Weir": (1.4, 0.4), "Church": (2.8, 1.2), "Ridge": (4.4, 3.4), "Farm": (2.8, 2.4),
             "Wood": (2.0, 3.5), "Lake": (0.6, 2.8), "Island": (-3.0, 5.0)}


class GeoNetwork(PathNetwork):
    """A path network whose junctions also have positions, in kilometres east and north."""

    def __init__(self, heights, positions):
        super().__init__(heights)
        self.positions = dict(positions)

    def straight_km(self, a, b):
        return math.dist(self.positions[a], self.positions[b])


def sample_geo():
    network = GeoNetwork(HEIGHTS, POSITIONS)
    for a, b, km in PATHS:
        network.add_path(a, b, km)
    return network


def grid_network(size):
    """A size-by-size grid of junctions named 'r-c', 1 km apart, with slightly longer paths to their neighbours."""
    names = {(r, c): f"{r}-{c}" for r in range(size) for c in range(size)}
    heights = {name: ((r * 13 + c * 7) % 9) * 20 for (r, c), name in names.items()}
    positions = {name: (float(c), float(r)) for (r, c), name in names.items()}
    network = GeoNetwork(heights, positions)
    for (r, c), name in names.items():
        if c + 1 < size:
            network.add_path(name, names[(r, c + 1)], 1.0 + ((r * 7 + c * 3) % 5) / 10)
        if r + 1 < size:
            network.add_path(name, names[(r + 1, c)], 1.0 + ((r * 3 + c * 5) % 5) / 10)
    return network

Warm-up

Ten random bytes (80 bits) make a 16-character code from a 32-letter alphabet. To guess one valid code out of a million in use, an attacker would need around 2**80 / 10**6 attempts, more than a billion billion: the code is the key, so it must come from secrets, never from random.

Codes nobody can guess

A share link like waymark.example/s/mfrggzdfmztwq2lk is a bearer credential: whoever has it can open the route. So the code must be:

  • random from a secure source: secrets.token_bytes(10) (Week 79), never random, whose sequence can be predicted from a few outputs, and never a counter or a hash of the route name;
  • long enough: entropy is length × log2(alphabet size) bits; 80 bits is plenty for links that expire in days;
  • easy to type and read: base32 in lower case avoids confusable characters and case problems in URLs.

For testing, inject the source of random bytes (as with clocks): production passes secrets.token_bytes, tests pass something predictable.

Storing shares safely

Store each share as the SHA-256 hash of its code (like the reset tokens of Week 85), with the route, the time it was created, its expiry and whether it’s been revoked. A leaked database then gives an attacker no working links. Looking a code up means hashing it and finding the hash.

Answer every failure the same way: unknown, expired and revoked codes all get the same 404 with the same message. Different answers would let an attacker learn which codes once existed. The owner, who is signed in, can list their shares and revoke them; viewers can’t.

GeoJSON out and in

GeoJSON (an open standard, RFC 7946) represents shapes as JSON. A route is a Feature whose geometry is a LineString: a list of [x, y] positions (in real GeoJSON, [longitude, latitude], in that order, a common source of maps drawn in the sea), and whose properties hold anything else (name, distance, climb, time). Waymark’s positions are kilometres on a local grid rather than longitude and latitude, so its export is GeoJSON in shape for the sake of the exercise; a real export would convert them.

Coming in (a walker importing a route someone sent), GeoJSON is untrusted input: check the types, that coordinates is a list of at least two pairs of numbers, and then that each point is actually at a junction on the map (within a small tolerance), before treating it as a route.

The public endpoints

Method Path Who Result
POST /shares owner 201 with the code, URL and expiry; 400 for a bad number of days; 404 for an unknown route
GET /s/CODE anyone with the code 200 with the GeoJSON; 404 otherwise
DELETE /shares/CODE owner 204; 404 if there’s no such share
Key idea

Share codes are bearer credentials: make them from secrets (inject the byte source for tests), with enough entropy (length × log2(alphabet) bits; 80 is plenty), in a readable alphabet such as lower-case base32. Store only SHA-256 hashes of codes, with expiry, revocation and view counts. Give unknown, expired and revoked codes the same 404. Export routes as GeoJSON Features with LineString geometry in [x, y] order and properties; validate incoming GeoJSON’s structure, numbers and that every point is on the map.

Share codes

Write make_code(random_bytes, nbytes=10): call random_bytes(nbytes) and return its base32 encoding in lower case without = padding. Then entropy_bits(length, alphabet_size): the bits of entropy in a random code of that length, rounded to 1 place, and guesses_needed(bits, codes_in_use): the expected number of random guesses to hit any valid code, 2 ** bits / codes_in_use, as a whole number.

Exercise15 points
A share store

Write ShareStore(clock), where clock() returns the time in seconds. create(route, days, code) stores a share of route that expires days × 86400 seconds from now, keyed by the SHA-256 hex digest of code (never the code itself), and returns the expiry time. open(code) returns the route and adds one to the share’s views, or None if the code is unknown, revoked or expired (now >= expiry). revoke(code) returns whether there was an unrevoked share. views(code) returns its view count (or None). The store must not hold any code as given.

Bug hunt10 points
A route drawn in the sea

GeoJSON positions are [x, y] (longitude first), but this writes [y, x], so the route appears mirrored across the diagonal: it prints [[0.0, 0.0], [0.4, 1.4]]. Write them in the right order, so it prints [[0.0, 0.0], [1.4, 0.4]].

Bug hunt10 points
A link that lasted a second too long

The share should stop working at its expiry time, but the check uses >, so at exactly that moment it still opens: it prints open at expiry: True. Treat the expiry moment as expired, so it prints open at expiry: False.
