Week 77, Day 2

FastAPI

Flask asks you to read and check every input yourself. FastAPI takes a different approach: you describe each endpoint’s inputs with ordinary type hints (an int path parameter, an optional query string, a body that must look like this model), and the framework parses, converts and validates the request before your function runs, answering bad input with a detailed 422 error. The same hints produce the API’s documentation automatically. Today you’ll write FastAPI endpoints, Pydantic models, errors and dependencies, using minifast.py, a small copy that follows FastAPI’s and Pydantic’s own names, so your code also runs on the real thing.

By the end of today you can

  • Declare path, query and header parameters with type hints, defaults and constraints
  • Validate request bodies with Pydantic models, and shape responses with response_model
  • Raise HTTPException, and read FastAPI’s 422 validation errors
  • Share work with Depends, including yield dependencies and overrides in tests

"""A small subset of FastAPI (and of Pydantic's BaseModel) that runs in the page (Week 77).

Names and behaviour follow FastAPI's own, so code written against this module also runs with the
real FastAPI (pip install "fastapi[standard]"): FastAPI, BaseModel, Field, Query, Header, Depends,
HTTPException, JSONResponse, Response and TestClient (from fastapi.testclient on the real thing).
Parameters are read from your type hints: path parameters, query parameters, a JSON body from a
BaseModel, and dependencies. Bad input gets FastAPI's 422 response. It's a teaching copy: no
async, no OpenAPI page, and only common types (int, float, str, bool, lists, optional, models).
"""
import copy
import inspect
import json
import re
import typing
from http import HTTPStatus
from urllib.parse import parse_qsl, urlencode, urlsplit

_MISSING = object()


# ---------- validation -------------------------------------------------------------------------

class ValidationError(Exception):
    def __init__(self, errors):
        super().__init__(f"{len(errors)} validation error(s)")
        self._errors = errors

    def errors(self):
        return list(self._errors)


class FieldInfo:
    def __init__(self, default=_MISSING, ge=None, le=None, gt=None, lt=None, min_length=None, max_length=None, alias=None):
        self.default, self.ge, self.le, self.gt, self.lt = default, ge, le, gt, lt
        self.min_length, self.max_length, self.alias = min_length, max_length, alias


def Field(default=_MISSING, **kw):
    return FieldInfo(default, **kw)


def _err(loc, msg, kind):
    return {"loc": list(loc), "msg": msg, "type": kind}


def _optional(tp):
    args = typing.get_args(tp)
    if (typing.get_origin(tp) is typing.Union or type(tp).__name__ == "UnionType") and type(None) in args:
        rest = [a for a in args if a is not type(None)]
        return True, rest[0] if len(rest) == 1 else typing.Union[tuple(rest)]
    return False, tp


def _convert(value, tp, loc, errors, from_text=False):
    """Convert value to tp, appending errors; returns the value or _MISSING."""
    optional, tp = _optional(tp)
    if value is None:
        if optional:
            return None
        errors.append(_err(loc, "Input should not be None", "none_required"))
        return _MISSING
    origin = typing.get_origin(tp)
    if tp is typing.Any or tp is inspect.Parameter.empty:
        return value
    if isinstance(tp, type) and issubclass(tp, BaseModel):
        if isinstance(value, tp):
            return value
        if not isinstance(value, dict):
            errors.append(_err(loc, "Input should be a valid dictionary or object", "model_type"))
            return _MISSING
        return tp._validate(value, loc, errors)
    if origin in (list, tuple, set):
        if not isinstance(value, (list, tuple)):
            errors.append(_err(loc, "Input should be a valid list", "list_type"))
            return _MISSING
        (item_type,) = typing.get_args(tp)[:1] or (typing.Any,)
        out = [_convert(v, item_type, list(loc) + [i], errors, from_text) for i, v in enumerate(value)]
        return _MISSING if any(v is _MISSING for v in out) else origin(out)
    if tp is bool:
        if isinstance(value, bool):
            return value
        if isinstance(value, str) and value.lower() in ("true", "1", "yes", "on", "false", "0", "no", "off"):
            return value.lower() in ("true", "1", "yes", "on")
        errors.append(_err(loc, "Input should be a valid boolean", "bool_parsing"))
        return _MISSING
    if tp is int:
        if isinstance(value, int) and not isinstance(value, bool):
            return value
        if isinstance(value, str) and re.fullmatch(r"[+-]?\d+", value.strip()):
            return int(value)
        if isinstance(value, float) and value.is_integer():
            return int(value)
        errors.append(_err(loc, "Input should be a valid integer", "int_parsing"))
        return _MISSING
    if tp is float:
        if isinstance(value, (int, float)) and not isinstance(value, bool):
            return float(value)
        if isinstance(value, str):
            try:
                return float(value)
            except ValueError:
                pass
        errors.append(_err(loc, "Input should be a valid number", "float_parsing"))
        return _MISSING
    if tp is str:
        if isinstance(value, str):
            return value
        if from_text:
            return str(value)
        errors.append(_err(loc, "Input should be a valid string", "string_type"))
        return _MISSING
    if tp is dict or origin is dict:
        if isinstance(value, dict):
            return value
        errors.append(_err(loc, "Input should be a valid dictionary", "dict_type"))
        return _MISSING
    return value


def _constraints(value, info, loc, errors):
    if value is _MISSING or value is None or info is None:
        return value
    checks = [("ge", lambda v, n: v >= n, "greater than or equal to", "greater_than_equal"),
              ("gt", lambda v, n: v > n, "greater than", "greater_than"),
              ("le", lambda v, n: v <= n, "less than or equal to", "less_than_equal"),
              ("lt", lambda v, n: v < n, "less than", "less_than")]
    for attr, ok, words, kind in checks:
        limit = getattr(info, attr)
        if limit is not None and not ok(value, limit):
            errors.append(_err(loc, f"Input should be {words} {limit}", kind))
            return _MISSING
    if info.min_length is not None and len(value) < info.min_length:
        errors.append(_err(loc, f"Value should have at least {info.min_length} item{'s' if info.min_length != 1 else ''}"
                           if not isinstance(value, str) else
                           f"String should have at least {info.min_length} character{'s' if info.min_length != 1 else ''}",
                           "string_too_short" if isinstance(value, str) else "too_short"))
        return _MISSING
    if info.max_length is not None and len(value) > info.max_length:
        errors.append(_err(loc, f"String should have at most {info.max_length} characters", "string_too_long"))
        return _MISSING
    return value


class BaseModel:
    """Declare fields as annotations, with defaults or Field(...)."""

    @classmethod
    def _fields(cls):
        hints = typing.get_type_hints(cls)
        fields = {}
        for name, tp in hints.items():
            if name.startswith("_"):
                continue
            raw = getattr(cls, name, _MISSING)
            info = raw if isinstance(raw, FieldInfo) else FieldInfo(raw)
            fields[name] = (tp, info)
        return fields

    @classmethod
    def _validate(cls, data, loc, errors):
        values = {}
        before = len(errors)
        for name, (tp, info) in cls._fields().items():
            key = info.alias or name
            if key in data:
                value = _constraints(_convert(data[key], tp, list(loc) + [key], errors), info, list(loc) + [key], errors)
            elif info.default is not _MISSING:
                value = copy.deepcopy(info.default)
            else:
                errors.append(_err(list(loc) + [key], "Field required", "missing"))
                value = _MISSING
            values[name] = value
        if len(errors) > before:
            return _MISSING
        obj = cls.__new__(cls)
        obj.__dict__.update(values)
        return obj

    def __init__(self, **data):
        errors = []
        obj = type(self)._validate(data, [], errors)
        if errors:
            raise ValidationError(errors)
        self.__dict__.update(obj.__dict__)

    @classmethod
    def model_validate(cls, data):
        errors = []
        obj = cls._validate(data, [], errors)
        if errors:
            raise ValidationError(errors)
        return obj

    def model_dump(self):
        def dump(v):
            if isinstance(v, BaseModel):
                return v.model_dump()
            if isinstance(v, (list, tuple, set)):
                return [dump(x) for x in v]
            return v
        return {name: dump(getattr(self, name)) for name in type(self)._fields()}

    def __eq__(self, other):
        return type(other) is type(self) and self.model_dump() == other.model_dump()

    def __repr__(self):
        inside = " ".join(f"{k}={v!r}" for k, v in self.model_dump().items())
        return f"{type(self).__name__}({inside})"


# ---------- parameters and dependencies ---------------------------------------------------------

class Query(FieldInfo):
    pass


class Header(FieldInfo):
    pass


class _Depends:
    def __init__(self, dependency):
        self.dependency = dependency


def Depends(dependency):
    return _Depends(dependency)


class HTTPException(Exception):
    def __init__(self, status_code, detail=None, headers=None):
        super().__init__(detail)
        self.status_code = status_code
        self.detail = detail if detail is not None else HTTPStatus(status_code).phrase
        self.headers = headers or {}


class Response:
    media_type = "text/plain; charset=utf-8"

    def __init__(self, content=b"", status_code=200, headers=None, media_type=None):
        self.body = content.encode("utf-8") if isinstance(content, str) else content
        self.status_code = status_code
        self.headers = {k.lower(): v for k, v in (headers or {}).items()}
        if self.body:
            self.headers.setdefault("content-type", media_type or self.media_type)


class JSONResponse(Response):
    media_type = "application/json"

    def __init__(self, content=None, status_code=200, headers=None):
        super().__init__(json.dumps(content).encode("utf-8"), status_code, headers)


class Request:
    def __init__(self, method, path, query, headers, body):
        self.method, self.url_path, self.query_params = method, path, dict(query)
        self.headers = {k.lower(): v for k, v in headers.items()}
        self.body = body

    def json(self):
        return json.loads(self.body or b"null")


# ---------- the application ---------------------------------------------------------------------

class FastAPI:
    def __init__(self, title="FastAPI", version="0.1.0"):
        self.title, self.version = title, version
        self.routes = []
        self.dependency_overrides = {}

    def api_route(self, path, methods, status_code=200, response_model=None):
        names = re.findall(r"{(\w+)(?::path)?}", path)
        regex = re.compile("^" + re.sub(r"{(\w+)(:path)?}", lambda m: f"(?P<{m.group(1)}>{'.+' if m.group(2) else '[^/]+'})", path) + "$")

        def decorate(func):
            for method in methods:
                self.routes.append((method, regex, names, func, status_code, response_model))
            return func
        return decorate

    def get(self, path, **kw):
        return self.api_route(path, ["GET"], **kw)

    def post(self, path, **kw):
        return self.api_route(path, ["POST"], **kw)

    def put(self, path, **kw):
        return self.api_route(path, ["PUT"], **kw)

    def patch(self, path, **kw):
        return self.api_route(path, ["PATCH"], **kw)

    def delete(self, path, **kw):
        return self.api_route(path, ["DELETE"], **kw)

    def _solve(self, func, request, path_values, errors, cleanups, cache):
        func = self.dependency_overrides.get(func, func)
        if func in cache:
            return cache[func]
        hints = typing.get_type_hints(func)
        kwargs = {}
        for name, param in inspect.signature(func).parameters.items():
            tp = hints.get(name, str if param.annotation is inspect.Parameter.empty else param.annotation)
            default = param.default
            if isinstance(default, _Depends):
                kwargs[name] = self._solve(default.dependency, request, path_values, errors, cleanups, cache)
            elif tp is Request:
                kwargs[name] = request
            elif name in path_values:
                kwargs[name] = _constraints(_convert(path_values[name], tp, ["path", name], errors, True),
                                            default if isinstance(default, FieldInfo) else None, ["path", name], errors)
            elif isinstance(tp, type) and issubclass(tp, BaseModel):
                try:
                    data = json.loads(request.body) if request.body else _MISSING
                except ValueError:
                    errors.append(_err(["body"], "JSON decode error", "json_invalid"))
                    continue
                if data is _MISSING:
                    if default is not inspect.Parameter.empty:
                        kwargs[name] = default
                    else:
                        errors.append(_err(["body"], "Field required", "missing"))
                    continue
                kwargs[name] = _convert(data, tp, ["body"], errors)
            else:
                info = default if isinstance(default, FieldInfo) else FieldInfo(default if default is not inspect.Parameter.empty else _MISSING)
                where = "header" if isinstance(default, Header) else "query"
                key = info.alias or (name.replace("_", "-") if where == "header" else name)
                if where == "header":
                    raw = request.headers.get(key.lower(), _MISSING)
                elif typing.get_origin(_optional(tp)[1]) is list:
                    found = [v for k, v in request._pairs if k == key]
                    raw = found if found else _MISSING
                else:
                    raw = request.query_params.get(key, _MISSING)
                if raw is _MISSING:
                    if info.default is _MISSING:
                        errors.append(_err([where, key], "Field required", "missing"))
                    else:
                        kwargs[name] = info.default
                    continue
                kwargs[name] = _constraints(_convert(raw, tp, [where, key], errors, True), info, [where, key], errors)
        if errors:
            return _MISSING
        result = func(**kwargs)
        if inspect.isgenerator(result):
            gen = result
            result = next(gen)
            cleanups.append(gen)
        cache[func] = result
        return result

    def handle(self, method, path, query_pairs, headers, body):
        request = Request(method, path, query_pairs, headers, body)
        request._pairs = list(query_pairs)
        allowed = []
        for m, regex, names, func, status_code, response_model in self.routes:
            match = regex.match(path)
            if not match:
                continue
            if m != method:
                allowed.append(m)
                continue
            errors, cleanups = [], []
            try:
                try:
                    result = self._solve(func, request, match.groupdict(), errors, cleanups, {})
                    if errors:
                        return JSONResponse({"detail": errors}, 422)
                except HTTPException as e:
                    return JSONResponse({"detail": e.detail}, e.status_code, e.headers)
                return self._respond(result, status_code, response_model)
            finally:
                for gen in reversed(cleanups):
                    try:
                        next(gen)
                    except StopIteration:
                        pass
        if allowed:
            return JSONResponse({"detail": "Method Not Allowed"}, 405, {"allow": ", ".join(sorted(set(allowed)))})
        return JSONResponse({"detail": "Not Found"}, 404)

    @staticmethod
    def _respond(result, status_code, response_model):
        if isinstance(result, Response):
            return result
        if response_model is not None:
            data = result.model_dump() if isinstance(result, BaseModel) else result
            if isinstance(data, list):
                result = [{k: d[k] for k in response_model._fields()} if isinstance(d, dict) else d.model_dump() for d in
                          [x.model_dump() if isinstance(x, BaseModel) else x for x in data]]
            else:
                result = {k: data[k] for k in response_model._fields()}
        if status_code == 204:
            return Response(b"", 204)

        def plain(v):
            if isinstance(v, BaseModel):
                return v.model_dump()
            if isinstance(v, (list, tuple)):
                return [plain(x) for x in v]
            if isinstance(v, dict):
                return {k: plain(x) for k, x in v.items()}
            return v
        return JSONResponse(plain(result), status_code)

    @property

class TestClient:

        self.app = app

    def request(self, method, url, params=None, json=None, headers=None, content=None):
        parts = urlsplit(url)
        pairs = parse_qsl(parts.query, keep_blank_values=True)

        body = b""

            hdrs.setdefault("content-type", "application/json")
        elif content is not None:
            body = content.encode("utf-8") if isinstance(content, str) else content
        return _TestResponse(self.app.handle(method.upper(), parts.path or "/", pairs, hdrs, body))

Warm-up

The function never parsed anything: the type hint item_id: int told FastAPI to take that part of the path, convert it to an integer, and refuse the request with a 422 and a precise explanation (where, what and why) when it isn’t one. q: str | None = None became an optional query parameter. That’s the whole idea of FastAPI: declare what you expect, and the framework enforces it.

Parameters from type hints

from fastapi import FastAPI, Query, Header

app = FastAPI()

@app.get("/books/{book_id}")
def get_book(book_id: int, include_reviews: bool = False,
             limit: int = Query(10, ge=1, le=100), x_request_id: str | None = Header(None)):
    ...

FastAPI looks at each parameter of the function:

  • If its name appears in the path ({book_id}), it’s a path parameter, converted to its type.
  • If it’s a simple type (int, float, str, bool, or a list of them), it’s a query parameter: required if it has no default, optional otherwise. bool accepts true, 1, yes and so on.
  • Query(default, ge=, le=, gt=, lt=, min_length=, max_length=) adds constraints; Header(...) reads a header instead (with _ in the name becoming -: x_request_id reads X-Request-Id).
  • If its type is a Pydantic model, it’s the JSON body (next section).

Decorators set the method and the success status: @app.post("/books", status_code=201). Return a dict, a list or a model and FastAPI sends JSON; return a JSONResponse(content, status_code, headers) for full control.

On your own computer FastAPI also writes interactive documentation from all of this: run the app and open /docs to see every endpoint, its parameters and its models, and try requests from the browser. Real FastAPI endpoints can be async def; FastAPI is built on ASGI, the asynchronous successor to WSGI (Week 67’s event loops). The copy here runs ordinary functions only.

Models

A Pydantic model describes structured data with type hints:

from pydantic import BaseModel, Field

class BookIn(BaseModel):
    title: str = Field(min_length=1, max_length=200)
    author: str
    year: int = Field(ge=1450, le=2100)
    tags: list[str] = []
  • Fields without a default are required. Field(...) adds constraints like Query’s.
  • Validating converts where it’s safe ("1815" becomes 1815 for an int field) and collects every problem rather than stopping at the first: BookIn.model_validate(data) raises a ValidationError whose .errors() lists them, each with a loc (where), a msg and a type.
  • Models nest: a field can be another model, or a list of models.
  • .model_dump() turns a model back into a dict.

In an endpoint, a model-typed parameter is the body: def create(book: BookIn) receives a validated BookIn, and invalid JSON or invalid fields become a 422 automatically.

Output models. @app.get("/users/{id}", response_model=UserOut) filters what’s returned to just UserOut’s fields, whatever the function returns. Separate input and output models are a good habit: the input model has the password, the output model never does.

Errors

  • raise HTTPException(status_code=404, detail="no book 7") stops the endpoint and sends {"detail": "no book 7"} with that status; headers= can add headers (such as WWW-Authenticate on a 401).
  • Validation errors get 422 Unprocessable Content with {"detail": [...]}: a list of errors, each with loc (such as ["query", "limit"], ["path", "book_id"] or ["body", "year"]), msg and type. Clients can show each message next to the right form field.
  • An unknown path gets 404 with {"detail": "Not Found"}; a known path with the wrong method, 405.

Because validation happens before your code, an endpoint’s body only ever deals with valid data. Business rules that types can’t express (does this author exist? is this title taken?) still need HTTPExceptions of your own: 404, 409 Conflict and so on.

Dependencies

Many endpoints need the same things: a database session, the current user, pagination settings. FastAPI’s dependency injection declares them as parameters with Depends:

def get_db():
    db = SessionLocal()
    try:
        yield db                     # the endpoint runs here
    finally:
        db.close()                   # then this runs, even after an error

def current_user(x_token: str = Header(), db = Depends(get_db)):
    user = db.user_for_token(x_token)
    if user is None:
        raise HTTPException(401, "invalid token")
    return user

@app.get("/me")
def me(user = Depends(current_user)):
    return {"name": user.name}
  • A dependency is a function whose own parameters are resolved the same way (path, query, headers, body, other dependencies), so they chain.
  • A dependency that yields works like a context manager (Week 61): code before the yield runs first, the value is passed in, and code after it runs when the response is ready.
  • Within one request, each dependency runs once, however many endpoints or other dependencies ask for it.
  • In tests, app.dependency_overrides[get_db] = fake_db swaps a dependency for a fake (Week 72’s fakes), with no change to the endpoints.
Key idea

FastAPI reads endpoints’ type hints: names in the path are path parameters; simple types are query parameters (required without a default); Query and Header add constraints and read headers; a Pydantic model parameter is the JSON body. Conversion and validation happen first, so bad input gets 422 with detail errors giving loc, msg and type. Models declare fields with types, defaults and Field constraints; model_validate collects every error; model_dump converts back; response_model filters output (use separate in and out models). HTTPException(status, detail, headers) sends {“detail”: …}. Depends injects shared work (database sessions, the current user, pagination), chained, once per request, with yield for clean-up, and replaceable in tests with dependency_overrides. Real FastAPI is ASGI, supports async def, and documents itself at /docs.

Challenge: a reading-list API

Write create_app(store), where store is a dict {"users": {token: name}, "books": {}}. Dependencies: current_user (from an Authorization: Bearer TOKEN header, raising 401 with detail "not authenticated" and the header WWW-Authenticate: Bearer if it’s missing or unknown) and get_store (returning store). Model BookIn (title: 1 to 200 characters, author: at least 1 character, rating: optional int from 1 to 5). Endpoints, all requiring a user, with each user seeing only their own books: POST /books (201, the book with an id; ids count up across all users from 1); GET /books with query author (optional, any case) and min_rating (optional, 1 to 5), returning the list by id; GET /books/{book_id} (404 with detail "no such book" for a missing book or one belonging to someone else, so ids don’t leak who has what); and DELETE /books/{book_id} (204, or the same 404).
