Before you start

The rules. You have 2 hours in total. Work alone: notes closed, no tutor, no web. You may run your code and use Check my answer as often as you like.

The marks.

Part What Marks
A 10 quiz questions 10 (1 each)
B 6 problems 90
Total 100

Count a problem’s full marks only when every check passes. 60 is a good result; 80 an excellent one.

Strategy. Read every problem first and write, for each, the pattern you’d use. Do the ones you’re sure of first; don’t stay stuck on one for more than 20 minutes. Test small and awkward cases (empty input, one item, ties, duplicates) before pressing Check.

Part A: quiz

Quiz10 questions

Part B: six problems

Exercise10 points
B1: At most k kinds

Write longest_with_k_kinds(s, k): the length of the longest substring of s with at most k different characters, in O(n). Then count_with_k_kinds(s, k): how many (non-empty) substrings have at most k different characters, also in O(n).

Exercise15 points
B2: Spreading mould

A store-room is a grid of strings: "." empty, "F" fresh fruit, "M" mouldy fruit. Each minute, every fresh fruit next to (up, down, left or right) a mouldy one becomes mouldy. Write minutes_until_spoiled(grid): the minutes until no fresh fruit is left, 0 if there’s none to begin with, or -1 if some fruit never spoils. Then spoil_times(grid): a dict from each fruit’s (row, col) to the minute it becomes mouldy (0 for those mouldy at the start); fruit that never spoils is left out.

Exercise15 points
B3: The fewest words

Write fewest_words(text, words): a list of dictionary words that join to give text using as few words as possible, or None if it can’t be split. (Up to 2,000 characters; words up to 20 characters.) On a tie, any fewest split is accepted. fewest_words("", words) is [].

Exercise15 points
B4: The kth best score so far

A leaderboard shows the k-th highest score so far. Write a class KthBest(k, scores=()) whose method add(score) records a score and returns the k-th highest score recorded so far (None while there are fewer than k). Each add must be O(log k): keep a min-heap of the top k. Also top(): the current top k scores, highest first.

Exercise20 points
B5: The biggest rectangle

Write largest_in_histogram(heights): the largest area of a rectangle under a histogram of bars of width 1, in O(n), with a monotonic stack. Then largest_block(grid): the largest rectangle of "1"s in a grid of "0" and "1" strings, by building a histogram of column heights row by row.

Bug hunt15 points
B6: Three bugs

longest_rising(nums) should return one longest strictly increasing subsequence in O(n log n), by patience with parent links. It has three bugs: it uses bisect_right (so equal values extend a run), it never records each element’s parent, and it returns the subsequence backwards. Fix them so this prints [2, 3, 7, 18].

When you finish

Add up your marks: 1 for each quiz question you got right first time, and the full marks for each problem whose checks all pass. Write down your total, the time you took, and a note of every problem you didn’t finish or found hard. Don’t look anything up yet: Saturday’s debrief goes through every one. Tomorrow: timed set 5.
