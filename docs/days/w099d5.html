Warm-up

list.sort() sorts in place and returns None; sorted() returns a new list. Mixing them up gives a None that fails much later, far from the cause: one of today’s debugging bugs.

The loop

Coding round

Exercise10 points
Coding 1: Products without division

Write products_except_self(nums): for each position, the product of every other number, without using division, in O(n).

Exercise15 points
Coding 2: How few hops?

Junctions are in a line; reach[i] is how many junctions ahead you can hop from junction i. Write fewest_hops(reach): the fewest hops from the first junction to the last, or -1 if it can’t be reached, greedily in O(n).

Design round

Exercise15 points
Design: storing walkers’ photos

Write photo_storage(users, photos_per_user_per_year, years, sizes_kb, copies=3): every photo is stored at each size in sizes_kb (for example the original, a large view and a thumbnail). Return a dict with photos (total), tb_raw (one copy of every size, in TB of 10^9 kB, 1 decimal place), tb_stored (times copies, 1 decimal place) and thumbnail_share (the smallest size’s share of the total, as a percentage to 1 decimal place).

Debugging round

Bug hunt10 points
Sorted into nothing

sort() returns None, so ordered is None and ordered[0] fails. Use sorted() so this prints 3.0 (and leaves walks in its original order).

Bug hunt10 points
Comparing times from two zones

One time has a time zone and the other doesn’t, so comparing them raises TypeError: can't compare offset-naive and offset-aware datetimes. Give the naive time the UTC zone so this prints True.

Exercise10 points
Debugging: a name that wasn’t equal

is_member(name, members) uses is to compare strings, which compares identity: it happens to work for some strings and not others. Fix it to compare values, ignoring case and surrounding spaces.

Python deep-dive round

Exercise15 points
Deep dive: an iterable you can loop over twice

Write a class Route(stops) that is iterable (each for loop over it starts again from the first stop) by returning a new iterator from __iter__, and a separate iterator class RouteIterator with __iter__ and __next__ that raises StopIteration at the end. len(route) gives the number of stops.

The hard question

Exercise25 points
Coding 3: The largest rectangle

heights are bars of width 1. Write largest_rectangle(heights): the area of the largest rectangle that fits under them, in O(n) with a monotonic stack.
