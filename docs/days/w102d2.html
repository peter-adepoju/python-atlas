Week 102, Day 2

Review: DSA

Phase 4 and the interview weeks gave you a toolbox of structures and techniques. Today you sort the toolbox, so that on the exam the right tool comes to hand quickly: arrays and two pointers, stacks and queues, hash tables, trees and heaps, tries, graphs, greedy choices and backtracking, dynamic programming, and a little bit manipulation. Each section has a short reminder and an example; the exercises are mixed, and each says nothing about which tool to use.

By the end of today you can

  • Choose the right structure for a problem from its shape
  • Use stacks, hash tables, heaps and tries fluently
  • Build and walk a binary search tree
  • Pick greedy, backtracking or dynamic programming correctly
  • State the complexity of every solution

Warm-up

Queue, stack, heap, and three bitwise operations: four structures answer “which comes next?” in four different ways (first in, last in, smallest), and bits answer questions about sets of flags in one machine operation.

Linear structures

  • Arrays: index in O(1); patterns: two pointers (sorted pairs, reversing), sliding windows (best stretch), prefix sums (stretch totals).
  • Linked lists: O(1) insertion at a known node, O(n) to find it; slow and fast pointers.
  • Stacks: most recent first: matching brackets, undo, evaluating expressions, monotonic stacks.
  • Queues (deque): first in, first out: breadth-first search, buffers.
  • Hash tables (dict, set): O(1) average lookup: counting, seen-before, grouping.

Trees, heaps and tries

  • Binary search trees: left smaller, right larger; search, insert and delete in O(height); in-order traversal gives sorted order.
  • Heaps (heapq): the smallest in O(1), push and pop in O(log n): top k, merging, running medians, Dijkstra.
  • Tries: a tree of characters; everything under a prefix in O(prefix length) to find.

Graphs and strategies

  • Graphs: adjacency lists; BFS for fewest steps, DFS for exploring and cycles, Dijkstra for weighted shortest paths, topological sort for dependencies, union-find for merging groups, Kruskal for spanning trees.
  • Greedy: take the locally best choice when you can prove it’s safe (interval scheduling by earliest end).
  • Backtracking: try a choice, recurse, undo (combinations, word search).
  • Dynamic programming: state, transition, base cases, order, when choices overlap and greedy fails.
  • Bits: n & (n - 1) clears the lowest set bit; a power of two has exactly one bit set.
Key idea

Arrays: two pointers, windows, prefix sums; stacks for most recent, queues for first in; hash tables for O(1) lookups. BSTs give sorted order in O(height); heaps give the smallest in O(1) and push/pop in O(log n); tries find prefixes. Graphs: BFS, DFS, Dijkstra, topological sort, union-find. Greedy only when provably safe; backtrack to explore; DP when choices overlap. State every complexity.

Exercise10 points
Pairs from both ends

Write pairs_summing(sorted_nums, target): all distinct pairs (a, b) with a <= b from a sorted list that add up to target, in increasing order of a, using two pointers in O(n).

Exercise15 points
A binary search tree

Write a class BST with insert(value) (ignoring duplicates), __contains__, in_order() (a sorted list), height() (0 for empty, 1 for a single node) and __len__. Use iteration for insert and __contains__.

Exercise10 points
The nearest cafés

Cafés are at (name, x, y) in km from the walker at (0, 0). Write nearest(cafes, k): the names of the k nearest (straight-line distance; ties by name), nearest first, using heapq.

Exercise10 points
Prefixes, counted

Write a class PrefixCounter with add(word) and count(prefix): how many added words start with prefix (words may be added more than once; each counts), in O(len(prefix)) per count, using a trie whose nodes store how many words pass through them.

Exercise10 points
The most guided walks

Walk leaders can lead one walk at a time; a walk ending at 5 lets a leader start another at 5. Write most_walks(slots): the largest number of (start, end) walks one leader can lead, greedily by earliest end.

Exercise10 points
Ways to make a fare

Write fare_ways(coins, amount): the number of different combinations of coins (order doesn’t matter, any number of each) that make amount.

Exercise10 points
Flags in a number

Walk features are bits: 1 hilly, 2 dogs welcome, 4 café, 8 circular. Write features(flags) (the names set in flags, in that order), with_feature(flags, name) (flags with that bit set), without_feature(flags, name), and count_features(flags) (the number of set bits, by repeatedly clearing the lowest with n & (n - 1)).
