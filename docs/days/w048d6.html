Week 48, Day 6Forge day

Forge

This week was about strings: tries for prefixes, the prefix function and KMP for matching one pattern without ever backing up, prefix hashes for comparing any two substrings in O(1), palindromes from centres to Manacher, and an autocomplete engine built from all of them. Today’s Forge combines the first two: the Aho-Corasick automaton, which matches hundreds of patterns at once in a single pass over the text by adding KMP-style failure links to a trie. The bonus uses rolling hashes to find passages two documents share. The weekly quiz and review finish the week.

By the end of today you can

  • Build a trie of patterns and add failure links breadth-first, as KMP does for one pattern
  • Match many patterns in one pass, streaming, in time proportional to the text plus the matches
  • Use the matches to count and censor
  • Find shared passages between documents with rolling hashes over words

Mixed review

Exercise10 points
Every distinct substring

Every substring of s is a prefix of some suffix of s. So insert every suffix into a trie, and each node other than the root is exactly one distinct substring. Write count_distinct_substrings(s) that way (fine for strings of a few hundred characters: the trie has O(n²) nodes), and nth_substring(s, n): the nth distinct substring in alphabetical order (n from 1), by walking the trie in sorted order with a stack. IndexError if there aren’t n.

Exercise10 points
Repeated sequences

Write repeated_sequences(dna, k=10): every length-k substring that occurs more than once in a DNA string, in order of first appearance. Encode A, C, G and T as 0 to 3 and keep a rolling value in base 4, so each window’s number is updated in O(1) (with only four letters and k ≤ 30, the numbers stay small and are exact, so there are no collisions to worry about). Raise ValueError for any other character.

Forge: many patterns at once

A message filter has a list of a thousand banned phrases, and must check every message for all of them. Running KMP once per phrase reads each message a thousand times. In 1975 Alfred Aho and Margaret Corasick, working on a bibliographic search tool, combined this week’s two big ideas so the text is read once:

  1. Put all the patterns in a trie (Day 1). Each node is “the last few characters read match this prefix of some pattern”.
  2. Give every node a failure link (Day 2’s prefix function, generalised): the node for the longest proper suffix of its string that is also a prefix of some pattern (a path in the trie). On a mismatch, follow failure links until a node has the needed child, or the root is reached, exactly as KMP falls back with pi.
  3. Compute the links breadth-first (Week 43): a node’s failure link is found from its parent’s, which is shallower and so already done. For a child reached from node by character c: start at node.fail, follow failure links until one has a child c (or you reach the root); that child (or the root, if even the root has none) is the link.
  4. Give every node an output list: the patterns ending exactly there, followed by the output list of its failure link (patterns that end at the same place but are shorter, like “he” inside “she”).

Then scanning the text is KMP with a trie: for each character, step (falling back as needed), and report everything in the current node’s output list. The time is O(text length + total pattern length + number of matches).

patterns: he, she, his, hers
          (root)
          /    \
         h      s
        / \      \
       e*  i      h
       |    \      \
       r     s*     e*     failure links: "sh" -> "h", "she" -> "he",
       |                    "hi" -> root, "his" -> "s", "her" -> root, ...
       s*                   output of "she": she, he

Write AhoCorasick(patterns):

  • Patterns must be non-empty strings (ValueError otherwise); repeats are ignored. Keep the distinct patterns in patterns, in first-seen order.
  • find_all(text): every match as (start, pattern), sorted.
  • count(text): a dict from each pattern to how many times it occurs (overlaps count).
  • feed(ch) and reset(): a streaming interface; feed returns the list of patterns that end with this character, longest first.
  • censor(text, mask="*"): the text with every character that’s part of any match replaced by mask. Do it in O(n): the longest match ending at each position covers all shorter ones, so mark its start and end in a difference array (Week 41’s prefix sums) and sweep once.

No recursion. The checks compare with brute force on random patterns and texts, and time 1,000 patterns against a 100,000-character text.

Write AhoCorasick to the specification above.

Two ideas, one structure

Aho-Corasick is what you get when two of this week’s ideas meet. The trie shares work between patterns that start the same way; the failure links share work between positions in the text, never re-reading a character, as KMP did for a single pattern. Building the links breadth-first is the same “use what you’ve already computed” move as the prefix function’s k = pi[k - 1], applied to a tree instead of a line. The algorithm is still at the heart of tools that scan text for many fixed strings at once: the original fgrep command was built on it, and network intrusion detection and virus scanners use descendants of it to check traffic against thousands of signatures.

Forge bonus: shared passages

Exercise30 points
Forge bonus: shared passages

Yesterday’s winnowing gave a similarity score; now find the actual passages two documents share, measured in words.

  • words(text): the lower-cased runs of letters and digits, using re.findall(r"[a-z0-9]+", text.lower()).
  • shared_passages(a, b, min_words): every maximal shared passage of at least min_words words, as (i, j, length): words(a)[i:i + length] == words(b)[j:j + length], and it can’t be extended (the words just before both, or just after both, differ or don’t exist). Sorted. Give each distinct word a number, hash every min_words-word window of both documents with a rolling hash (random base, modulus 2⁶¹ − 1), and look a’s windows up in a dict of b’s. For each matching pair that starts a passage (no equal words just before both), confirm the window really matches (a collision is possible), then extend it word by word.
  • coverage(a, b, min_words): the fraction of a’s words that lie in at least one shared passage (0.0 if a has no words).
  • report(a, b, min_words): one line per passage: words 0-4 of a = words 1-5 of b: the quick brown fox jumps.
