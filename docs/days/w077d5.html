Week 77, Day 5

Deployment

A backend running on your laptop helps nobody. Deploying it means running it on a server that’s always on, reachable over HTTPS, configured without editing the code, observable when something goes wrong, and replaceable with a new version without anyone noticing. Today is the practical side of all that: configuration from the environment, the production servers and the reverse proxy in front of them, health checks, structured logs with request ids, containers, and rolling out new versions safely. The browser can’t run a server, so the exercises build and test the pieces each of those steps relies on, and On your own computer shows the real commands.

By the end of today you can

  • Configure an app from environment variables, validated at start-up, with secrets kept out of code and logs
  • Run behind a reverse proxy, trusting forwarded headers only from the proxy
  • Add liveness and readiness checks, and structured logs with request ids
  • Package an app in a container, size its workers, and roll out new versions without downtime

"""A small subset of Flask that runs in the page (Week 77).

The names and behaviour follow Flask's own, so code written against this module also runs with
the real Flask (pip install flask): Flask, request, g, jsonify, abort, redirect, make_response,
url_for, Blueprint, and app.test_client(). It's a teaching copy, not the real thing: no templates,
sessions, streaming or debugger.
"""
import io
import json
import re
from contextvars import ContextVar
from http import HTTPStatus
from urllib.parse import parse_qs, urlencode, urlsplit

_current = ContextVar("request")


class HTTPException(Exception):
    def __init__(self, code, description=None):
        self.code = code
        self.name = HTTPStatus(code).phrase
        self.description = description or self.name
        super().__init__(f"{code} {self.name}: {self.description}")


def abort(code, description=None):
    raise HTTPException(code, description)


class Headers:
    """Case-insensitive headers."""
    def __init__(self, items=()):
        self._items = [(k, str(v)) for k, v in (items.items() if isinstance(items, dict) else items)]

    def get(self, name, default=None):
        for k, v in self._items:
            if k.lower() == name.lower():
                return v
        return default

    def __getitem__(self, name):
        value = self.get(name)
        if value is None:
            raise KeyError(name)
        return value

    def __contains__(self, name):
        return self.get(name) is not None

    def __setitem__(self, name, value):
        self._items = [(k, v) for k, v in self._items if k.lower() != name.lower()] + [(name, str(value))]

    def items(self):
        return list(self._items)


class Args(dict):
    """Query or form values: .get(name) gives the first value; .getlist(name) all of them."""
    def __init__(self, pairs):
        super().__init__()
        self._lists = {}
        for k, v in pairs:
            self._lists.setdefault(k, []).append(v)
            dict.setdefault(self, k, v)

    def get(self, key, default=None, type=None):
        if key not in self:
            return default
        value = self[key]
        if type is not None:
            try:
                return type(value)
            except (TypeError, ValueError):
                return default
        return value

    def getlist(self, key):
        return list(self._lists.get(key, []))


class Request:
    def __init__(self, environ):
        self.environ = environ
        self.method = environ["REQUEST_METHOD"].upper()
        self.path = environ.get("PATH_INFO", "/") or "/"
        self.args = Args(_pairs(environ.get("QUERY_STRING", "")))
        items = [(k[5:].replace("_", "-").title(), v) for k, v in environ.items() if k.startswith("HTTP_")]
        if environ.get("CONTENT_TYPE"):
            items.append(("Content-Type", environ["CONTENT_TYPE"]))
        self.headers = Headers(items)
        length = int(environ.get("CONTENT_LENGTH") or 0)
        self.data = environ["wsgi.input"].read(length) if length else b""
        self.content_type = environ.get("CONTENT_TYPE", "")
        self.form = Args(_pairs(self.data.decode("utf-8"))) if self.content_type.startswith("application/x-www-form-urlencoded") else Args([])
        self.view_args = {}
        cookie = environ.get("HTTP_COOKIE", "")
        self.cookies = dict(p.strip().split("=", 1) for p in cookie.split(";") if "=" in p)

    @property
    def is_json(self):
        return self.content_type.split(";")[0].strip() == "application/json"

    def get_json(self, silent=False, force=False):
        if not (self.is_json or force):
            if silent:
                return None
            abort(415, "expected a JSON body (Content-Type: application/json)")
        try:
            return json.loads(self.data or b"null")
        except ValueError:
            if silent:
                return None
            abort(400, "the body isn't valid JSON")

    @property
    def json(self):
        return self.get_json()


def _pairs(text):
    return [(k, v) for k, vs in parse_qs(text, keep_blank_values=True).items() for v in vs]


class _Proxy:
    def __init__(self, getter):
        object.__setattr__(self, "_getter", getter)

    def __getattr__(self, name):
        return getattr(self._getter(), name)

    def __setattr__(self, name, value):
        setattr(self._getter(), name, value)

    except LookupError:

def _g():
    try:
        return _current.get()[1]
    except LookupError:

class _G:
    def get(self, name, default=None):
        return self.__dict__.get(name, default)


request = _Proxy(_request)
g = _Proxy(_g)


class Response:
    def __init__(self, response=b"", status=200, headers=None, mimetype=None, content_type=None):
        if isinstance(response, str):
            response = response.encode("utf-8")
        self.data = response
        self.status_code = status
        self.headers = Headers(headers or {})
        if content_type or mimetype or "Content-Type" not in self.headers:
            ctype = content_type or (f"{mimetype}; charset=utf-8" if mimetype and mimetype.startswith("text/") else mimetype) or "text/html; charset=utf-8"
            self.headers["Content-Type"] = ctype

    @property
    def status(self):
        return f"{self.status_code} {HTTPStatus(self.status_code).phrase}"

    @property
    def text(self):
        return self.data.decode("utf-8")

    def get_json(self):
        return json.loads(self.data)

    @property
    def json(self):
        return self.get_json()

    def set_cookie(self, key, value="", max_age=None, path="/", secure=False, httponly=False, samesite=None):
        parts = [f"{key}={value}"]
        if max_age is not None:
            parts.append(f"Max-Age={max_age}")
        parts.append(f"Path={path}")
        if secure:
            parts.append("Secure")
        if httponly:
            parts.append("HttpOnly")
        if samesite:
            parts.append(f"SameSite={samesite}")
        self.headers._items.append(("Set-Cookie", "; ".join(parts)))


def jsonify(*args, **kwargs):
    data = args[0] if len(args) == 1 else (list(args) if args else kwargs)
    return Response(json.dumps(data), headers={"Content-Type": "application/json"})


def redirect(location, code=302):
    return Response(b"", code, {"Location": location})


def make_response(*args):
    rv = args[0] if len(args) == 1 else args
    return _App._to_response(rv)


def url_for(endpoint, **values):
    return _current.get()[2].url_for(endpoint, **values)


_CONVERTERS = {"int": (r"\d+", int), "float": (r"\d+(?:\.\d+)?", float), "path": (r".+", str), "string": (r"[^/]+", str)}


class _Rule:
    def __init__(self, rule, endpoint, view, methods):
        self.rule, self.endpoint, self.view = rule, endpoint, view
        self.methods = {m.upper() for m in methods} | ({"HEAD"} if "GET" in {m.upper() for m in methods} else set())
        regex, self.converters = "", {}
        for piece in re.split(r"(<[^>]+>)", rule):
            m = re.fullmatch(r"<(?:(\w+):)?(\w+)>", piece)
            if m:
                kind, name = m.group(1) or "string", m.group(2)
                pattern, convert = _CONVERTERS[kind]
                regex += f"(?P<{name}>{pattern})"
                self.converters[name] = convert
            else:
                regex += re.escape(piece)
        self.regex = re.compile(regex)

    def match(self, path):
        m = self.regex.fullmatch(path)
        if not m:
            return None
        return {k: self.converters[k](v) for k, v in m.groupdict().items()}

    def build(self, values):
        def fill(m):
            return str(values.pop(m.group(2)))
        path = re.sub(r"<(?:(\w+):)?(\w+)>", fill, self.rule)
        return path + (f"?{urlencode(values)}" if values else "")


class _Setup:
    def route(self, rule, methods=("GET",), endpoint=None):
        def decorate(view):
            self._add(rule, endpoint or view.__name__, view, methods)
            return view
        return decorate

    def get(self, rule, **kw):
        return self.route(rule, methods=["GET"], **kw)

    def post(self, rule, **kw):
        return self.route(rule, methods=["POST"], **kw)

    def put(self, rule, **kw):
        return self.route(rule, methods=["PUT"], **kw)

    def patch(self, rule, **kw):
        return self.route(rule, methods=["PATCH"], **kw)

    def delete(self, rule, **kw):
        return self.route(rule, methods=["DELETE"], **kw)


class Blueprint(_Setup):
    def __init__(self, name, import_name, url_prefix=""):
        self.name, self.url_prefix = name, url_prefix
        self.deferred = []

    def _add(self, rule, endpoint, view, methods):
        self.deferred.append((rule, endpoint, view, methods))


class _App(_Setup):
    def __init__(self, import_name):
        self.import_name = import_name
        self.config = {"TESTING": False}
        self.rules = []
        self.before_funcs, self.after_funcs, self.error_handlers = [], [], {}

    def _add(self, rule, endpoint, view, methods):
        self.rules.append(_Rule(rule, endpoint, view, methods))

    def register_blueprint(self, bp, url_prefix=None):
        prefix = url_prefix if url_prefix is not None else bp.url_prefix
        for rule, endpoint, view, methods in bp.deferred:
            self._add(prefix + rule, f"{bp.name}.{endpoint}", view, methods)

    def before_request(self, f):
        self.before_funcs.append(f)
        return f

    def after_request(self, f):
        self.after_funcs.append(f)
        return f

    def errorhandler(self, code):
        def decorate(f):
            self.error_handlers[code] = f
            return f
        return decorate

    def url_for(self, endpoint, **values):
        for r in self.rules:
            if r.endpoint == endpoint:
                return r.build(dict(values))
        raise LookupError(f"no endpoint {endpoint!r}")

    @staticmethod
    def _to_response(rv):
        status, headers = None, None
        if isinstance(rv, tuple):
            if len(rv) == 3:
                rv, status, headers = rv
            elif isinstance(rv[1], (dict, list)):
                rv, headers = rv
            else:
                rv, status = rv
        if isinstance(rv, Response):
            response = rv
        elif isinstance(rv, (dict, list)):
            response = jsonify(rv)
        elif isinstance(rv, (str, bytes)):
            response = Response(rv)
        elif rv is None:
            raise TypeError("the view function did not return a valid response")
        else:
            raise TypeError(f"can't turn {type(rv).__name__} into a response")
        if status is not None:
            response.status_code = status
        for k, v in (headers.items() if isinstance(headers, dict) else headers or []):
            response.headers[k] = v
        return response

    def _error(self, e):
        handler = self.error_handlers.get(e.code)
        if handler:
            return self._to_response(handler(e))
        body = f"<h1>{e.code} {e.name}</h1><p>{e.description}</p>"
        return Response(body, e.code)

    def _dispatch(self, req):
        path = req.path
        allowed = set()
        for r in self.rules:
            values = r.match(path)
            if values is None:
                continue
            if req.method in r.methods:
                req.view_args = values
                return r.view(**values)
            allowed |= r.methods
        if allowed:
            raise _MethodNotAllowed(sorted(allowed | {"OPTIONS"}))
        abort(404, "The requested URL was not found on the server.")

    def full_dispatch(self, environ):
        req = Request(environ)
        token = _current.set((req, _G(), self))
        try:
            try:
                rv = None
                for f in self.before_funcs:
                    rv = f()
                    if rv is not None:
                        break
                if rv is None:
                    rv = self._dispatch(req)
                response = self._to_response(rv)
            except _MethodNotAllowed as e:
                response = self._error(HTTPException(405))
                response.headers["Allow"] = ", ".join(e.allowed)
            except HTTPException as e:
                response = self._error(e)
            except Exception as e:
                if self.config.get("TESTING") and 500 not in self.error_handlers:
                    raise
                response = self._error(HTTPException(500)) if 500 not in self.error_handlers else self._to_response(self.error_handlers[500](e))
                response.status_code = 500
            for f in self.after_funcs:
                response = f(response) or response
            if req.method == "HEAD":
                response.headers["Content-Length"] = len(response.data)
                response.data = b""
            return response
        finally:
            _current.reset(token)

    def __call__(self, environ, start_response):
        response = self.full_dispatch(environ)
        if "Content-Length" not in response.headers:
            response.headers["Content-Length"] = len(response.data)
        start_response(response.status, response.headers.items())
        return [response.data]

    def test_client(self):
        return _TestClient(self)


class _MethodNotAllowed(Exception):
    def __init__(self, allowed):
        self.allowed = allowed

class _TestClient:
    def __init__(self, app):
        self.app = app
        self.cookies = {}

    def open(self, path, method="GET", json=None, data=None, headers=None, query_string=None):
        url = urlsplit(path)
        query = url.query
        if query_string:
            query = (query + "&" if query else "") + urlencode(query_string, doseq=True)
        body, ctype = b"", None
        if json is not None:
            import json as _json
            body, ctype = _json.dumps(json).encode("utf-8"), "application/json"
        elif isinstance(data, dict):
            body, ctype = urlencode(data, doseq=True).encode("utf-8"), "application/x-www-form-urlencoded"
        elif data is not None:
            body = data.encode("utf-8") if isinstance(data, str) else data
        environ = {"REQUEST_METHOD": method.upper(), "PATH_INFO": url.path or "/", "QUERY_STRING": query,
                   "SERVER_NAME": "localhost", "SERVER_PORT": "80", "wsgi.url_scheme": "http",
                   "wsgi.input": io.BytesIO(body), "CONTENT_LENGTH": str(len(body))}
        headers = dict(headers or {})
        if ctype and not any(k.lower() == "content-type" for k in headers):
            environ["CONTENT_TYPE"] = ctype
        for k, v in headers.items():
            if k.lower() == "content-type":
                environ["CONTENT_TYPE"] = v
            else:
                environ["HTTP_" + k.upper().replace("-", "_")] = v
        if self.cookies:
            environ["HTTP_COOKIE"] = "; ".join(f"{k}={v}" for k, v in self.cookies.items())
        response = self.app.full_dispatch(environ)
        for k, v in response.headers.items():
            if k.lower() == "set-cookie":
                name, _, rest = v.partition("=")
                self.cookies[name] = rest.split(";")[0]
        return response

    def get(self, path, **kw):
        return self.open(path, "GET", **kw)

    def post(self, path, **kw):
        return self.open(path, "POST", **kw)

    def put(self, path, **kw):
        return self.open(path, "PUT", **kw)

    def patch(self, path, **kw):
        return self.open(path, "PATCH", **kw)

    def delete(self, path, **kw):
        return self.open(path, "DELETE", **kw)

Warm-up

Environment variables are always strings: bool("false") is True (any non-empty string is), and "4" * 2 is "44". Configuration from the environment is the standard way to deploy, and every value needs parsing and checking, once, at start-up, so a typo stops the app from starting rather than misbehaving in production.

Configuration

The twelve-factor app guidelines, widely followed for web services, say: keep configuration in the environment, separate from the code. The same build runs in development, staging and production; only the environment differs.

  • Read settings from environment variables (os.environ), perhaps loaded from a .env file in development (never committed: Week 79). Typical ones: DATABASE_URL, SECRET_KEY, DEBUG, ALLOWED_HOSTS, LOG_LEVEL, PORT.
  • Parse and validate them at start-up into a typed settings object: integers, booleans (true, 1, yes), lists (comma-separated), URLs. Report every problem at once and refuse to start. Libraries such as pydantic-settings do this from type hints, like FastAPI.
  • Secrets (keys, passwords, tokens) come from the environment or a secrets manager, never from code or the repository, and must never appear in logs or error pages: show them masked (****).
  • Production defaults must be safe: DEBUG off, SECRET_KEY required with no default, HTTPS only. A debugger page in production lets anyone run code on your server.

Servers and proxies

Development servers (flask run, fastapi dev) are for one person. In production:

  • An application server runs your app with several workers: Gunicorn for WSGI (gunicorn "shop:create_app()" --workers 4 --bind 0.0.0.0:8000), Uvicorn for ASGI (often as Gunicorn workers). A common starting point is 2 x cores + 1 workers for synchronous apps; measure and adjust.
  • A reverse proxy such as nginx or Caddy (or a cloud load balancer) sits in front: it terminates TLS (HTTPS, with certificates from Let’s Encrypt), serves static files, buffers slow clients, limits request sizes, and spreads requests over several app servers.
  • Behind a proxy, the app sees the proxy’s address and plain http. The proxy passes the originals in headers: X-Forwarded-For (the client’s address, with each proxy appending the one it got the request from), X-Forwarded-Proto (https) and X-Forwarded-Host (or the standard Forwarded header). The app must trust these only from its own proxies, because anyone can send them; Werkzeug’s ProxyFix middleware does this for Flask. Then redirects, URLs and rate limits use the real client and scheme.
  • Browsers enforce the same-origin policy: a page from https://shop.example.com can only call https://api.example.com if the API sends CORS headers (Access-Control-Allow-Origin: https://shop.example.com), after answering a preflight OPTIONS request for anything but the simplest calls. Allow specific origins, never * with credentials.

Health, logs and metrics

Once deployed, you need to know it’s working without logging in to look:

  • Health checks. A liveness endpoint (/healthz) answers 200 if the process is running at all; the platform restarts the instance if it stops answering. A readiness endpoint (/readyz) answers 200 only when the instance can really serve (its database and other dependencies are reachable), and 503 otherwise, so the load balancer sends it no traffic until it’s ready. Keep both fast and unauthenticated, and don’t let them leak details.
  • Logs. Write logs to standard output (the platform collects them), one structured JSON object per line ({"ts": "...", "level": "INFO", "msg": "request", "method": "GET", "path": "/orders", "status": 200, "ms": 12, "request_id": "..."}), so they can be searched and counted. Give every request a request id (taken from an incoming X-Request-Id if it’s well-formed, otherwise generated), include it in every log line and send it back in the response, so one request can be followed through every service it touches.
  • Metrics (requests per second, error rate, latency percentiles, saturation) are counted and graphed by tools such as Prometheus and Grafana, with alerts when they cross thresholds (Week 85 has more).

Containers and releases

A container image packages the app with its exact Python version and dependencies, so it runs the same everywhere. A typical Dockerfile:

FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
RUN useradd --create-home app
USER app
EXPOSE 8000
CMD ["gunicorn", "shop:create_app()", "--bind", "0.0.0.0:8000", "--workers", "4"]
  • Pin the base image to a specific version, never latest.
  • Copy and install the requirements (the lock file, Week 73 Day 5) before copying the code, so rebuilding after a code change reuses the cached dependency layer.
  • Don’t run as root; don’t bake secrets into the image (pass them as environment variables when it runs); keep the image small (-slim, no build tools left behind).

Releasing a new version without downtime:

  • A rolling deployment replaces instances one (or a few) at a time: start a new one, wait for it to pass its readiness check, move traffic to it, then stop an old one; if new instances never become ready, stop and roll back.
  • Blue-green runs the whole new version beside the old and switches traffic at once (and back, if needed); canary releases send a small share of traffic to the new version first and watch its errors.
  • Stopping an instance should be graceful: stop accepting new requests, finish the ones in progress, then exit.
  • Database migrations must work with both the old and new code during the changeover: add a column first, deploy code that uses it, and remove old columns only in a later release.
Key idea

Keep configuration in the environment, parsed and validated at start-up into typed settings, reporting every problem and refusing to start; environment values are strings (bool(“false”) is True); secrets never in code, images or logs; safe production defaults (DEBUG off, SECRET_KEY required). Run under Gunicorn (WSGI) or Uvicorn (ASGI) with several workers, behind a reverse proxy that terminates TLS and serves static files; trust X-Forwarded-For and -Proto only from your proxies; allow cross-origin calls with specific CORS origins. Offer fast liveness (/healthz) and readiness (/readyz, 503 when dependencies are down) checks; log structured JSON to stdout with a request id per request, echoed in X-Request-Id; watch metrics and alert. Build pinned, non-root container images with dependencies installed before the code; release by rolling (gated on readiness, with rollback), blue-green or canary, shut down gracefully, and keep migrations compatible with old and new code.

Reviewing a Dockerfile

Write review_dockerfile(text): a list of problems (in this order, each at most once): "base image not pinned" if the first FROM has no tag or the tag latest; "secret in ENV: NAME" for each ENV NAME=... (or ENV NAME value) whose name contains KEY, SECRET, TOKEN or PASSWORD; "code copied before dependencies are installed" if a COPY . line comes before the first RUN pip install; "runs as root" if there’s no USER line (or only USER root); and "no CMD" if there’s no CMD or ENTRYPOINT. Instructions are case-insensitive; ignore blank lines and comments.

Exercise10 points
How many workers, how many servers?

Write workers(cores): the common starting point 2 * cores + 1. Then throughput(workers, threads, avg_ms): requests per second one instance can handle if each worker thread handles one request at a time taking avg_ms milliseconds on average (rounded down). Finally instances_needed(peak_rps, per_instance, headroom=0.3, minimum=2): enough instances to serve the peak with headroom spare (so each runs at most 1 - headroom of its capacity), rounded up, and never fewer than minimum (so one can fail or be replaced during a deploy).

Bug hunt10 points
Debug on, by accident

The environment says DEBUG=false, but bool() of any non-empty string is True, so the app starts in debug mode and this prints debug: True. Parse the text properly, so it prints debug: False.

Bug hunt10 points
A secret in the logs

The start-up message logs the whole settings dict, secret key included, and logs are read by many people and kept for a long time: this prints the key. Mask any setting whose name contains KEY, SECRET, TOKEN or PASSWORD, so this prints starting with {'DEBUG': False, 'SECRET_KEY': '****', 'PORT': 8000}.

Bug hunt10 points
Ready, while the database is down

The readiness check always answers 200, so the load balancer keeps sending traffic to an instance that can’t reach its database, and this prints 200. Check the database, answering 503 when it’s down, so this prints 503.

Then build and run it in a container (with Docker or Podman installed):

docker build -t shop:1.0 . && docker run --rm -p 8000:8000 -e SECRET_KEY=dev-only -e DATABASE_URL=sqlite:///shop.db shop:1.0

For a real deployment, platforms that run containers or Python apps from a Git repository (and give you HTTPS, logs and health checks) are the quickest start; a virtual server with nginx, Gunicorn and a systemd service teaches you the most.

Challenge: a rolling deployment

Simulate a rolling deployment. rolling_deploy(instances, new_version, start, ready, batch=1, min_healthy=None): instances is a list of the current instances (dicts with "name" and "version"); start(name, version) starts a replacement instance and returns its name; ready(name) returns whether it passed its readiness check. Replace the old instances batch at a time, in order: for each, start a new instance (named by start), and if it’s ready, stop the old one (log "stop OLD"), otherwise stop the new one, stop deploying, and roll back: every new instance started so far that’s still running is stopped, and for each old instance already stopped, a replacement running the old version is started (and assumed ready), in order. Never let the number of ready instances drop below min_healthy (default: the original count): new instances are always started before old ones are stopped. Return (succeeded, running, log): whether the deploy finished, the list of (name, version) running at the end, and the log of actions ("start NAME VERSION", "ready NAME", "not ready NAME", "stop NAME", "rollback").
