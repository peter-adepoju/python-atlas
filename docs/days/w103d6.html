Where you started

On the first day you learned what a computer and a program are, used the console, and read your first error message. Think back to what was hard then: perhaps the difference between = and ==, why "3" + 4 fails, or what a loop variable is doing. Each of those is now something you’d explain to a beginner in a sentence, as you did in Week 101.

That’s what learning looks like from the inside: the hard things become invisible. It’s worth stopping, once, to see them again.

What you’ve done

  • Phase 1, Foundations: values, names, conditions, loops, functions, strings, lists and dictionaries, files and errors.
  • Phase 2, Thinking like a programmer: methods, recursion, Big-O, searching and sorting, modules, the shell and Git, testing, and your first project, spend.
  • Phase 3, Objects and design: classes, inheritance, the data model, type hints, design principles and patterns.
  • Phase 4, Data structures and algorithms: linked lists, trees, heaps, hash tables, graphs, dynamic programming.
  • Phase 5, Advanced Python: iterators and generators, closures and decorators, context managers, the memory model, attribute magic, CPython’s insides, performance and concurrency.
  • Phase 6, Professional engineering: testing in depth, packaging, databases, HTTP and web backends, security, the helpdesk, system design, data and machine learning.
  • Phase 7, Mastery: the Waymark capstone, open source and CPython, interview practice, teaching, and the final exam.

Ninety-six weeks of lessons, 576 days. Whatever your final exam score, finishing them is the achievement.

Key idea

You’ve finished all seven phases: from a first print() to a capstone, contributions to open source and a final exam. The hard things of Week 1 are now ones you could teach. Mark it, rest, and then follow the plan you wrote yesterday.

To finish

A few things to take with you:

  • Keep building. The plan you wrote yesterday is a start; the best learning comes from projects you care about.
  • Keep reading code, especially the code of the projects you use. You can read CPython now.
  • Keep helping. Answer a beginner’s question, review a first pull request, write the tutorial you wish you’d had. You’ll learn as much as they do.
  • Come back. Every lesson, exercise and exam in this course stays here, free. Redo the ones you found hard; they’ll feel different now.
