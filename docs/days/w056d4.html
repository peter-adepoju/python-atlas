Part B: six problems

Exercise10 points
C1: Lakes that don’t reach the sea

A map is a list of strings: "L" land, "W" water. A lake is a group of water cells joined up, down, left or right that touches no edge of the map (water on the edge is sea). Write count_lakes(grid) and largest_lake(grid) (the number of cells in the biggest lake, 0 if none). Use no recursion: the checks include a 400 × 400 map.

Exercise15 points
C2: Cheap flights, few changes

flights are (from, to, price), one way. Write cheapest_with_stops(n, flights, src, dst, k): the cheapest price from src to dst using at most k stops (so at most k + 1 flights), or -1. Cities are 0 to n − 1. Then route_with_stops(n, flights, src, dst, k): the cities on one such cheapest route, or None.

Exercise15 points
C3: Combinations that add up

Write combinations_summing(candidates, target): every different combination of candidates (positive whole numbers, possibly with repeats in the list; each list position used at most once) that adds up to the target. Each combination is a sorted list; return them sorted. Backtrack over the sorted candidates, skipping equal values at the same level, and stop a branch when the next value is too big.

Exercise15 points
C4: Shuffled together

Two decks of cards are riffled together, keeping each deck’s order. Write is_interleaving(a, b, c): True if the string c is a riffle of strings a and b (every character of each, in each one’s order). Then riffle_choices(a, b, c): how many different ways (sequences of “take from a” or “take from b”) produce c. A table over prefix lengths of a and b.

Exercise20 points
C5: The smallest team

A project needs a list of skills (at most 16). Each candidate has some of them. Write smallest_team(skills, people): the indices (sorted) of a smallest group of people who between them have every required skill, or None if impossible. people is a list of lists of skills. Up to 60 people. Turn each person’s skills into a bitmask, and DP over the masks of skills covered: best[mask] = the smallest team reaching exactly that set of skills.

Bug hunt15 points
C6: Three bugs

cheapest_network(n, cables) should return the least total cost of cables (a, b, cost) connecting all n buildings (Kruskal’s algorithm), or None if they can’t all be connected. It has three bugs: it sorts the cables by their first building instead of their cost, it joins the two buildings themselves instead of their sets’ roots, and it never checks whether everything ended up connected. Fix them so this prints [6, None].
