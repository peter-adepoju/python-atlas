Week 77, Day 4

Authentication

Almost every backend has to answer two questions about each request: who is this (authentication), and are they allowed to do this (authorisation)? Getting either wrong is how data leaks. Today you’ll build the pieces from the standard library and see exactly what the libraries you’d normally use are doing: storing passwords so a stolen database doesn’t reveal them, comparing secrets safely, keeping people logged in with signed session cookies or tokens (including the JSON Web Tokens most APIs use), deciding permissions, and slowing down people trying to guess passwords.

By the end of today you can

  • Store passwords with a slow, salted hash (PBKDF2), and verify them in constant time
  • Keep users logged in with signed session cookies or JWTs, checking signatures and expiry
  • Decide permissions with roles and ownership, and enforce them in every endpoint
  • Defend logins against guessing, and explain where OAuth and single sign-on fit

import io
import json
import re
from contextvars import ContextVar
from http import HTTPStatus
from urllib.parse import parse_qs, urlencode, urlsplit

_current = ContextVar("request")


class HTTPException(Exception):
    def __init__(self, code, description=None):
        self.code = code
        self.name = HTTPStatus(code).phrase
        self.description = description or self.name
        super().__init__(f"{code} {self.name}: {self.description}")


def abort(code, description=None):
    raise HTTPException(code, description)


class Headers:
    """Case-insensitive headers."""
    def __init__(self, items=()):
        self._items = [(k, str(v)) for k, v in (items.items() if isinstance(items, dict) else items)]

    def get(self, name, default=None):
        for k, v in self._items:
            if k.lower() == name.lower():
                return v
        return default

    def __getitem__(self, name):
        value = self.get(name)
        if value is None:
            raise KeyError(name)
        return value

    def __contains__(self, name):
        return self.get(name) is not None

    def __setitem__(self, name, value):
        self._items = [(k, v) for k, v in self._items if k.lower() != name.lower()] + [(name, str(value))]

    def items(self):
        return list(self._items)


class Args(dict):
    """Query or form values: .get(name) gives the first value; .getlist(name) all of them."""
    def __init__(self, pairs):
        super().__init__()
        self._lists = {}
        for k, v in pairs:
            self._lists.setdefault(k, []).append(v)
            dict.setdefault(self, k, v)

    def get(self, key, default=None, type=None):
        if key not in self:
            return default
        value = self[key]
        if type is not None:
            try:
                return type(value)
            except (TypeError, ValueError):
                return default
        return value

    def getlist(self, key):
        return list(self._lists.get(key, []))


class Request:
    def __init__(self, environ):
        self.environ = environ
        self.method = environ["REQUEST_METHOD"].upper()
        self.path = environ.get("PATH_INFO", "/") or "/"
        self.args = Args(_pairs(environ.get("QUERY_STRING", "")))
        items = [(k[5:].replace("_", "-").title(), v) for k, v in environ.items() if k.startswith("HTTP_")]
        if environ.get("CONTENT_TYPE"):
            items.append(("Content-Type", environ["CONTENT_TYPE"]))
        self.headers = Headers(items)
        length = int(environ.get("CONTENT_LENGTH") or 0)
        self.data = environ["wsgi.input"].read(length) if length else b""
        self.content_type = environ.get("CONTENT_TYPE", "")
        self.form = Args(_pairs(self.data.decode("utf-8"))) if self.content_type.startswith("application/x-www-form-urlencoded") else Args([])
        self.view_args = {}
        cookie = environ.get("HTTP_COOKIE", "")
        self.cookies = dict(p.strip().split("=", 1) for p in cookie.split(";") if "=" in p)

    @property
    def is_json(self):
        return self.content_type.split(";")[0].strip() == "application/json"

    def get_json(self, silent=False, force=False):
        if not (self.is_json or force):
            if silent:
                return None
            abort(415, "expected a JSON body (Content-Type: application/json)")
        try:
            return json.loads(self.data or b"null")
        except ValueError:
            if silent:
                return None
            abort(400, "the body isn't valid JSON")

    @property
    def json(self):
        return self.get_json()


def _pairs(text):
    return [(k, v) for k, vs in parse_qs(text, keep_blank_values=True).items() for v in vs]


class _Proxy:
    def __init__(self, getter):
        object.__setattr__(self, "_getter", getter)

    def __getattr__(self, name):
        return getattr(self._getter(), name)

    def __setattr__(self, name, value):
        setattr(self._getter(), name, value)

class Response:
    def __init__(self, response=b"", status=200, headers=None, mimetype=None, content_type=None):
        if isinstance(response, str):
            response = response.encode("utf-8")
        self.data = response
        self.status_code = status
        self.headers = Headers(headers or {})
        if content_type or mimetype or "Content-Type" not in self.headers:
            ctype = content_type or (f"{mimetype}; charset=utf-8" if mimetype and mimetype.startswith("text/") else mimetype) or "text/html; charset=utf-8"
            self.headers["Content-Type"] = ctype

    @property
    def status(self):
        return f"{self.status_code} {HTTPStatus(self.status_code).phrase}"

    @property
    def text(self):
        return self.data.decode("utf-8")

    def get_json(self):
        return json.loads(self.data)

    @property
    def json(self):
        return self.get_json()

    def set_cookie(self, key, value="", max_age=None, path="/", secure=False, httponly=False, samesite=None):
        parts = [f"{key}={value}"]
        if max_age is not None:
            parts.append(f"Max-Age={max_age}")
        parts.append(f"Path={path}")
        if secure:
            parts.append("Secure")
        if httponly:
            parts.append("HttpOnly")
        if samesite:
            parts.append(f"SameSite={samesite}")
        self.headers._items.append(("Set-Cookie", "; ".join(parts)))


def jsonify(*args, **kwargs):
    data = args[0] if len(args) == 1 else (list(args) if args else kwargs)
    return Response(json.dumps(data), headers={"Content-Type": "application/json"})


def redirect(location, code=302):
    return Response(b"", code, {"Location": location})


def make_response(*args):
    rv = args[0] if len(args) == 1 else args
    return _App._to_response(rv)


def url_for(endpoint, **values):
    return _current.get()[2].url_for(endpoint, **values)


_CONVERTERS = {"int": (r"\d+", int), "float": (r"\d+(?:\.\d+)?", float), "path": (r".+", str), "string": (r"[^/]+", str)}


class _Rule:
    def __init__(self, rule, endpoint, view, methods):
        self.rule, self.endpoint, self.view = rule, endpoint, view
        self.methods = {m.upper() for m in methods} | ({"HEAD"} if "GET" in {m.upper() for m in methods} else set())
        regex, self.converters = "", {}
        for piece in re.split(r"(<[^>]+>)", rule):
            m = re.fullmatch(r"<(?:(\w+):)?(\w+)>", piece)
            if m:
                kind, name = m.group(1) or "string", m.group(2)
                pattern, convert = _CONVERTERS[kind]
                regex += f"(?P<{name}>{pattern})"
                self.converters[name] = convert
            else:
                regex += re.escape(piece)
        self.regex = re.compile(regex)

    def match(self, path):
        m = self.regex.fullmatch(path)
        if not m:
            return None
        return {k: self.converters[k](v) for k, v in m.groupdict().items()}

    def build(self, values):
        def fill(m):
            return str(values.pop(m.group(2)))
        path = re.sub(r"<(?:(\w+):)?(\w+)>", fill, self.rule)
        return path + (f"?{urlencode(values)}" if values else "")


class _Setup:
    def route(self, rule, methods=("GET",), endpoint=None):
        def decorate(view):
            self._add(rule, endpoint or view.__name__, view, methods)
            return view
        return decorate

    def get(self, rule, **kw):
        return self.route(rule, methods=["GET"], **kw)

    def post(self, rule, **kw):
        return self.route(rule, methods=["POST"], **kw)

    def put(self, rule, **kw):
        return self.route(rule, methods=["PUT"], **kw)

    def patch(self, rule, **kw):
        return self.route(rule, methods=["PATCH"], **kw)

    def delete(self, rule, **kw):
        return self.route(rule, methods=["DELETE"], **kw)


class Blueprint(_Setup):
    def __init__(self, name, import_name, url_prefix=""):
        self.name, self.url_prefix = name, url_prefix
        self.deferred = []

    def _add(self, rule, endpoint, view, methods):
        self.deferred.append((rule, endpoint, view, methods))


class _App(_Setup):
    def __init__(self, import_name):
        self.import_name = import_name
        self.config = {"TESTING": False}
        self.rules = []
        self.before_funcs, self.after_funcs, self.error_handlers = [], [], {}

    def _add(self, rule, endpoint, view, methods):
        self.rules.append(_Rule(rule, endpoint, view, methods))

    def register_blueprint(self, bp, url_prefix=None):
        prefix = url_prefix if url_prefix is not None else bp.url_prefix
        for rule, endpoint, view, methods in bp.deferred:
            self._add(prefix + rule, f"{bp.name}.{endpoint}", view, methods)

    def before_request(self, f):
        self.before_funcs.append(f)
        return f

    def after_request(self, f):
        self.after_funcs.append(f)
        return f

    def errorhandler(self, code):
        def decorate(f):
            self.error_handlers[code] = f
            return f
        return decorate

    def url_for(self, endpoint, **values):
        for r in self.rules:
            if r.endpoint == endpoint:
                return r.build(dict(values))
        raise LookupError(f"no endpoint {endpoint!r}")

    @staticmethod
    def _to_response(rv):
        status, headers = None, None
        if isinstance(rv, tuple):
            if len(rv) == 3:
                rv, status, headers = rv
            elif isinstance(rv[1], (dict, list)):
                rv, headers = rv
            else:
                rv, status = rv
        if isinstance(rv, Response):
            response = rv
        elif isinstance(rv, (dict, list)):
            response = jsonify(rv)
        elif isinstance(rv, (str, bytes)):
            response = Response(rv)
        elif rv is None:
            raise TypeError("the view function did not return a valid response")
        else:
            raise TypeError(f"can't turn {type(rv).__name__} into a response")
        if status is not None:
            response.status_code = status
        for k, v in (headers.items() if isinstance(headers, dict) else headers or []):
            response.headers[k] = v
        return response

    def _error(self, e):
        handler = self.error_handlers.get(e.code)
        if handler:
            return self._to_response(handler(e))
        body = f"<h1>{e.code} {e.name}</h1><p>{e.description}</p>"
        return Response(body, e.code)

    def _dispatch(self, req):
        path = req.path
        allowed = set()
        for r in self.rules:
            values = r.match(path)
            if values is None:
                continue
            if req.method in r.methods:
                req.view_args = values
                return r.view(**values)
            allowed |= r.methods
        if allowed:
            raise _MethodNotAllowed(sorted(allowed | {"OPTIONS"}))
        abort(404, "The requested URL was not found on the server.")

    def full_dispatch(self, environ):
        req = Request(environ)
        token = _current.set((req, _G(), self))
        try:
            try:
                rv = None
                for f in self.before_funcs:
                    rv = f()
                    if rv is not None:
                        break
                if rv is None:
                    rv = self._dispatch(req)
                response = self._to_response(rv)
            except _MethodNotAllowed as e:
                response = self._error(HTTPException(405))
                response.headers["Allow"] = ", ".join(e.allowed)
            except HTTPException as e:
                response = self._error(e)
            except Exception as e:
                if self.config.get("TESTING") and 500 not in self.error_handlers:
                    raise
                response = self._error(HTTPException(500)) if 500 not in self.error_handlers else self._to_response(self.error_handlers[500](e))
                response.status_code = 500
            for f in self.after_funcs:
                response = f(response) or response
            if req.method == "HEAD":
                response.headers["Content-Length"] = len(response.data)
                response.data = b""
            return response
        finally:
            _current.reset(token)

    def __call__(self, environ, start_response):
        response = self.full_dispatch(environ)
        if "Content-Length" not in response.headers:
            response.headers["Content-Length"] = len(response.data)
        start_response(response.status, response.headers.items())
        return [response.data]

    def test_client(self):
        return _TestClient(self)


class _MethodNotAllowed(Exception):
    def __init__(self, allowed):
        self.allowed = allowed

    def open(self, path, method="GET", json=None, data=None, headers=None, query_string=None):

        query = url.query

        environ = {"REQUEST_METHOD": method.upper(), "PATH_INFO": url.path or "/", "QUERY_STRING": query,
                   "SERVER_NAME": "localhost", "SERVER_PORT": "80", "wsgi.url_scheme": "http",

        headers = dict(headers or {})
        if ctype and not any(k.lower() == "content-type" for k in headers):

        for k, v in headers.items():
            if k.lower() == "content-type":
                environ["CONTENT_TYPE"] = v
            else:
                environ["HTTP_" + k.upper().replace("-", "_")] = v

            environ["HTTP_COOKIE"] = "; ".join(f"{k}={v}" for k, v in self.cookies.items())

        for k, v in response.headers.items():
            if k.lower() == "set-cookie":
                name, _, rest = v.partition("=")
                self.cookies[name] = rest.split(";")[0]
        return response

Warm-up

Hashing the passwords wasn’t enough. Ada and Bob have the same hash, so cracking one cracks both, and anyone with the stolen table can hash a list of common passwords once and look every user up instantly. A fast hash like SHA-256 is designed for speed, which is exactly wrong for passwords: attackers can try billions a second. Password storage needs a salt and a deliberately slow hash.

Passwords

Never store passwords, not even encrypted. Store a value from which the password can be checked but not recovered:

  1. Generate a random salt for each user (secrets.token_bytes(16)), so equal passwords get different hashes and precomputed tables are useless.
  2. Run a slow key-derivation function: PBKDF2 (repeating HMAC hundreds of thousands of times), scrypt, or Argon2 (the current recommendation, which also uses lots of memory, defeating specialised cracking hardware). hashlib.pbkdf2_hmac and hashlib.scrypt are in the standard library on most systems; argon2-cffi and bcrypt are popular packages.
  3. Store the algorithm, the cost settings, the salt and the result together, in one string such as pbkdf2_sha256$600000$SALT$HASH, so you can raise the cost later and re-hash each user’s password when they next log in.
  4. To check a login, recompute with the stored salt and settings, and compare with hmac.compare_digest, which takes the same time however many characters match. A normal == stops at the first difference, and the timing can leak how close a guess is.

PBKDF2 itself is short: for each block of output, compute U1 = HMAC(password, salt + block_number), then U2 = HMAC(password, U1), and so on, iterations times, XORing all the Us together. (This browser’s Python has no hashlib.pbkdf2_hmac, so today you’ll write it, with small iteration counts for speed; real systems use 600,000 or more.)

Also: require reasonable length (at least 8 characters, preferably more) rather than complicated rules, check new passwords against lists of known-breached ones, and never log, email or display a password.

Staying logged in

After a login, the server must recognise the user’s later requests without asking for the password every time. Two common ways:

Sessions. The server creates a random session id (secrets.token_urlsafe(32)), stores id -> user (in a database or cache), and sends the id in a cookie (Set-Cookie: session=...; HttpOnly; Secure; SameSite=Lax, Week 76 Day 2). Each request’s cookie is looked up. Logging out deletes the stored session, which ends it at once. Alternatively, the session data itself can live in the cookie, signed with a server-side secret key (an HMAC of the data), so the browser can read but not change it: Flask’s default sessions work this way.

Tokens. APIs usually send a token in the Authorization: Bearer ... header. A JSON Web Token (JWT) is three base64url parts joined by dots: a header ({"alg": "HS256", "typ": "JWT"}), a payload of claims ({"sub": "42", "exp": 1767225600, "role": "admin"}) and a signature (HMAC-SHA256 of the first two parts with a secret key). Anyone can read a JWT (it isn’t encrypted, so put nothing secret in it); only the key holder can make one. Verifying means: recompute the signature and compare in constant time, insist on the algorithm you expect (never accept "alg": "none", a classic attack), and check exp (expiry) and nbf (not before). Because they’re checked without a database, JWTs can’t easily be revoked before they expire, so keep them short-lived (minutes) and pair them with a longer-lived refresh token that the server does store.

Either way: generate secrets with secrets, never random; keep keys out of code (Week 79); and set cookies HttpOnly and Secure.

Authorisation

Knowing who someone is doesn’t say what they may do. Common models:

  • Roles: users have roles (reader, editor, admin), and each role grants permissions (orders:read, orders:refund). Check permissions, not roles, in code, so roles can change without touching every endpoint.
  • Ownership: many rules are about whose thing it is: you may edit your own order. These must be checked against the resource itself, on every request.
  • Deny by default: an endpoint with no explicit rule should be closed, not open.

The most common real-world access bug (top of the OWASP list, Week 79) is broken object-level authorisation: checking that the user is logged in, but not that order 7 is theirs, so changing the number in the URL shows someone else’s data. Answer 404 rather than 403 when revealing that something exists would itself leak information (yesterday’s reading-list challenge did this).

Enforce rules in one place where possible: a decorator or dependency that every protected endpoint uses (Week 60’s decorators), with tests that try every endpoint as the wrong user.

Logins under attack, and OAuth

Guessing. Attackers try common passwords against many accounts (password spraying), or leaked password lists against yours (credential stuffing). Defences: rate-limit login attempts per account and per address, lock or slow an account after repeated failures, offer multi-factor authentication (a time-based code or a security key), and give the same error message for “no such user” and “wrong password”, so attackers can’t find out which accounts exist.

OAuth 2.0 and OpenID Connect. “Sign in with …” buttons let another service vouch for the user: your app redirects the user to the identity provider, which authenticates them and redirects back with a short-lived code that your server exchanges for tokens. You never see their password. For anything beyond a small project, use a well-reviewed library or service for this; it’s easy to get subtly wrong.

Key idea

Never store passwords: store a per-user random salt and a slow key-derivation result (PBKDF2, scrypt or Argon2) with its settings, and compare with hmac.compare_digest. Keep users logged in with random session ids in HttpOnly, Secure cookies (deleted on logout), cookies signed with an HMAC, or JWTs: base64url header, payload and HMAC signature, which anyone can read but only the key holder can make; verify the signature in constant time, insist on the expected algorithm (never none), and check exp and nbf; keep them short-lived with refresh tokens. Authorise with permissions granted by roles plus ownership checks on every object (broken object-level authorisation is the top API flaw), deny by default, and enforce in one place. Rate-limit and lock logins, offer MFA, give one error for unknown users and wrong passwords, and use OAuth/OpenID Connect libraries for third-party sign-in.

Slowing down guessers

Write a class LoginGuard(clock, limit=5, window=900, lockout=900) with attempt(username, ok): record a login attempt (ok says whether the password was right) and return "ok", "wrong" or "locked". A user with limit failures within the last window seconds is locked for lockout seconds from the last of them: while locked, every attempt returns "locked" (even with the right password) and isn’t counted. A success clears the user’s failures. Usernames are case-insensitive. Also message(result): the text to show: "Signed in", or the same "Wrong username or password" for "wrong" (so attackers can’t tell which was wrong), or "Too many attempts; try again later".

Bug hunt10 points
The same hash for the same password

Passwords are hashed without a salt, so Ada and Bob, who chose the same password, get the same hash, and this prints True. Give each user a random 16-byte salt from secrets and hash the salt with the password (keeping the salt with the hash), so this prints False (and checking still works).

Bug hunt10 points
A token that never expired

The decoder checks the signature but never looks at exp, so a token that expired long ago is still accepted and this prints accepted. Refuse tokens whose exp has passed, so this prints refused: expired.

Bug hunt10 points
Someone else’s order

The endpoint checks that a user is logged in, but not that the order is theirs, so Bob can read Ada’s order by changing the number in the URL, and this prints 200. Answer 404 for an order that isn’t the user’s (so its existence isn’t revealed either), so this prints 404.

Challenge: an authenticated API

Write create_app(key, clock) (miniflask) with an in-memory user store and these endpoints. POST /register takes {"email", "password"}: emails are lower-cased and must contain @ (422 otherwise), passwords at least 8 characters (422), duplicates 409; it stores a hash from hash_password (given, with 200 iterations for speed) and answers 201 with {"id": N, "email": ...}, never the hash. POST /login checks the password with verify_password (given) and answers 200 with {"token": JWT} (from encode_jwt, given), whose payload has sub (the user id), role ("admin" for the first user registered, "member" otherwise) and exp (clock() + 900); any failure gets 401 with the one message "wrong email or password". GET /me requires Authorization: Bearer TOKEN (decoded with decode_jwt, given; any problem is 401 with {"error": "invalid token"}) and returns {"id", "email", "role"}. GET /admin/users additionally requires the admin role (403 with {"error": "admins only"}) and lists every user’s {"id", "email"}.
