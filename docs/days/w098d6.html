Warm-up

Mixed review

Exercise10 points
The busiest moment

Walkers are on a path from start to end (times in minutes; someone leaving at the same moment another arrives doesn’t overlap). Write most_at_once(intervals): the largest number on the path at any moment, using a sweep over sorted start and end events.

Exercise10 points
Which errors, how often?

Write error_counts(tracebacks): from a list of traceback texts, count the exception class names on their last lines (the part before any ": "), returning a dict sorted by count, most first, then by name.

Coding round

Exercise50 points
Coding round: autocomplete

Write a class Autocomplete with add(word, count=1) (record that the word was searched count more times) and suggest(prefix, k=3): up to k recorded words starting with prefix, most searched first, ties alphabetical. Use a trie of nested nodes so that suggest only looks at words under the prefix: the checks add 50,000 words and make 2,000 suggestions within a time limit. Also write count(word) (0 if never added).

Design and debugging rounds

Design round: autocomplete for every Waymark search

Fifteen minutes aloud: Waymark users type 20 million searches a day, peak factor 5. How many suggestion requests a second at peak (one per keystroke, about 8 keystrokes a search)? Would you precompute the top 5 at each trie node, and what does that cost when counts change? How would you split the trie across servers (by first letter? by hash?), and what happens to a hot prefix like “m”? Then the debugging round: a user reports that suggest("Mi") returns nothing although “Mill” exists. Say your method step by step, and the fix.

Bonus: two loops compared

Exercise30 points
Bonus: what improved?

Write compare_loops(first, second): each loop maps round names to a dict of criteria and ratings (1 to 4). For each round in second (in its order), report "ROUND: A to B (CHANGE)" with the means to 2 decimal places and CHANGE +X or -X (2 places) or same, or "ROUND: new, B" if it wasn’t in the first loop. Then "most improved: ROUND" (largest rise, first on ties, none if nothing rose), "focus next: ROUND" (the lowest mean in the second loop, first on ties), and "weakest criterion: NAME (R)": the lowest single rating in the second loop, first in order on ties.
