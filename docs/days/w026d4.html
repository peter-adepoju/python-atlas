Part B: five problems

Exercise10 points
P1: Paths through a grid

A grid is a list of strings of . (open) and # (blocked). Write paths(grid): how many routes go from the top-left square to the bottom-right square, moving only right or down, through open squares? Use recursion with memoisation; it must handle a 16 by 16 open grid quickly. If the start or end is blocked, there are 0 routes.

Exercise15 points
P2: The smallest of a rotated list

A sorted list of different numbers has been rotated: some items from the front moved to the end, like [15, 18, 22, 3, 7, 9]. Write rotated_min(xs) returning the smallest item in O(log n), with binary search (no min, sorted or loops over every item). The list may not be rotated at all, and has at least one item.

Exercise15 points
P3: Rankings

Write ranking(scores) for a dictionary from names to scores. Return a list of (position, name, score), highest score first, names A to Z for equal scores. Equal scores share a position, and the next position skips: scores 90, 85, 85, 70 get positions 1, 2, 2, 4.

Exercise15 points
P4: Timesheets

A timesheet line looks like Mon 09:00-12:30, 13:15-17:45: a day, then one or more HH:MM-HH:MM ranges separated by commas. Write hours(text) returning a dictionary from each day to its total minutes, in the order days first appear (a day can appear on several lines). Raise ValueError(f"line {n}: ...") with any message you like for a line that doesn’t fit, or a range that ends before it starts. Blank lines are skipped.

Exercise15 points
P5: Test the median

median(xs) in stats.py returns the median of a list of numbers (the mean of the middle two for an even count), without changing the list, and raises ValueError for an empty list. Write pytest tests that catch all five broken versions.

stats.py
def median(xs):
    if not xs:
        raise ValueError("median of an empty list")
    s = sorted(xs)
    mid = len(s) // 2
    if len(s) % 2:
        return s[mid]
    return (s[mid - 1] + s[mid]) / 2

Part C: a larger program

Exercise30 points
C: Exam clashes

A school’s exam entries arrive as CSV text with columns student, subject, date (DD/MM/YYYY), start and end (HH:MM, 24-hour). Write:

  1. load(text) returning (entries, problems): each entry is a dictionary with student and subject (stripped), date (ISO text), and start and end (minutes after midnight); a row whose date or times can’t be read, or whose end isn’t after its start, gives the problem line N: <the student> instead (N from reader.line_num).
  2. clashes(entries) returning a list of (student, subject1, subject2, date) for every pair of one student’s exams on the same day whose times overlap (one starts before the other ends; touching end to start is fine). In each tuple, subject1 is the exam that starts first (alphabetical if they start together). Sort the list by student, then date, then subject1, then subject2.
  3. report(text) returning lines: Clashes: N then, for each clash, Ada: Maths and Physics on 2027-06-03, then Problems: none or Problems: line 4: Bo, line 7: Cy.

Afterwards

When the timer ends, add up your marks, then go back through each problem with its hint and solution. For every mark you dropped, decide which kind of reason it was:

  1. Didn’t know it: revise the topic from this week’s review days.
  2. Misread the question: the code did something sensible but different. Tomorrow, underline every requirement before you start.
  3. Edge case: the main case worked; an empty list, a tie or a boundary didn’t. Tomorrow, test small and extreme cases before pressing Check.
  4. Ran out of time: do the problems you’re sure of first, and move on after 15 minutes stuck.
